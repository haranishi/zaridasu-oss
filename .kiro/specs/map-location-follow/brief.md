# 地図の現在地追従（brief）

2026-10-21、本人の依頼。「地図の自分の位置が、車で動いても現在地のまま変わらない。追従する仕組みがほしい。SDDにも足してほしい」。
要件は [requirements.md](requirements.md)、設計は [design.md](design.md)、進捗は [tasks.md](tasks.md)。

## 何が起きているか

地図右下の「現在地を表示」は、押した瞬間に位置を1回だけ取り、青い点を1つ置いて終わる。
`MapView.tsx` の `LocateButton` が `map.locate({ setView: true, maxZoom: 14 })` を1回呼び、結果を `once` で受けている。継続して取る指定（`watch`）が無い。
`src/` 全体を検索しても `watchPosition` は1か所も無い。だから、移動しても点は動かない。

同じ箇所に、追従と合わせて直したい点が3つある。

- 秋田県の外にいると、地図はそこへ動くのに青い点を出さない。条件は初期実装から残っていて、理由の記録は無い。
- 位置が取れない・許可されないとき、何も表示せずにボタンが戻るだけ。
- 押すたびに点を作り直している。

## 範囲

地図の現在地ボタンだけを変える。投稿フォーム・クイック保存・調査画面の位置取得は、一度きりのまま変えない。
DB・権限・計測は変えない。新しい画面やボタンは足さず、既存ボタンの挙動を「追従」に広げる。

## 本人の判断が要るもの

次の6つは、既定を決めて実装する。違えば、該当の箇所だけ戻せる。

| 項目 | 既定 | 理由 |
|---|---|---|
| 追従中は「現在の地図範囲内のみ」を自動でオフにする | する（取得中・追従中。一時停止中は使える） | この絞り込みがオンだと、地図の範囲（南北・東西の座標）が検索条件としてサーバーへ送られる。追従中はその範囲が現在地を中心に動くので、移動の軌跡がログイン中の利用者のIDと一緒にサーバーのログに残る。実装中に見つけた抜け道 |
| 追従中に画面を点けたままにする | する（対応端末だけ。やめる・ページが隠れると解放） | 車で使うと、画面が自動で消えた時点で更新が止まり、今回と同じ「動かない」に戻る。電池は減る |
| 秋田県の外でも青い点を出す | 出す | 追従する対象が見えなくなるのを避ける。県外で押すと地図がそこへ動く、という従来の動きは変わらない |
| 進行方向の矢印 | 作らない | 依頼は位置の追従。向きの取得は端末の向きの許可（iOS）が別に要る |
| 画面を閉じている間の追従 | できない | Webの制約。ブラウザが裏に回ると位置の取得が止まり、戻ると自動で再開する。常時追従は、アプリ化の別の話 |
| 軌跡の記録・保存 | 作らない | 位置を保存すると、個人情報の扱いが変わる |

## 先に決まっている前提

- REQ-324: 初期表示で位置情報の許可を求めない。追従は、ボタンを押した後だけ始める。
- REQ-331: 右下のボタンの入れ物（`MapAction`）にある現在地ボタンの位置と順序は変えない。
- REQ-322: 地図の操作子は無彩色にする。青は種別（データ）の色なので、ボタンに使わない。
- 現在地の青い点は、従来どおり `#3B82F6`（種別の青 `#0072B2` とは別の、現在地の慣例色）。
