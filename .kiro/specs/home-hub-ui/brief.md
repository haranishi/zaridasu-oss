# 起動時のホーム画面を、参加と閲覧の入口にする

2026-10-19の本人訂正により、対象をLPからアプリのホームへ変更した。
提供されたBiomeのスクリーンショット5枚を構造と情報密度の参考にする。
今回の成果物はFigmaでの確認用UI。実装・本番反映は次工程。

## 本人が指定した構成

- アプリ起動時にこのホームを表示する。地図は下部タブから開く。
- マイページ、本人のレベル・記録・バッジを上部で確認できる。
- 差し替える参加企画・広告のバナーを置く。内容は見本でよい。
- クエスト、ピックアップ、新着投稿、人気投稿、新着の質問を並べる。
- コレクション、いきものログ・読みもの、お知らせを置く。
- 承認済みBロゴとザリダスの対象2種を引き継ぐ。

## 現行との関係

現在の `/` は地図で、下部ナビは地図・動向・投稿・ランキング・マイページ。
ホームを `/`、地図を独立した入口へ移すのは挙動変更になるため、今回は遷移案まで。
既存の投稿・認証・XP・バッジ・調査依頼・コレクションの契約を引き継ぐ。
新着質問・記事・広告管理・人気集計などのデータ接続は、この試作で実装済みと扱わない。

## UXの5階層と利用者

| 階層 | 設計 |
|---|---|
| 戦略 | 初回も再訪も、次の観察・閲覧・参加へ迷わず進める |
| 要件 | 本人の状況、差し替えバナー、横に読める一覧、投稿と地図の入口 |
| 構造 | 参加企画 → 本人の状況・バッジ → クエスト → 投稿 → 質問・図鑑・読みもの・お知らせ |
| 骨格 | スマホの固定ヘッダーと5つの下部タブ。カードは横方向にも閲覧できる |
| 表層 | 白地と写真を中心に、Bロゴの赤を操作の目印に使う |

初回利用者はログインせず記録を見られる。投稿や自分の進捗は認証後の状態と区別する。
再訪者は自分の進捗と参加できる調査を見つけ、地図・投稿へ進める。

## 見本と検証

- 参考画像のロゴ・利用者・投稿は転用しない。表示例の写真は生成素材であると説明する。
- バッジ・XPは承認済み投稿に基づく既存条件を守り、いいねにXPを付けない。
- 仮の協賛・行政との共催・開催期限を実在するものとして見せない。
- 390/768/1440px、初回・再訪、バナー切替、地図への移動、バッジ表示をFigmaで確認する。
- 画像と編集可能なレイヤー構造を確認する。実データ・認証・性能・読み上げは次工程。
