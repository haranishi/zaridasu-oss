# 卒業研究としての位置づけ

[READMEへ戻る](../README.md) · [設計思想](08-design-philosophy.md)

本アプリは、市民参加型の外来種調査を扱う卒業研究プロジェクトです。秋田県では、外来種の目撃情報が個人や一部の専門家の間に留まりやすく、行政や専門家だけで全県の分布を継続的に把握するにはコストがかかる、という課題があります。

そこで、スマートフォンからの投稿を地図に集約し、季節ごとの変化や生息の集中地点を把握できるようにします。市民が外来種問題を身近に捉えるきっかけをつくり、蓄積した情報を効果的な調査・駆除計画に役立てることを目的としています。研究上は、参加率・継続率・データ品質を分けて追跡する設計です。

### 研究の枠組み（2026-09-06 時点）

- **所属と種別**: 秋田県立大学 システム科学技術学部 経営システム工学科の卒業研究。
- **題目**（2026-05-17 確定）: 「市民科学プラットフォーム『ザリダス』に基づくアメリカザリガニ統合管理モデルの構築 ─環境DNA・経済評価による多面的検証─」。
- **期間**: 2026 年 5 月〜2027 年 3 月（卒業論文の提出と最終発表）。投稿データの収集は 2026 年 7〜9 月（アメリカザリガニの活動期）を中心に置く。
- **メインのリサーチクエスチョン**: ザリダスから得られるアメリカザリガニの分布データは、環境 DNA 分析と経済損失データによる多面的な検証を通じて、地域の外来種管理の意思決定（モニタリング・駆除・利活用）に資する科学的信頼性と実用性を示すか。
- **サブのリサーチクエスチョン**（4 テーマ。番号は研究ノートの 2026-06-02 時点の整理に合わせる）:
  - RQ1: 市民投稿データの質と量を向上させるシステム要件は何か。本アプリが直接担うテーマで、UI/UX 改善・フィードバック機能・ゲーミフィケーションが投稿数、位置情報の精度、写真添付率、リピート投稿率に与える効果を測る。
  - RQ2: 駆除したアメリカザリガニの利活用経路（食用・飼料・肥料・教育素材など）の経済性はどうか。
  - RQ3: アメリカザリガニによる農業被害と生態系サービス損失の金銭評価額はいくらか。
  - RQ4: 種特異的な環境 DNA 検出（PCR / qPCR）で、地域の在・不在をどの精度・感度・コストで把握できるか。市民投稿の分布図との一致度（Cohen's κ）で市民投稿の信頼性を検証する。
- **仮説**（研究計画書）: H1 = 鳥海ダム周辺で投稿地点と環境 DNA 検出地点の Cohen's κ は 0.4 以上。H2 = フィードバック機能の導入でリピート投稿率は導入前の 1.5 倍以上（カイ二乗検定、p < 0.05）。経済損失額の仮説は予備調査のあとに数値を置く。
- **評価指標**: 参加率・継続率・データ品質を分けて追跡する（[研究 KPI 週次レビュー](../docs/runbooks/kpi-weekly-review.md)）。
- **倫理審査**: 公開データセットはアカウント情報・IP・自由記述などを含めない。アプリ内部の投稿は利用者IDに結び付き、本人管理と権限確認に使う。研究計画書では CVM アンケートと事業者ヒアリングを「審査が必要になり得る項目」とし、実施前に指導教員と要否を確認する。
- **成果と発表**: 日本環境教育学会 第 37 回年次大会（2026-09-12〜13）で実践報告のポスター発表（P実07）。査読付き論文は未投稿。卒業論文は 2027 年 3 月に提出予定。

### 位置情報・個人情報・投稿データの扱い

公開位置は記録ごとに「正確な位置」「約 111 m に粗化した位置」「非公開」のいずれかで管理し、アメリカザリガニとウシガエルの既定値は粗化です。投稿者も自分の記録を「非公開」にでき（公開へ戻すのは管理者だけ）、非公開の記録では字名・水系名も公開しません（REQ-329）。投稿者本人と管理者は正確な座標を参照できますが、一般公開される座標は設定された公開範囲に制限されます。投稿写真は保存前に再処理し、撮影場所を含み得る EXIF メタデータを除去します。

公開データセットは、承認済みの投稿だけを対象とし、座標を小数第 3 位（約 111 m のグリッド）へ粗化します。`user_id`、メールアドレス、投稿元 IP、自由記述、写真などの個人を識別し得る項目は含めず、スナップショット公開前にも人手で再確認します。

### 投稿データの研究利用と同意

- **研究に使う範囲**: 承認済みの投稿の観察情報（種類・情報種別・市区町村・観察日時・個体数・調査手法など）。個人を特定できる項目（アカウント情報・IP アドレス・自由記述）は使わず、写真は公開データセットに含めない。運営者（研究者本人）は管理者として正確な座標を参照できるが、公開と再配布は粗化した座標に限る。
- **参加者への説明**: [利用規約 第 4 条](../src/views/TermsPage.tsx)で、粗化と個人情報の除外を条件に、研究・行政・教育目的のオープンデータとして CC BY 4.0 で公開・再配布し、Zenodo などに DOI 付きで登録することを許諾してもらう。[プライバシーポリシー](../src/views/PrivacyPage.tsx)には利用目的（サービス改善・統計分析）と第三者提供の条件を、`/about` にはデータの活用先（分布調査・生態系保全研究・行政の外来種対策）を書いている。
- **同意の形**: 登録や投稿の画面に個別の同意チェックは置かず、利用規約とプライバシーポリシーへの同意で扱っている。研究に採用されたときの通知は、プロフィールで本人が選ぶ（コード上の既定はオン）。
- **保持と削除**: 利用者には自分の投稿・写真の削除操作がある。DBとStorageは一括の処理ではなく、削除の部分完了や残存の制約は[保存と審査](../docs/architecture/posting-moderation.md)で確認する。アカウントを削除するとプロフィール・バッジ・いいね・調査依頼・非公開スポット（REQ-329）は消え、投稿とコメントは匿名化して残る（削除画面に明記）。運用ログの保持は [REQ-279](../docs/requirements/REQ-279-db-rls-initplan-log-retention.md) の方針で AI 呼び出しログとメール送信ログが 180 日、監査ログが 365 日。DOI を付けた公開スナップショットは取り消さない前提で扱う。
