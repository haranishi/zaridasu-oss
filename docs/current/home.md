# ホームと地図の入口

起動時の `/` は参加と閲覧のホーム。地図・写真の既存機能は `/map` にある。
ナビはホーム・地図・投稿・図鑑・マイページ。動向・ランキング・調査依頼はメニューから開く。
正本：[HomeHub](../../src/components/features/home/HomeHub.tsx)、[BottomNav](../../src/components/layout/BottomNav.tsx)。

## 最初の画面で、何のサービスかを伝える

未ログイン（認証の確認中を含む）のホームの最上部は、見出し・説明・主ボタン「無料で登録して記録する」・副ボタン「登録せずに地図を見る」・運営者の一行・記録ガイドと「記録の使われ方・連絡先」（`/about`）へのリンク。
文言はLPの見出しと運営者の一文を引き継ぐ。運営者の一文は、画面の他の欄に合わせて「報告」を「記録」に直した `homeHub.hero.operator`（LP側の文は変えない）。大学名は出さない。ページの h1 は読み上げ専用のまま、ヒーローの見出しは h2。
サーバーが出すHTMLにも含め、認証が確定しても未ログインでは画面がずれない。会員にはヒーローを出さず、本人カードを出す。
サーバーは日本語で描き、起動後にブラウザの言語（英・韓・中）へ切り替わる。行数が言語で変わると、切り替わる瞬間に下の要素が動く（CIのChromeは英語）。最初の画面（約820px以内）に足す文言は、どの言語でも行数が大きく変わらない長さにする。リンクは1行に収める（英語の「How records are used & contact」が折り返して、CLSが上限0.1を超えた）。
正本：[HomeHero](../../src/components/features/home/HomeHero.tsx)。

本文の並びは、ピックアップ → まだ足りない記録 → 新着の記録 → 人気の記録 → 新着のしつもん → 図鑑 → 記録ガイド → お知らせ。バナーはヒーローの下（会員は本人カードの上）。
画面の名詞は「記録」にそろえる（「投稿」は下部ナビのボタン名にだけ残す）。下部ナビの「図鑑」と、ホームの欄名も同じ「図鑑」。ガイドの呼び名は「記録ガイド」の一つ（欄名・ページの題・ヒーローのリンク・PCの案内ボタン）。

## 見本のデータを実績にしない・中身が無い欄は出さない

ピックアップ・新着は直近24件の承認済み公開投稿。人気はその取得分のいいね順で、全期間順位ではない。
質問は同じ投稿の公開コメントから疑問符を含むものを選ぶ。専用の質問サービスとしては扱わない。
人気は、いいねが付いた記録が3件以上のときだけ出す。しつもんは1件以上のときだけ出す。ピックアップは写真付きが0件なら出さず、写真の枚数に合わせて空きマスなく組む。
ピックアップに出した記録は、新着の記録には出さない（同じ写真が1回のスクロールで2度出ない）。残りが無く、写真なしの記録も保存も無いときは、新着の記録の欄ごと出さない。
新着の写真なしの記録は、灰色の空カードにせず1行で並べる（同じ日・市町村・種・種類は「N件」にまとめ、不在確認は「見つからなかった」と書く）。
読み込み・空・取得失敗を分け、失敗時には再試行を表示する。正確な座標、投稿者の個人情報、非公開プロフィールをホームへ取得しない。
正本：[useHomeFeed](../../src/hooks/posts/useHomeFeed.ts)、[公開取得層](../../src/lib/data/posts.ts)、[集計](../../src/lib/homeGaps.ts)。

本人のXP・承認数・種類数は既存RPCを使う。未取得をゼロ扱いせず、再試行は本人の集計をまとめて読み直す。
バッジは既存の承認1・5・10・30件。新しい報酬の付与条件は作らない。
正本：[HomeProfile](../../src/components/features/home/HomeProfile.tsx)、[参加の契約](gamification.md)。

## まだ足りない記録

承認済みの公開記録の種・種類・市町村だけを取り、記録が少ない種（5件未満）、「見つからなかった」（20件未満）、記録のある市町村（全25未満）を、数字つきで最大3枚出す。数字は見出し程度の大きさで本文と同じ色にする（赤い大きな「0件」は、まだ使われていない印象を最初に与えるため使わない）。説明文は「公開されている記録を数えて」と数字の出どころを書く。取得中・失敗・該当なしは欄ごと出さない。
押すと、会員は種・種類を選んだ投稿画面（`/map?post=1&postSpecies=…&postType=…`）、未ログインは登録画面を開く。登録後に投稿画面を自動で開く処理は無い。
正本：[HomeGaps](../../src/components/features/home/HomeGaps.tsx)、[useHomeCoverage](../../src/hooks/posts/useHomeCoverage.ts)、[postPreset](../../src/lib/postPreset.ts)。

## 端末への保存と、編集できる案内

保存は端末・ブラウザ内で最大200件。会員IDとゲストを分け、別端末への同期は行わない。
「保存した記録を見る」は、1件以上保存したときだけ出す。開き直す際も、現在の承認済み公開投稿だけを再取得する。
非公開・削除済みの投稿は一覧に出さない。本人用の非公開スポット保存とは別の機能。
正本：[HomeFeed](../../src/components/features/home/HomeFeed.tsx)、[SavedPosts](../../src/components/features/home/SavedPosts.tsx)。

参加・モニターアンケート・アプリ紹介の3バナーは手動で切り替える。1枚目（参加）は「記録する」（`/map?post=1`。会員は投稿画面、未ログインは登録の小窓）へ案内する。調査依頼のページ（`/requests`）は、本物の依頼が立つまで案内しない。架空の協賛や開催期限は掲載しない。
小見出し（ホーム冒頭の見出しの上と `/map` のヘッダー）は「水辺の外来生物を、みんなで記録する地図」の系統。ヘッダーは幅が狭く1行なので、短い形（`header.subtitle`）にしてある。ホーム冒頭は言語を切り替えても1行に収める（サーバーが日本語で描いた後に言語が切り替わるため、行数が違うと下がずれる）。ブラウザのタブ名・検索結果・共有カード・アプリ名は別の文言のまま。
記事・お知らせはローカルの案内文。生成した水辺・生き物画像（[homeImages](../../src/components/features/home/homeImages.ts) の6枚）には「説明用の画像」の札を重ね、実投稿には使わない。バナー・図鑑・記録ガイドの記事は別々の画像にし、同時に見える位置で同じファイルを繰り返さない。
画像の最適化は同じURLを31日覚えるため、中身を差し替えるときは同じ名前に上書きせず、ファイル名の版（`-v2`）を上げる。
ホームにはフッターが無いので、末尾に「このサービスについて・利用規約・プライバシーポリシー・お問合せ」のリンクを置く。
`/guide` に記録方法、まだ足りない記録、FAQを置く。投稿は `/map?post=1`、認証は既存のモーダルへ接続する。
正本：[CampaignBanner](../../src/components/features/home/CampaignBanner.tsx)、[HomeResources](../../src/components/features/home/HomeResources.tsx)。

## 計測

`home_cta`（ヒーローの副ボタン・ガイド・記録の使われ方）、`home_banner`、`home_gap`、未ログインで記録しようとした操作の `post_intent` を送る。座標・個人情報は送らない。GTMの転送設定は別に必要。

要件・設計・検証：[home-hub-ui](../../.kiro/specs/home-hub-ui/requirements.md)。
