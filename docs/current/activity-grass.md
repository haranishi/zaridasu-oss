# マイページの「活動の記録（草）」

マイページ（`/dashboard`）の、進捗の下・バッジの上にあるカード。過去1年に記録を投稿した日を、GitHubの貢献グラフのように濃さで見せる。**本人だけ**が見る。
正本：[ActivityGrass](../../src/components/features/dashboard/ActivityGrass.tsx)、[集計](../../src/lib/activityCalendar.ts)、[取得](../../src/lib/data/posts-own.ts)。要件・設計：[activity-grass](../../.kiro/specs/activity-grass/requirements.md)。

## 何を数えるか

- 活動した日は、**本人が記録を投稿した日**。審査待ちも、投稿した日に数える。却下は数えない。承認が遅れても、投稿した日の実感が消えないようにするため。審査待ちが後で却下されると、その日の草は消える（カードに一文で書いてある）。
- 「見つからなかった」の記録も同じ1件。調べた日そのものが積み上がる。
- 日付は観察日（なければ投稿日）を日本時間で区切る。過去の観察を後から投稿しても、観察した日に生える。
- 濃さは**1日5件で頭打ち**（1・2・3〜4・5件以上の4段階と、0件）。5件は1日の投稿上限。件数に比例させない。量産で稼ぐ動機を作らない（いいねを報酬にしない、XPは1日120まで、という方針に合わせる）。凡例は、この件数を数字で書く（`legendSteps` が `levelFor` から作るので食い違わない）。暗い配色は濃いほど明るい緑になるので、「少ない／多い」の語は使わない。
- **出さないもの**：連続日数、途切れの表示、他人との比較・順位、いいねやコメントでの加点、公開プロフィールへの表示。休んだ日が罰に見えないようにする（クエストも任意・無罰）。

## 取得

本人の審査待ち・承認済みの記録の、観察日・投稿日・種類・状態の4列だけを、過去1年分（上限2000行）1回で取る。座標・コメント・写真は取らない。新しいDB・権限・RPCは作っていない（本人の投稿は、本人なら全状態を読める）。失敗は、空と区別して再試行を出す。
DBアクセスは `src/lib/data/` に置く決まり（lint が止める）。

## 見た目と使い方

- 週を列・曜日を行、月曜始まり、今日を含む週が右端。全部のセルに枠を付ける（枠と下地は3:1以上。薄い緑だけでは、下地との差が足りない）。色は `globals.css` の `--grass-*`（明暗）で、テストが計算で確かめる。
- スマホは12pxのセルで横に送り、はじめは右端を見せる。**横に送れることは、文（「表を右へずらすと、1年前まで見られます。」）と、続きがある側の端のうすい影で伝える**（影は `data-more-left/right` を再描画なしで切り替える。左の影は曜日の列の右端から始め、列の下に隠れかけたマスの切れ端も消す）。カードが700px以上なら、10pxのセルで1年分を横に送らずに見せ、案内も影も出さない。
- 並びは、表 → 凡例 → 操作の案内 → 選んだ日の枠 → 一覧を開くボタン。凡例は色の読み方なので表のすぐ下に置き、文字は本文の色にする。
- 日を選ぶ（押す・矢印キー・Enter）と、その日の件数・内訳（件数の単位つき）・審査待ちの件数が出る。見出しは、本人が選ぶまでは「最後に記録した日」（自動で選んでいるだけ）、選んだあとは「選んだ日」。ホバー専用にしない。Tabの停止は1つ（選んだ日）。上下は前後の日、左右は前後の週。去年の日付には年も付ける。
- セルが小さく、押しやすさの基準に届かない。そこで、44px以上の行で並ぶ「記録した日の一覧」でも、同じことができる。一覧は**新しい7日から出し、「さらに表示」で14日ずつ足す**（高さを固定した内側のスクロールは、ページのスクロールと入れ子になり指で扱いにくいので使わない）。一覧から選んだら、画面の外にある詳細を見える位置まで動かす。
- 記録が0件のあいだは、合計・注記・操作の案内を出さず、「最初の記録を投稿すると、その日のマスに色がつきます」と「記録を投稿する」だけを出す（0日・0件の合計は責めるように見える）。
- マイページの初期JS（予算24 kB）を増やさないため、`next/dynamic`（`ssr: false`）で別チャンクにしている。

## 触るときの注意

- 頭打ちの件数と濃さの決め方は、`levelFor` だけで決める。
- 左の曜日の列は、全部の行で下地つきの固定列にする。月・水・金の行だけだと、横に送ったセルが下から透けて見える。
- 文字色は、どの文字にも `var(--color-*)` で必ず指定する。アプリの本文は body から色を継承せず（黒のまま）、指定を忘れると明るい配色では読めても、暗い配色では紺の地に黒文字（1.4:1）になる。E2E の暗い配色のテストが、詳細欄の全行を4.5:1で確かめる。
- 文言は `activityGrass.*`（4言語）。月・曜日の名前は `Intl` で作り、文言ファイルに持たない。
- 公開・共有（プロフィール、画像、SNS）を足すときは、別の仕様で、本人の同意と見せ方を決める。
