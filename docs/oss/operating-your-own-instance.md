# 自分でサービスとして運用する人へ

ザリダスのコードをもとに、自分のサービスを公開する人向けの注意です。法的な助言ではありません。
このリポジトリに、公式サービス（zaridasu.com）の鍵・データは入っていません。

## 対象としている構成

公式サービスは、Vercel（Webの配備）とSupabase（DB・認証・ストレージ・Edge Functions）で動いています。このリポジトリが対象にするのも、この構成です。

`cloudflare/`・`scripts/cloudflare/`・`wrangler.jsonc`・`open-next*.ts` などは、Cloudflare Workersへ移れるかを調べる実験です。公式サービスでは使っておらず、移行も決まっていません。この部分を変える提案は、大きな変更として、先にIssueで相談してください。

## 最初に変える設定

公開版は、公式サービスを宛先にしないように作ってあります。それでも、次は自分の値に変えてください。

- `NEXT_PUBLIC_APP_URL`。`.env.example` の例は公式のURLです。変えないと、canonical・OGP・共有リンクが公式サイトを指します。
- Edge Functionの `SITE_URL`・`NOTIFY_FROM_EMAIL`・`VAPID_SUBJECT`。未設定のときの既定値は、公式のドメインと連絡先です。
- Supabase・AI・メール・Sentryの鍵は、自分のアカウントで作った値を使います。
- 計測（GTM）の `NEXT_PUBLIC_GTM_ID` は、自分のIDを入れるか、空にします。空なら読み込まれません。
- フィードバックと調査へのリンク。公開版では `src/lib/constants.ts` の `FEEDBACK_FORM_URL` と、`src/components/features/home/CampaignBanner.tsx` の `MONITOR_SURVEY_URL` が、存在しない宛先になっています。自分の窓口に差し替えるか、リンクを外してください。

## DB側の注意

- DBがEdge Functionを呼ぶ通知は、自分のVaultに鍵を入れ、`app.settings.supabase_url` に自分のプロジェクトのURLを設定して動かします。`WEBHOOK_SECRET_ENFORCE=true` も設定してください。
- AIの呼び出し（`private.call_ai_edge_function`）は、URLがマイグレーションに固定されています。公開版では存在しない宛先なので、AIを使うなら、該当するマイグレーションの行を自分のURLに直してください。
- AIと通知は、利用上限と止める手順を先に決めます。
- 公式サービスのDBや鍵は、開発・検証に流用しません。

## 公式の運用記録は、そのまま実行しない

`docs/runbooks`・`docs/archive`・`.kiro/specs` は、公式サービスの運用と開発の記録です。公式のプロジェクトIDや過去の計測ID、公式向けの手順が文章として残っています。自分の環境では読み替えてください。そのまま実行しないでください。

## 個人情報を扱う責任は運営者にある

位置・写真・音声・メールアドレスは、個人情報になりえます。公開して運用する人が、自分で次を用意します。

- 利用規約とプライバシーポリシー。利用目的、同意の取り方、保存期間、削除の窓口、問い合わせ先を書きます。公式のものは公式サービスの運営者・連絡先・研究計画が前提なので、そのまま使えません。
- 位置の公開範囲。ザリダスは、希少種や非公開地点の正確な座標を公開しない設計です。この境界（RLS・列権限）を弱める変更は、投稿者に被害が出うる変更として扱ってください。
- 漏えいや不具合の連絡先と担当。

## 地図と素材

- OpenStreetMapの標準タイルは、大量のアクセスを前提にしていません。公開サービスにするなら、提供元の利用ポリシーを確かめてください。必要なら自分で契約・用意したタイルを使います。出典表示は消さないでください。
- 同梱の画像・ロゴは、[素材台帳](../../THIRD_PARTY_NOTICES.md)の条件に従います。公式サービスと間違えられないよう、自分のサービスには別の名前とロゴを使ってください。ライセンスの条件ではなく、お願いです。
- 地図の部品 `react-leaflet` は倫理条項つきのライセンスです。条件は素材台帳の表で確かめてください。

## 公式サービスとの関係

このリポジトリで取り込まれた変更が、公式サービスにいつ反映されるかは約束しません。forkして運用するサービスのサポートも約束しません。
