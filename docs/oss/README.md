# OSSの公開範囲と参加

`haranishi/zaridasu-oss` は、運営している非公開の運用repoから、履歴を持ち込まずにソースだけを切り出して公開したものです。
ソースと表示確認用の代替画像を含み、本番の観察記録・写真・非公開地点を配布するものではありません。
由来と未確認事項は [公開の状況](release-status.md)、公開準備の背景は [仕様](../../.kiro/specs/oss-readiness/tasks.md) で確認できます。
元の運用repoは非公開のまま保持します。

## 公開するものを分ける

| 対象 | 方針 |
| --- | --- |
| アプリ・DB定義・テスト・共通文書 | コードのMITを維持する。[LICENSE](../../LICENSE) |
| 地図・フォント・説明画像・ロゴ | 一律にMITと判断せず、[素材台帳](../../THIRD_PARTY_NOTICES.md)の出所と個別条件を確認する |
| 投稿者・投稿写真・正確な座標・非公開地点 | コード公開に含めない。本番DB・Storageを開発者へ配布しない |
| 公開データセット | このリポジトリとは別にCC BY 4.0で提供する。[公開仕様](../current/public-dataset.md)に従う。元の公開投稿と照合できるIDを含むため完全な匿名データとは呼ばない |
| 本番キー・バックアップ・運用ログ | 非公開で管理する |

GitHubで既存repoをPublicにすると、過去のコミット・PR・Issue・Actionsログ等も公開対象になります。
`.gitignore`や`.gitattributes`は、GitHubでの閲覧・cloneから履歴を隠す機能ではありません。

## 履歴を持ち込まない理由と確認

[公開手順と判断条件](publication.md)に従い、export元revision、素材manifest、文書差分、検証の結果を照合しました。
旧repoの履歴・PR・ログ・artifactは持ち込んでいません。元の履歴をmergeして更新しないでください。元repoへの過去のリンクは設計の記録です。
このリポジトリのmainはリリース用、developはソースの統合先で、自動配備はありません。参加者のPRから本番へ配備できません。
元の運用repoの秘密情報は、ここへコピーせず、Actions・artifact経由で取り出すこともしません。

## マージされた変更の行き先

このrepoは、保守者が運営する非公開の運用repoから、ソースだけを切り出して公開したものです。
採用するPRは、ここでレビューしてマージします。保守者が同じ変更を運用repoにも取り込み、元のコミットの作者を残します。その後の同期で、このrepoと内容をそろえます。
PRを採用するかどうかは約束しません。採用した変更も、運営中のサービスに反映されるとは限りません。反映の時期も約束しません。

## 保守の範囲

文書・翻訳・再現手順付きの不具合報告・小さな修正を受け付けます。
新機能・依存追加・権限や保存形式の変更は、実装前に保守者と相談してください。
返答時期や全PRの採用は約束しません。外部の協力者へ本番の認証情報を渡す必要はありません。
