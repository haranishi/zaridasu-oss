## コンテンツ優先度

| 優先度 | 改善対象 | 理由 |
|--------|---------|------|
| P1（必須） | PostCard（リスト一覧） | 全ユーザーが最も長時間見る画面 |
| P1（必須） | MapView ポップアップ | 地図操作時に必ず参照する |
| P1（必須） | StatsBar | ヘッダー直下で常に見える |
| P2（重要） | FilterBar | 操作の起点 |
| P2（重要） | TrendsPage チャート | データ分析に必須 |
| P2（重要） | CommentSection | 詳細ページのコミュニケーション領域 |
| P3（補助） | Footer / Header 細部 | 閲覧頻度が低い |
| P3（補助） | PostForm / EditDialog ラベル | 操作時のみ参照 |

## テスト観点

1. PostCard のコメントが 2 行まで表示され、ホバーで全文がツールチップ表示されること
2. 地図ポップアップの全テキストが `text-sm`（14px）以上であること
3. StatsBar の全テキストが `text-sm`（14px）以上であること（前月比の `text-xs` は例外許容）
4. ライトモードの全テキストが白背景に対してコントラスト比 4.5:1 以上であること
5. ダークモードの全テキストが暗い背景に対してコントラスト比 4.5:1 以上であること
6. モバイル（375px幅）でテキストが 12px 未満にならないこと
7. BarChart の軸ラベルが 12px 以上であること
8. Chrome DevTools のアクセシビリティ監査で contrast 違反が 0 件であること
