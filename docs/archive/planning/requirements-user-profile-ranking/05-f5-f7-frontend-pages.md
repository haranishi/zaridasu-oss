### F7: プロフィール編集モーダル

| フィールド | 型 | バリデーション |
|---|---|---|
| display_name | TEXT | 1〜20文字、禁止ワードフィルタ |
| avatar_emoji | TEXT | 絵文字1文字（プリセットから選択） |
| bio | TEXT | 0〜100文字 |
| is_public | BOOLEAN | ランキング表示のON/OFF |
