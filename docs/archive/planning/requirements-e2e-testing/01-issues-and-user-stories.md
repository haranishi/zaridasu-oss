## 現状の課題

1. Vitest + React Testing Library によるユニット/コンポーネントテストのみ（11ファイル）
2. 投稿→承認→地図表示のような**エンドツーエンドのフロー検証が一切ない**
3. ブラウザ固有の問題（Leaflet 地図描画、EXIF 読み取り、Service Worker 等）がテストされていない
4. デプロイ前にリグレッションを自動検知する仕組みがない
5. レスポンシブ（モバイル/デスクトップ）の動作確認が手動のみ

---

## ユーザーストーリー

| 対象ユーザー | やりたいこと | 理由 |
|------------|------------|------|
| 開発者 | 主要ユーザーフローが壊れていないことをデプロイ前に自動確認したい | リグレッションによるサービス停止を防げる |
| 開発者 | モバイル・デスクトップ両方の表示崩れを自動検知したい | 手動確認の漏れによるUX劣化を防げる |
| 管理者 | 投稿承認・拒否フローが正しく動くことを保証したい | 誤承認・データ消失のリスクを減らせる |
