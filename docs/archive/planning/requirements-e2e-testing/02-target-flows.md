## 機能要件

### F1: テスト対象フロー（優先度順）

**P1: クリティカルパス（必須）**

| # | テストシナリオ | 検証内容 |
|---|-------------|---------|
| 1 | トップページ表示 | 地図・投稿リストが描画される。フィルター操作で投稿が絞り込まれる |
| 2 | ユーザー登録→ログイン | サインアップフォーム送信 → ログイン → ヘッダーにユーザー情報表示 |
| 3 | 投稿作成 | ログイン済ユーザーが種別・位置・写真を指定して投稿 → 成功トースト表示 |
| 4 | 投稿詳細表示 | 投稿カードクリック → 詳細ページ遷移 → 写真・コメント・地図表示 |
| 5 | 管理者：投稿承認/拒否 | 管理者ログイン → /admin/posts → 承認ボタン → ステータス変更確認 |

**P2: 重要フロー（計画対応）**

| # | テストシナリオ | 検証内容 |
|---|-------------|---------|
| 6 | コメント投稿 | 詳細ページでコメント入力 → 投稿 → コメント一覧に反映 |
| 7 | いいね機能 | いいねボタンクリック → カウント増加 → 再クリックで取り消し |
| 8 | 投稿編集・削除 | 自分の投稿を編集 → 保存 → 反映確認。削除 → 確認ダイアログ → 消去 |
| 9 | ダッシュボード | マイページに自分の投稿統計・CSV エクスポートが表示される |
| 10 | トレンドページ | グラフ・KPI が描画される。データが 0 件でもクラッシュしない |

**P3: エッジケース（将来対応）**

| # | テストシナリオ | 検証内容 |
|---|-------------|---------|
| 11 | 未認証ガード | 未ログインで投稿ボタン → ログインモーダル表示 |
| 12 | 404ページ | 存在しないURLアクセス → NotFoundPage 表示 |
| 13 | オフライン | Service Worker 有効時にオフライン → OfflinePage 遷移 |
| 14 | 多言語切替 | 言語切替 → UI テキストが対応言語に変わる |
| 15 | ダークモード | テーマ切替 → 背景・テキスト色が切り替わる |
