## 画面遷移・ユーザーフロー（P1テスト対象）

```
[トップページ /]
   ├── [フィルター操作] → 投稿リスト絞り込み確認
   ├── [投稿カードクリック] → [詳細ページ /post/:id]
   │                              ├── 写真・コメント表示確認
   │                              └── [コメント投稿] → 反映確認
   ├── [投稿ボタン（未認証）] → [ログインモーダル]
   │                              ├── [サインアップ] → 登録確認
   │                              └── [ログイン] → 認証成功
   └── [投稿ボタン（認証済）] → [投稿フォーム]
                                   └── [送信] → 成功トースト

[管理画面 /admin]
   └── [/admin/posts] → [承認ボタン] → ステータス approved に変更
                       → [拒否ボタン] → 理由入力 → ステータス rejected に変更
```
