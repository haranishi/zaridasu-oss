## 実装前の準備作業（コード不要）

1. テスト用 Supabase プロジェクトを作成（または既存プロジェクトにテスト用ユーザーを準備）
2. テスト用環境変数（`TEST_SUPABASE_URL`, `TEST_SUPABASE_ANON_KEY`）を GitHub Secrets に登録
3. テスト用管理者ユーザーの認証情報を Secrets に登録

---

## テスト観点（メタテスト）

1. ローカルで `npm run test:e2e` が正常に完了すること
2. CI（GitHub Actions）で PR 作成時に自動実行されること
3. テスト失敗時にスクリーンショット・トレースが保存されること
4. モバイルビューポートでタブ切替（地図/リスト）が正しく動作すること
5. テスト間でデータが干渉しないこと（並列実行で不安定にならない）
