# チェックリスト: Apex安定化リリース受け入れ

## 1. 事前確認

- [ ] 本番環境変数が最新
- [ ] OAuth callback 設定が本番ドメインと一致
- [ ] 監視通知先が有効
- [ ] ロールバック手順が確認済み

## 2. 機能確認（正常系）

- [ ] https://zaridasu.com/ でトップが初回表示される
- [ ] 再訪時に chunk エラーが発生しない
- [ ] offline導線が表示される
- [ ] Retryで復帰可能

## 3. 異常系確認

- [ ] 通信断時にオフライン画面へ遷移
- [ ] 通信復帰後に通常画面へ復帰
- [ ] chunk系失敗時に1回の自動復旧が働く
- [ ] 無限リロードが起きない

## 4. 認証確認

- [ ] apex起点でログイン導線に入れる
- [ ] callbackで失敗しない
- [ ] 認証失敗時に適切なエラーメッセージが出る

## 5. 監視確認

- [ ] chunk失敗イベントが取得できる
- [ ] SW更新失敗ログが取得できる
- [ ] CSP違反レポートが取得できる
- [ ] apex限定エラー率を可視化できる

## 6. 回帰確認

- [ ] 連続デプロイ1回目で問題なし
- [ ] 連続デプロイ2回目で問題なし
- [ ] 問い合わせ件数が通常範囲

## 7. リリース判定

- [ ] Go
- [ ] No-Go（理由記載）
