### REQ-007: 逆ジオコーディング失敗時の通知

**背景**
`useReverseGeocode.js` は Nominatim API の 5 秒タイムアウトを設定しているが、失敗・タイムアウト時にユーザーへの通知がなく、市区町村フィールドが空のまま無言でフォームが続く。

#### ユーザーストーリー

```
As a 投稿者,
I want to 地図をタップして市区町村が自動入力されない場合に理由を知りたい,
So that 手動で市区町村を選択するなど適切に対処できる。

受け入れ条件:
- [ ] 逆ジオコーディング中はローディングインジケーターが表示される
- [ ] タイムアウト・失敗時にインラインメッセージが表示される（「市区町村の自動取得に失敗しました。手動で選択してください。」）
- [ ] 失敗時は市区町村の手動選択フィールドがハイライト（focus）される
- [ ] ネットワークオフライン時は即座に失敗扱いにし、別のメッセージを表示する
- [ ] リトライボタンを表示し、再取得を試みられる
```

#### 機能要件

| # | 要件 | 優先度 |
|---|------|--------|
| F1 | `useReverseGeocode.js` に `error` 状態を追加し、失敗理由を返す | 高 |
| F2 | PostForm で `geocoding === true` の間、市区町村フィールドにスピナーを表示 | 高 |
| F3 | `error` が存在する場合、フィールド下部にインラインメッセージを表示 | 高 |
| F4 | `error` が存在する場合、市区町村選択ドロップダウンに自動フォーカスを当てる | 中 |
| F5 | リトライ関数を `useReverseGeocode` から返し、PostForm でボタン表示 | 中 |
| F6 | `navigator.onLine === false` の場合は Nominatim を呼ばず即座に失敗 | 中 |

#### UI 設計

```
地図タップ後:
  [ジオコーディング中] → 市区町村フィールド: "取得中..." + スピナー
  [成功]             → 市区町村フィールドに自動入力
  [失敗/タイムアウト] → "自動取得に失敗しました [再試行]" + 選択ドロップダウンをフォーカス
  [オフライン]       → "オフラインのため自動取得できません。手動で選択してください。"
```
