## 3. 情報アーキテクチャ

### 3.1 画面遷移フロー

```
■ 依頼者フロー
[ホーム/マップ] → [投稿ボタン(+)] → [PostForm: 情報種別「助っ人募集」選択]
  → [SOS専用フィールド表示: カテゴリ/緊急度/希望日時/募集人数]
  → [投稿] → [承認不要・即時公開] → [マップにSOSピン表示]
  → [応答通知受信] → [コメントで調整] → [解決済みに変更]

■ 協力者フロー
[ホーム/マップ] → [SOSピン(🆘)タップ] → [ポップアップ: 概要+「詳しく見る」]
  → [詳細ページ] → [「協力する」ボタン] → [依頼者に通知]
  → [コメントで日時調整] → [現地で合流]

■ 通知フロー
[SOS投稿INSERT] → [Edge Function: notify-sos]
  → [対象エリアユーザー検索] → [メール送信]
  → [ユーザーがリンクタップ] → [SOS詳細ページ]
```

### 3.2 コンテンツ優先度

| 優先度 | 要素 | 説明 |
|--------|------|------|
| P1（必須） | SOSピンのマップ表示 | 通常ピンと明確に区別されるオレンジ/アンバー色ピン |
| P1（必須） | SOS投稿フォーム | カテゴリ・緊急度・コメント入力 |
| P1（必須） | SOS詳細ページ | 依頼内容 + 協力ボタン + コメント |
| P1（必須） | SOSステータス管理 | 募集中 → 解決済み / 期限切れ |
| P2（重要） | 協力ボタン + 応答者数表示 | ワンタップで参加表明 |
| P2（重要） | メール通知 | 同エリアユーザーへの即時通知 |
| P2（重要） | 自動期限切れ | 7日間で自動クローズ |
| P3（補助） | SOS専用フィルター | FilterBarでSOSのみ絞り込み |
| P3（補助） | 解決実績バッジ | 協力回数に応じたバッジ付与 |
| P3（補助） | Push通知（将来） | ブラウザPush通知対応 |
