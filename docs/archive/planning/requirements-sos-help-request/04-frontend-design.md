## 5. フロントエンド設計

### 5.1 定数追加 (`constants.js`)

```javascript
// INFO_TYPES に追加
{ value: 'sos', label: '助っ人募集', emoji: '🆘' }

// SOS専用定数
export const SOS_CATEGORIES = [
  { value: 'capture_help', label: '捕獲支援', emoji: '🤝', description: '一人では捕獲が難しい' },
  { value: 'survey',       label: '調査協力', emoji: '🔍', description: '広範囲の調査に人手が必要' },
  { value: 'equipment',    label: '機材貸出', emoji: '🧰', description: '罠や網など機材が足りない' },
  { value: 'other',        label: 'その他',   emoji: '💬', description: 'その他の協力依頼' },
]

export const SOS_URGENCY = [
  { value: 'high',   label: '急ぎ',   color: '#DC2626', bgClass: 'bg-red-100 text-red-700' },
  { value: 'medium', label: 'ふつう', color: '#F59E0B', bgClass: 'bg-amber-100 text-amber-700' },
  { value: 'low',    label: 'いつでも', color: '#6B7280', bgClass: 'bg-gray-100 text-gray-600' },
]
```

### 5.2 マップピンデザイン

```
通常ピン:   🔴 赤（アメリカザリガニ）/ 🟢 緑（ウシガエル）
不在確認:   ⚪ グレー丸（✕マーク）
SOSピン:   🟠 オレンジ（🆘マーク）+ パルスアニメーション（募集中のみ）
解決済みSOS: 🔘 グレーオレンジ（アニメなし、半透明）
```

SOSピンはCSS `@keyframes pulse` で外縁がゆっくり明滅し、マップ上で目を引く。
