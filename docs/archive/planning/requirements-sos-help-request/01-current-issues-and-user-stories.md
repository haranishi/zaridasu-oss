## 1. 現状の課題サマリー

- 現在の投稿は「報告完了型」（目撃/捕獲/痕跡/被害/不在確認）のみで、**進行中の状況に対する協力要請**の手段がない
- フィールドで「一人では対処できない」状況に遭遇しても、SNS等の外部ツールに頼るしかない
- 地域の調査協力者とのマッチング手段がなく、調査効率が低い
- マップ上で「今まさに助けが必要な場所」が可視化されていない
- 解決済みのSOSが残り続けると情報が陳腐化するリスクがある

---

## 2. ユーザーストーリー

### US-1: SOSピンの投稿（依頼者）

```
As a フィールド調査ユーザー（認証済み）,
I want to マップ上に助っ人募集ピンを立てて状況を説明したい,
So that 近隣の協力者に来てもらい、一人では難しい捕獲・調査を実現できる.

受け入れ条件:
- [ ] 情報種別「助っ人募集」を選択してSOSピンを作成できる
- [ ] SOSカテゴリ（捕獲支援/調査協力/機材貸出/その他）を選択できる
- [ ] 緊急度（高/中/低）を設定できる
- [ ] 希望日時（任意）を指定できる
- [ ] 募集人数（任意、1〜10人）を指定できる
- [ ] 写真・コメントで現場状況を伝えられる
- [ ] 認証ユーザーのみ投稿可能（匿名不可）
```

### US-2: SOSピンの確認と応答（協力者）

```
As a 近隣の調査ユーザー,
I want to マップ上でSOS依頼を見つけて応答したい,
So that 困っている人を助けに行ける.

受け入れ条件:
- [ ] マップ上でSOSピンが通常ピンと明確に区別できる（色・アイコン）
- [ ] SOSピンをタップすると依頼内容（カテゴリ/緊急度/コメント/写真）が見える
- [ ] 「協力する」ボタンで応答でき、依頼者に通知が届く
- [ ] 応答済みの人数が依頼ピン上に表示される
- [ ] 詳細ページでコメント（相談・調整）ができる
```

### US-3: SOSの解決と終了（依頼者）

```
As a SOS依頼者,
I want to 解決後にSOSステータスを「解決済み」に変更したい,
So that マップ上の情報が最新に保たれ、不要な来訪を防げる.

受け入れ条件:
- [ ] 依頼者が「解決済み」にステータス変更できる
- [ ] 解決済みSOSはマップ上でグレーアウト表示（or 非表示切替）
- [ ] 7日間未解決のSOSは自動的に「期限切れ」になる
- [ ] 解決時に結果コメント（任意）を残せる
```

### US-4: SOS通知（周辺ユーザー）

```
As a 登録済みユーザー,
I want to 自分の活動圏内にSOSが投稿されたらメール通知を受けたい,
So that すぐに駆けつけられる.

受け入れ条件:
- [ ] プロフィールで「SOS通知を受け取る」ON/OFF設定ができる
- [ ] 通知対象: 投稿者の市区町村と同じエリアの登録ユーザー
- [ ] メール通知に場所・カテゴリ・緊急度・マップリンクを含む
- [ ] 緊急度「高」の場合のみ通知する設定も可能
```
