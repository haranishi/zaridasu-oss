# Runbook: Apexドメイン Chunk障害 一次対応

対象: https://zaridasu.com/ で Loading chunk failed が発生した場合

## 1. 初動（5分以内）

1. 影響範囲を確認する
- 対象URL: apexのみか、全ドメインか
- 端末: PC/モバイル
- ブラウザ: Chrome/Safari/Firefox

2. 障害判定を記録する
- 発生時刻
- 発生URL
- エラー文面
- スクリーンショット

3. 一次アナウンスを出す
- 再読み込み
- ブラウザキャッシュ削除
- それでも不可なら問い合わせ誘導

## 2. 技術確認（15分以内）

1. 本番疎通確認
- apexでトップ表示
- offline遷移
- Retryボタン動作

2. 直近デプロイ確認
- 最新Production URL
- 前回との差分

3. ヘッダー確認
- sw.js の no-cache
- CSPの想定値

## 3. 封じ込め

- 条件: apexエラー率が閾値超過
- アクション: 直前安定版へロールバック
- 判断者: 当番 + リード

## 4. ユーザー案内テンプレート

ご不便をおかけして申し訳ありません。\
現在、一部環境で表示不具合を確認しています。\
お手数ですが、以下を順にお試しください。\
1. ページ再読み込み\
2. ブラウザのサイトデータ削除\
3. ブラウザ再起動後に再アクセス\
改善しない場合は、端末/OS/ブラウザ情報を添えてご連絡ください。

## 5. 収束判定

- 30分連続で新規発生なし
- 監視値が通常範囲
- 問い合わせ急増が停止

## 6. 事後対応

- 障害後レビュー様式を起票
- 再発防止アクションをチケット化
- 次回デプロイ前チェックへ反映
