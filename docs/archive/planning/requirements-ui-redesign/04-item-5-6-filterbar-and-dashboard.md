### 5. フィルターバーの簡素化（優先度: 中）

**バイオームの特徴:**
- 検索はメイン画面に目立たず、コンテンツが優先
- フィルタは必要時のみ表示

**ザリダスへの適用:**

**現在:** 検索バー + エリアボタン + フィルターボタンが常時表示
**改善:** 検索アイコンのみ表示 → タップで展開

```
改善前: [🔍 検索... ] [📍] [⚙ 3]    ← 常時3要素
改善後: [🔍]                         ← アイコンのみ
         タップ → フィルターシート展開
```

- 検索アイコンをヘッダー右、または地図上のオーバーレイに配置
- タップでボトムシート型のフィルターパネルが表示
- アクティブフィルター数をアイコンにバッジ表示

### 6. マイページ（Dashboard）のバイオーム風整理（優先度: 低）

**バイオームの特徴:**
- プロフィール情報がコンパクト
- 統計が円形アイコンで直感的
- セクションが明確に分かれている

**ザリダスへの適用:**

現在のDashboardPageの構成を整理:

```
┌──────────────────────────────────────┐
│ 🦞 名前              [編集]          │
│ レベル表示 + 進捗バー                 │
│                                      │
│ [投稿 3] [コメント 5] [活動圏 2]     │  ← 円形 or 角丸アイコン
├──────────────────────────────────────┤
│ 獲得バッジ (横スクロール)             │
│ [🏅][🏅][🏅][  ][  ]               │
├──────────────────────────────────────┤
│ 📝 自分の投稿                        │
│ (投稿カードリスト)                    │
├──────────────────────────────────────┤
│ 📊 全体統計  >                       │
│ 📥 CSVエクスポート  >                 │
└──────────────────────────────────────┘
```

- バッジを横スクロールに変更（現在のグリッドから）
- 統計は円形アイコン+数値のバイオーム風に
- 折りたたみセクションはそのまま維持
