## 改善項目一覧

### 1. ボトムタブナビゲーションの追加（優先度: 高）

**バイオームの特徴:**
- 画面下部に5つのアイコンタブが常時表示
- ホーム / 発見 / カメラ（投稿） / 図鑑 / マイページ
- 中央の投稿ボタンが目立つデザイン

**ザリダスへの適用:**

```
[🗺️ 地図] [📊 統計] [＋ 投稿] [🏆 ランキング] [👤 マイページ]
```

| タブ | アイコン | 遷移先 | 備考 |
|------|---------|--------|------|
| 地図 | Map アイコン | `/` (HomePage) | 現在のメイン画面 |
| 統計 | BarChart アイコン | `/trends` | 現在のTrendsPage |
| 投稿 | Plus (円形・大) | PostForm モーダル | 中央で目立たせる |
| ランキング | Trophy アイコン | `/ranking` | 現在のRankingPage |
| マイページ | User アイコン | `/dashboard` | 未ログイン時はログイン促進 |

**実装仕様:**
- モバイル（`md`未満）のみ表示、デスクトップではヘッダーナビを維持
- `fixed bottom-0` + `safe-area-inset-bottom` 対応
- 現在のページに対応するタブがハイライト（赤色アクティブ）
- 投稿ボタンは他のタブより大きく、円形で浮き出させる
- ボトムタブ分の高さ（約60px + safe-area）を各ページの`padding-bottom`で確保

**削除対象:**
- モバイルの FAB（地図上の投稿ボタン）→ ボトムタブの中央ボタンに統合
- ハンバーガーメニューのメインナビ項目（地図・統計・ランキング・マイページ）→ ボトムタブに移動
- ドロワーは設定系（言語・テーマ・規約等）のみに縮小

### 2. ヘッダーの簡素化（優先度: 高）

**バイオームの特徴:**
- 左: ハンバーガー（設定用）
- 中央: ページタイトル「ホーム」
- 右: 通知ベルアイコン
- 非常にシンプルで余白がある

**ザリダスへの適用:**

**モバイルヘッダー（新）:**
```
[≡ 設定] ───── ページタイトル ───── [🔔 通知]
```

- 左: ドロワーアイコン（設定・言語・テーマ用）
- 中央: 現在のページ名（「地図」「統計」「ランキング」「マイページ」）
- 右: 通知アイコン（将来対応、現時点はテーマ切替ボタン）
- 背景: 白（ライト）/ slate-950（ダーク）、**赤グラデーションを廃止しフラットに**
- 高さ: `h-12`（現在の`h-14`から縮小）
- ロゴ絵文字は不要（ボトムタブで十分にブランド認知）

**デスクトップヘッダー（変更少）:**
- 既存のナビリンク構成を維持
- 言語・テーマ切替をそのまま配置
- ただしヘッダーの高さを`h-12`に統一
