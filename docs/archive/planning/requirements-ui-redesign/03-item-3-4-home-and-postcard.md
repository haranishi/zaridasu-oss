### 3. ホーム画面の再構成（優先度: 中）

**バイオームの特徴:**
- プロフィールカード（アバター・名前・レベル・ポイント・進捗バー）
- 統計アイコン（投稿数・発見種数・提案数・クエスト達成）が円形で並ぶ
- 水平スクロールのクエストカード（写真ベース）

**ザリダスへの適用:**

ホーム画面にログインユーザー向けのミニプロフィールセクションを追加:

```
┌─────────────────────────────────────────────┐
│ 🦞 名無し調査員          投稿 3件 │
│ Lv.1 ━━━━━━━━━━━━━━━━ 次のレベルまで 7投稿  │
│                                             │
│ [📝 投稿数] [🗺️ 活動圏] [🏅 バッジ]       │
│ [   3   ]  [ 2市町村 ]  [  1個  ]          │
└─────────────────────────────────────────────┘
```

- ログイン時のみ地図の上に表示（折りたたみ可能）
- 未ログイン時は既存の `SignupBanner` を表示
- タップでマイページに遷移
- バイオームの円形統計はザリダスでは角丸カード（`rounded-xl`）で代替

**地図/リスト切替:**
- 現在のタブ切替はそのまま維持（ボトムタブの「地図」タブ内のサブ切替として）
- ただしタブのデザインをバイオーム風のピル型セグメントに変更:

```
[ 🗺️ 地図 | 📋 リスト ]  ← rounded-full の切替ボタン
```

### 4. 投稿カード（PostCard）のビジュアル強化（優先度: 中）

**バイオームの特徴:**
- 大きな写真（カード全体の上部を占める）
- カード型レイアウト（角丸の独立したカード）
- 写真の上にオーバーレイでバッジ

**ザリダスへの適用:**

現在の横並び（アイコン + テキスト + 小サムネイル）を**カード型**に変更:

**写真ありの場合:**
```
┌─────────────────────────┐
│ [写真: 横幅100%、h-36] │
│ ───────────────────────  │
│ 🦞 アメリカザリガニ  👁 目撃│
│ 📍 秋田市 · 3月15日       │
│ ✓ AI判定済み             │
└─────────────────────────┘
```

**写真なしの場合:**
```
┌─────────────────────────┐
│ 🦞 アメリカザリガニ  👁 目撃│
│ 📍 秋田市 · 3月15日       │
│ 「田んぼの用水路にて...」   │
└─────────────────────────┘
```

**実装仕様:**
- リスト表示を1カラム → **2カラムグリッド**に変更（モバイル）
- デスクトップサイドバーでは1カラムのまま（幅が狭いため）
- カード間のギャップ: `gap-3`
- 写真: `aspect-[4/3]` で統一、`object-cover`、`rounded-t-xl`
- カード全体: `rounded-xl shadow-sm border` + hover エフェクト
- 種類ごとの左ボーダーは廃止 → カード上部の写真で種類を視覚表現
