## REQ-005: テストカバレッジ拡大

### 現状の課題

```
現在のテスト状況:
  ファイル数:    5 / ~90 ファイル（約5%）
  カバレッジ:    不明（計測なし）
  テストなし:    全 hooks / 認証フロー / API エラー / PostForm バリデーション

リスク:
  - hooks をリファクタリングすると、バグが発生しても検出できない
  - エラーハンドリングの変更（REQ-003）が正しく動くか確認できない
  - 写真アップロードロールバック（REQ-008）の実装正確性が検証できない
```

---

### ユーザーストーリー

```
As a 開発者,
I want to 主要機能に対するテストが存在する状態にしたい,
So that リグレッションを早期に検出でき、安心してリファクタリングできる。

受け入れ条件:
- [ ] 全 hooks に unit test が存在する（usePostForm, useDeletePost, useReverseGeocode）
- [ ] PostForm の全バリデーションにテストが存在する
- [ ] API エラー発生時の挙動がテストされている
- [ ] 認証フロー（AuthModal）の主要パスにテストが存在する
- [ ] `npm run test:coverage` でカバレッジレポートが生成される
- [ ] カバレッジが hooks で 80% 以上、全体で 60% 以上
- [ ] CI でテストが自動実行される
```
