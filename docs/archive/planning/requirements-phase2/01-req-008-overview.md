
## REQ-008: 複数写真アップロード途中失敗処理

### 現状の課題

```
Promise.all で3枚並列アップロード中:
  写真1: ✅ アップロード成功 → Storage に残る
  写真2: ❌ アップロード失敗 → throw error
  写真3: ✅ アップロード成功 → Storage に残る

→ Promise.all が reject されるが、写真1・3は Storage に残ったまま（orphan ファイル）
→ DB への投稿も行われない（整合性なし）
→ ユーザーには「投稿に失敗しました」のみ表示（何枚成功したか不明）
→ 進捗表示がないため、長時間処理で固まって見える
```

---

### ユーザーストーリー

```
As a 投稿者,
I want to 写真のアップロードが失敗したとき、安全に中断されてほしい,
So that 意図しないファイルが残らず、安心して再試行できる。

受け入れ条件:
- [ ] 1枚でもアップロード失敗した場合、成功済みの写真を Storage から自動削除（ロールバック）する
- [ ] 失敗時に「写真のアップロードに失敗しました（3枚中2枚成功）。再試行してください。」と表示する
- [ ] 失敗後も写真の選択状態は維持され、再投稿できる
- [ ] アップロード進捗が分かる（例: 「写真をアップロード中... 2/3」）
- [ ] ネットワーク切断時は即座に失敗し、適切なメッセージを表示する
```
