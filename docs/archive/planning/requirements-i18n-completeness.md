# 要件定義: i18n 未対応コンポーネント修正

## 概要

- **ID**: CQ-006-ext
- **優先度**: 🟠 中（多言語ユーザーへの影響）
- **作成日**: 2026-03-15
- **対象ファイル**: `src/components/features/dashboard/MyPostsSection.jsx`

---

## 問題

`MyPostsSection.jsx` で以下の文字列が日本語にハードコードされている。アプリは ja/en/zh/ko の4言語に対応しているが、これらの文字列は他言語ユーザーには日本語のまま表示される。

| 行 | ハードコード文字列 |
|----|------------------|
| L47 | `自分の投稿一覧` |
| L55 | `まだ投稿がありません。` |
| L56 | `トップページ` |
| L56 | `から投稿してみましょう。` |
| L87 | `詳細` |

---

## 修正方針

1. 各言語ファイル（`src/locales/{ja,en,zh,ko}/translation.json`）に `myPosts` セクションを追加
2. `MyPostsSection.jsx` で `useTranslation()` を使い、ハードコード文字列を `t('myPosts.*')` に置換

### 追加する翻訳キー

```json
"myPosts": {
  "title": "自分の投稿一覧",
  "empty": "まだ投稿がありません",
  "emptyAction": "{{link}}から投稿してみましょう。",
  "topPage": "トップページ",
  "detail": "詳細"
}
```

---

## テスト観点

- 英語ロケールで `MyPostsSection` を表示した場合に英語テキストが表示されること
- 投稿がない状態でリンクが正しく機能すること
