## 6. テスト観点

### 手動テスト
- [ ] パスワードリセットメール送信 → リンククリック → パスワード設定画面が表示される
- [ ] 新パスワード入力 → 更新成功 → ダッシュボードにリダイレクトされる
- [ ] 期限切れリンク → エラーメッセージが表示される
- [ ] 新規登録メール確認フロー → 既存の動作が壊れていない
- [ ] 通常のログインフロー → 既存の動作が壊れていない

### エッジケース
- [ ] 同じリンクを2回クリック → 適切なエラー表示
- [ ] ブラウザの戻るボタン → 意図しない動作がない
- [ ] モバイルブラウザでのリンクオープン
