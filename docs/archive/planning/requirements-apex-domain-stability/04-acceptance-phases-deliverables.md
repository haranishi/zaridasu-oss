## 7. 受け入れ基準

- apex直アクセスで正常表示できる。
- デプロイ後の既存タブ再訪でも chunk エラーで詰まらない。
- オフライン遷移と復帰が成立する。
- OAuth callback が apex 起点でも失敗しない。
- 連続2回の本番デプロイで回帰しない。

## 8. 実行フェーズ

1. Phase A: 即日復旧（告知・一次対応・封じ込め）
2. Phase B: 恒久対策（SW・ドメイン・CSP・認証）
3. Phase C: 受け入れ検証（E2E・手動）
4. Phase D: 監視運用（閾値・通知・レビュー）
