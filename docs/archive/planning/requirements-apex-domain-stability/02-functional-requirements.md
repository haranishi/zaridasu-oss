## 4. 機能要件

### FR-01 即日復旧導線

- 障害時に、ユーザー向けに再読み込み・キャッシュクリア手順を即時提示できること。
- 問い合わせ一次回答テンプレートを運用チームが使用できること。

### FR-02 SWキャッシュ整合

- HTML遷移は network-first を原則とする。
- offline フォールバックは静的資産で成立すること。
- デプロイ後に stale chunk 参照を残さないこと。

### FR-03 自己回復

- chunk系エラー発生時、1回だけ自動リロードを許可する。
- 復旧しない場合は明示的な回復手順を表示する。

### FR-04 ドメイン正規化

- apex と正規URLの運用方針を単一化する。
- metadata / canonical / runtime origin の不整合を許容しない。

### FR-05 認証整合

- OAuth callback URL が許可済みリストと一致すること。
- 環境変数と認証基盤設定の同期責任を明確にする。
