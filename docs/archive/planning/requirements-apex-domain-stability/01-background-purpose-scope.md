## 1. 背景

- 本番運用中、apexドメイン（zaridasu.com）でのみ Loading chunk failed が発生する。
- 同一リリースでも別URLでは再現しないため、ドメイン・キャッシュ・SW更新タイミングの複合要因が疑われる。
- 利用者影響は「初回表示不能」「再試行で復帰しない」「離脱増加」。

## 2. 目的

- 即日でユーザー影響を最小化する運用要件を定義する。
- 再発を防止する恒久対策要件を定義する。
- 障害検知から復旧判断までを標準化する。

## 3. スコープ

### 3.1 対象

- apexドメインでの画面表示失敗
- Service Worker 更新・キャッシュ整合
- オフラインフォールバックの安定化
- CSP / OAuth callback のドメイン整合
- 監視・運用フロー

### 3.2 対象外

- 新規機能追加
- UI全面刷新
- SEO全体改善
