# テスト環境 i18n 安定化 要件定義

## 1. 概要
- 対象課題: テスト時の i18next インスタンス未初期化警告
- 優先度: 中
- 作成日: 2026-03-14

## 2. 背景
一部テストで `NO_I18NEXT_INSTANCE` 警告が出ており、将来的なテスト不安定化や誤検知の原因となる。テストが通過していても、環境依存で失敗するリスクが残る。

## 3. 目的
- i18n 依存コンポーネントを安定してテストできる基盤を整える
- 警告をゼロにし、ノイズのないテストログにする

## 4. スコープ
### 対象
- `src/test/setup.js` の初期化
- i18n 依存ページのテスト（TrendsPage など）
- テスト専用 i18n インスタンスまたはモック

### 非対象
- 文言翻訳の追加
- 多言語 UX 改修

## 5. ユーザーストーリー
As a 開発者,
I want to i18n 警告なしでテストを実行したい,
So that 真の失敗のみを素早く判別できる。

## 6. 受け入れ条件
- [ ] `NO_I18NEXT_INSTANCE` 警告が発生しない
- [ ] i18n 依存コンポーネントのテストがローカル/CI で安定実行できる
- [ ] テスト用初期化処理が共通化される

## 7. 機能要件
| ID | 要件 | 優先度 |
|---|---|---|
| F1 | テスト実行前に i18next を初期化する setup を追加する | 高 |
| F2 | `useTranslation` 利用コンポーネントのテストヘルパを共通化する | 高 |
| F3 | i18n 初期化を伴う最小回帰テストを追加する | 中 |

## 8. 非機能要件
- テスト実行速度を悪化させない
- 本番 i18n 設定と乖離しない

## 9. 実装方針
- setup ファイルで単一インスタンスを初期化
- テストごとに状態を初期化して相互干渉を防ぐ

## 10. テスト観点
- 翻訳キー表示の正否
- 初期言語切替時の描画
- 警告ログ未出力

## 11. 完了定義
- 警告ゼロで `npm run test:coverage` が完走
- i18n 依存テストが CI で安定稼働
