## 機能要件

### F1: カード型レイアウト（審査待ちタブ）

現在の**テーブル行形式**を**カード型レイアウト**に変更する。

**カードの構成（1投稿あたり）**:

```
┌──────────────────────────────────────────────────────────────────┐
│ ☐  3/20 07:50  由利本荘市            🟡 審査待ち               │ ← ヘッダー行
├────────────────────┬─────────────────────────────────────────────┤
│                    │  種類: 🦞 ウシガエル                        │
│   [  写真プレ     │  種別: 目撃                                 │
│    ビュー         │  個体数: 3                                   │
│   160×120px  ]    │  観察日: 2026-03-19                          │
│                    │  天気: ☀️ 晴れ  気温: 15°C                   │
│   [写真2] [写真3] │                                              │
│                    │  コメント:                                   │
├────────────────────┤  ウシガエルではありませんがAI判定どうので    │
│  🤖 AI判定        │  すか？実際に捕獲して確認しました。          │
│  検出種: ウシガエル│                                              │
│  信頼度: ██████ 87%│                                              │
│  画質: 鮮明       ├─────────────────────────────────────────────┤
│  一致: ✅ 一致     │  📍 位置情報                                │
│  適切性: 問題なし  │  ┌─────────────────────┐                    │
│                    │  │   ミニマップ          │                    │
│  📝 AIメモ:       │  │   (Leaflet 200×150px) │                    │
│  体色が緑褐色で…  │  │                       │                    │
│                    │  └─────────────────────┘                    │
├────────────────────┴─────────────────────────────────────────────┤
│  [✅ 承認する]              [❌ 却下する]              [🗑 削除]  │ ← アクションバー
└──────────────────────────────────────────────────────────────────┘
```

**テキストサイズ指針**:

| 要素 | 現状 | 改善後 |
|------|------|--------|
| ヘッダー（日付・市区町村） | `text-sm`（14px） | `text-base`（16px）`font-semibold` |
| 種類・種別ラベル | `text-sm`（14px） | `text-base`（16px） |
| コメント本文 | `text-sm truncate`（14px・省略） | `text-sm`（14px）**折り返し・全文表示** |
| AI判定ラベル | `text-xs`（12px）ポップアップ内 | `text-sm`（14px）カード上に常時表示 |
| アクションボタン | `text-xs`（12px） | `text-sm`（14px）`py-2 px-4` |

### F2: 写真プレビュー拡大

| 項目 | 現状 | 改善後 |
|------|------|--------|
| サムネイルサイズ | `w-8 h-8`（32×32px） | `w-40 h-30`（160×120px）メイン写真 |
| 追加写真 | 3枚まで `w-8 h-8` | 2~3枚目は `w-16 h-12`（64×48px）でメインの下に |
| クリック時 | `PhotoModal`（単一画像） | `PhotoViewer`（左右ナビ・全画面ギャラリー） |

### F3: AI判定結果の常時表示

現在のポップアップ（`AIBadge` の `open` ステート）を廃止し、カード内に常時展開する。

**表示項目**:

| 項目 | 表示 | 条件付き色分け |
|------|------|------------|
| 検出種 | `アメリカザリガニ` / `ウシガエル` / `その他` / `不明` | — |
| 申告との一致 | `✅ 一致` / `❌ 不一致` / `不明` | 緑 / 赤 / グレー |
| 信頼度 | プログレスバー + `87%` | ≥70% 緑 / ≥50% 黄 / <50% 赤 |
| 画質 | `鮮明` / `普通` / `不鮮明` | — |
| 適切性 | `問題なし` / `⚠️ 要注意` | 緑 / 赤 |
| AIメモ | 全文表示（`ai.notes`） | — |

### F4: ミニマップ（位置情報確認）

- 各カードに静的な Leaflet ミニマップ（200×150px）を表示
- 投稿の座標にマーカーを配置
- ズームレベル: 13（市区町村レベルの確認に十分）
- **操作不可**（ドラッグ・ズーム無効）で審査の邪魔にならないように
- クリックで拡大マップモーダル表示（操作可能）

**パフォーマンス考慮**:
- `IntersectionObserver` で画面内に入った時のみ地図を描画（遅延読み込み）
- 審査待ちタブのみミニマップ表示（公開中・却下済みでは非表示）
