## 画面遷移・ユーザーフロー

### 審査フロー（改善後）

```
[管理者: /admin/posts（審査待ちタブ）]
        │
        ├── カードで投稿を確認（写真・AI判定・コメント・地図を一目で把握）
        │
        ├── [承認する] → 即座に承認 → カードがフェードアウト → 「承認しました」トースト
        │
        ├── [却下する] → RejectDialog → 理由選択 → 却下完了 → カードがフェードアウト
        │
        ├── [写真クリック] → PhotoViewer（全画面ギャラリー）→ 閉じる → カードに戻る
        │
        ├── [ミニマップクリック] → 拡大マップモーダル（操作可能）→ 閉じる
        │
        └── [チェックボックス複数選択] → フローティングバー表示
              ├── [一括承認] → 確認ダイアログ → 全件承認
              └── [一括削除] → 確認ダイアログ → 全件削除
```

### 公開中/却下済みタブ（変更最小限）

```
[管理者: /admin/posts（公開中タブ）]
        │
        └── テーブル形式を維持（フォントサイズ拡大 + 写真サムネイル拡大のみ）
```

## コンテンツ優先度（カード内）

| 優先度 | コンテンツ | 理由 |
|--------|----------|------|
| P1（必須） | 写真プレビュー | 種別確認の最重要情報 |
| P1（必須） | AI判定結果（信頼度・一致/不一致） | 承認判断の主要根拠 |
| P1（必須） | 承認/却下ボタン | 主要アクション |
| P2（重要） | 種類・種別・市区町村 | 投稿の基本情報 |
| P2（重要） | コメント全文 | 投稿者の補足情報 |
| P2（重要） | ミニマップ | 位置の妥当性確認 |
| P3（補助） | 個体数・観察日・天気 | 詳細データ |
| P3（補助） | 投稿日時 | 参考情報 |

## テスト観点

1. 審査待ちタブでカード型レイアウトが表示されること
2. 公開中・却下済み・全件タブはテーブル形式のままであること
3. 写真クリックで PhotoViewer が開き、複数枚のナビゲーションができること
4. AI判定の信頼度バー・検出種・一致/不一致がカード上に常時表示されること
5. コメントが全文表示され、途中で切れないこと
6. ミニマップが正しい座標にマーカーを表示すること
7. ミニマップが画面外のカードでは描画されないこと（遅延読み込み）
8. モバイル（375px幅）でカードが縦スタックで操作可能なこと
9. 承認ボタン押下後にカードがフェードアウトし、トースト通知が出ること
10. 一括承認・一括削除が正しく動作すること
