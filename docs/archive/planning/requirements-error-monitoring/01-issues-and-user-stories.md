## 現状の課題

1. `logError()` は開発環境（`import.meta.env.DEV`）でのみ `console.error` を出力し、**本番では何も記録されない**
2. `ErrorBoundary` がレンダリングエラーを捕捉するが、**外部へ送信されない**
3. 非同期エラー（API呼び出し失敗、画像アップロード失敗等）の発生頻度・パターンが把握できない
4. ユーザーからの「動かない」報告を受けても再現・原因特定の手がかりがない

---

## ユーザーストーリー

| 対象ユーザー | やりたいこと | 理由 |
|------------|------------|------|
| 開発者/運用者 | 本番で発生したエラーをリアルタイムに把握したい | ユーザー報告を待たず能動的に問題を検知・修正できる |
| 開発者 | エラーの発生頻度・影響範囲をダッシュボードで確認したい | 優先度の高いバグに集中的にリソースを割ける |
| 開発者 | エラー発生時のユーザー操作コンテキスト（ブラウザ、OS、画面）を知りたい | 再現手順の推測が容易になり修正が速くなる |
| 管理者 | 重大なエラーが発生したら即座に通知を受けたい | サービス障害の対応時間を短縮できる |
