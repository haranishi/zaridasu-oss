## 画面遷移・ユーザーフロー

### 通知購読フロー

```
[ダッシュボード /dashboard]
   └── [PushNotificationCard]
          │
          ├── [非対応環境] → グレーアウト + 理由メッセージ表示
          │
          └── [対応環境] → 「通知を受け取る」トグル
                │
                ├── ON → ブラウザ許可ダイアログ
                │     ├── 許可 → 購読成功 → フィルタ設定 UI 展開
                │     ├── 拒否 → エラーメッセージ + 設定手順
                │     └── 閉じた → トグル OFF に戻す
                │
                └── OFF → 購読解除 → 「通知を再び受け取れます」メッセージ
```

### 通知受信フロー

```
[ユーザーA: 投稿を作成]
        ↓
[管理者: 投稿を承認（status → approved）]
        ↓ Database Webhook
[send-push Edge Function]
        ↓ フィルタマッチング
[ユーザーB: フィルタ条件に合致]
        ↓ Web Push
[スマホ通知: 「🦞 秋田市で新しい目撃情報」]
        ↓ タップ
[アプリ起動 → /post/{id} 詳細ページ表示]
```
