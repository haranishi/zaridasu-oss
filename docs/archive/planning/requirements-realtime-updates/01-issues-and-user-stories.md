
## 現状の課題

1. 投稿一覧は**初回ロード + フィルタ変更時のみ**取得（`usePostList`）。新しい投稿が反映されるにはリロードが必要
2. 他ユーザーの投稿承認・新規投稿が地図にリアルタイムで反映されない
3. 詳細ページのコメント・いいねもリアルタイム反映されない（投稿者がページを開いたまま待っても更新されない）
4. 管理画面の投稿一覧も手動リロードが必要（承認待ち件数がリアルタイムで分からない）

---

## ユーザーストーリー

| 対象ユーザー | やりたいこと | 理由 |
|------------|------------|------|
| 地図を見ている住民 | 新しい目撃情報が投稿・承認されたら地図に自動で表示されてほしい | 常に最新の分布状況を把握できる |
| 投稿の詳細を見ている人 | 他の人がコメントしたらリアルタイムで表示されてほしい | ページをリロードしなくても会話が追える |
| 管理者 | 新しい承認待ち投稿が来たら件数がリアルタイムで更新されてほしい | 承認作業の見落としを防げる |
| 投稿者 | 自分の投稿が承認/拒否されたらすぐに分かりたい | 結果を確認するために何度もリロードしなくて済む |
