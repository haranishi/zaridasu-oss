## 画面遷移・ユーザーフロー

### トップページ（リアルタイム更新）

```
[ユーザーA: 投稿を作成]
        ↓
[管理者: /admin/posts で承認]
        ↓ Supabase Realtime (posts UPDATE: status → approved)
[ユーザーB: トップページを開いたまま]
        ↓
[「新しい投稿があります」バナー表示]
        ↓ タップ
[投稿リスト先頭に新投稿が追加 + 地図にマーカー出現（アニメーション付き）]
```

### 詳細ページ（コメントリアルタイム）

```
[ユーザーA: /post/123 を閲覧中]
        ↓
[ユーザーB: 同じ投稿にコメント投稿]
        ↓ Supabase Realtime (comments INSERT)
[ユーザーA: コメント一覧末尾に新コメントがフェードイン]
```

### 管理画面（バッジ更新）

```
[管理者: /admin を開いたまま]
        ↓
[一般ユーザーが投稿を作成]
        ↓ Supabase Realtime (posts INSERT: status=pending)
[サイドバー「投稿管理」のバッジ: 5 → 6 に更新]
```
