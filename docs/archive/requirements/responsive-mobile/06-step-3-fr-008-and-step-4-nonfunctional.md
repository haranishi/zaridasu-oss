### FR-008: ダークモード コントラスト改善
- **説明:** ダークモード時のテキスト・ボーダー・背景のコントラスト比を改善
- **基準:** WCAG 2.1 AA（通常テキスト4.5:1、大テキスト3:1）
- **問題箇所:**
  | テキスト色 | 背景色 | コントラスト比 | 判定 |
  |-----------|--------|-------------|------|
  | `text-slate-400` (#94a3b8) | `bg-slate-900` (#0f172a) | 5.1:1 | ✅ OK |
  | `text-slate-500` (#64748b) | `bg-slate-900` (#0f172a) | 3.8:1 | ⚠️ 不足 |
  | `text-slate-500` (#64748b) | `bg-slate-950` (#020617) | 3.5:1 | ⚠️ 不足 |
  | `border-slate-700/60` | - | 透過でコントラスト低下 | ⚠️ |
- **改善:**
  - `faint(dark)` の `text-slate-500` → `text-slate-400` に変更
  - ボーダー透過度: `/60` → `/80` に上げる

## Step 4: 非機能要件

### パフォーマンス
- **レスポンスタイム:** 画面切替 300ms 以下（タブ切替含む）
- **レンダリング:** 60fps 維持（スクロール、アニメーション）
- **初回ロード:** LCP 2.5秒以下（モバイル3G環境）
- **画像:** Next.js `Image` コンポーネントで自動最適化
- **スケルトン表示:** データ取得中は即座にスケルトン表示（白画面を避ける）

### セキュリティ
- 変更なし（レスポンシブ改善はフロントエンドのみ）

### 可用性・信頼性
- **オフライン:** Service Worker でオフラインページ表示
- **エラー時:** ErrorBoundary でクラッシュ防止
- **ハイドレーションエラー:** SSR/CSR 一致を保証（`mounted` パターン使用）

### アクセシビリティ
- **WCAG 2.1 AA 準拠項目:**
  - コントラスト比 4.5:1 以上（通常テキスト）
  - タッチターゲット 44px×44px 以上
  - フォーカスインジケーター（`:focus-visible`）
  - スクリーンリーダー対応（`aria-label`, `aria-expanded`）
  - キーボードナビゲーション（フォーカストラップ）
  - スキップリンク（`#main-content`）✅ 実装済み
  - 画像の代替テキスト（`alt` 属性）

### レスポンシブ対応
- **対応ブレークポイント:**
  | ブレークポイント | 幅 | 主な対象デバイス |
  |---|---|---|
  | デフォルト | 0〜374px | 小型スマホ |
  | xs | 375px〜 | iPhone SE |
  | sm | 640px〜 | 大型スマホ・小型タブレット |
  | md | 768px〜 | タブレット |
  | lg | 1024px〜 | ノートPC |
  | xl | 1280px〜 | デスクトップ |

- **モバイルファースト設計方針:**
  - デフォルトスタイル = モバイル
  - `sm:` / `md:` / `lg:` で上位ブレークポイントのスタイルを追加
  - レイアウト: モバイルで縦積み → タブレット以上で横並び
  - テーブル: モバイルでカード → タブレット以上でテーブル
  - ナビ: モバイルでボトムタブ → PCでサイドバーまたはヘッダーナビ
