## Step 5: 画面仕様

### SC-001: ホーム画面（地図/リスト）
- **URL:** `/`
- **用途:** メインの地図表示とリスト表示の切替
- **レイアウト:**
  ```
  モバイル:                    PC:
  +---------------------------+  +---------------------------+
  | Header (h-12)             |  | Header (h-12, ナビ表示)    |
  +---------------------------+  +---------------------------+
  | StatsBar (横スクロール)     |  | StatsBar | FilterBar      |
  +---------------------------+  +---------------------------+
  | FilterBar                 |  | Map / List (flex-1)       |
  +---------------------------+  +---------------------------+
  | Map or List (flex-1)      |
  +---------------------------+
  | BottomNav (h-14+safe)     |
  +---------------------------+
  ```
- **コンポーネント:**
  | コンポーネント | モバイル | PC |
  |---|---|---|
  | Header | ハンバーガー + タイトル + テーマ切替 | ロゴ + ナビ + 言語 + テーマ + ユーザーメニュー |
  | StatsBar | 横スクロール (`overflow-x-auto scrollbar-hide`) | 1行表示 |
  | FilterBar | 縦積みフィルター | 横並びフィルター |
  | MapView | 全幅・全高 | 全幅・全高 |
  | PostList | 1列(〜399px)/2列(400px+) | 1列 |
  | BottomNav | 5タブ表示 | 非表示 (`md:hidden`) |
- **ステータス:** ✅ 良好
