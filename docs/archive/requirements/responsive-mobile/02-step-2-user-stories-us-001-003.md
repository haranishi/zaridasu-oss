## Step 2: ユーザーストーリー

### US-001: モバイルでの管理画面テーブル閲覧
**As a** 管理者（スマホ使用時）,
**I want to** 投稿一覧・コメント一覧・ユーザー一覧・ログ一覧をカード形式で見たい,
**So that** 外出先からでもモデレーション作業ができる.

**受け入れ条件:**
- [x] AC-1: `md:` 未満ではテーブルの代わりにカード形式で表示される
- [x] AC-2: カードには最低限の情報（日時、種別、内容の要約）が表示される
- [x] AC-3: カードからアクション（承認/却下/削除）を直接実行できる
- [x] AC-4: タッチターゲットは44px以上
- [x] AC-5: 全カードで一貫したデザインパターン

**優先度:** 高
**見積もり:** M
**ステータス:** ✅ 完了（AdminPostsPage, AdminCommentsPage, AdminUsersPage, AdminLogsPage 全て対応済み）

### US-002: スマホでのフォーム入力体験
**As a** 一般ユーザー（スマホ使用時）,
**I want to** ストレスなく投稿フォームに入力したい,
**So that** 野外で素早く投稿できる.

**受け入れ条件:**
- [x] AC-1: フォームがボトムシート形式で開く（`rounded-t-2xl md:rounded-2xl`）
- [x] AC-2: 地図の高さが `h-56 sm:h-64` でレスポンシブ
- [ ] AC-3: ランドスケープモードでフォームが適切に表示される（`landscape:max-h-[98dvh]`対応済みだが追加検証必要）
- [ ] AC-4: 仮想キーボード表示時にフォームがスクロール可能
- [x] AC-5: 写真プレビューがモバイルで見やすいサイズ

**優先度:** 高
**見積もり:** S
