## Step 1: 要件概要

### 背景・目的
- ザリガニダスは秋田県の外来生物（アメリカザリガニ・ウシガエル）の出没・分布情報を市民が投稿・閲覧するWebアプリ
- **現場での利用が主体**：野外で発見した際にスマホから投稿する利用シーンが最も多い
- 現状、管理画面のモーダルやナビゲーションなど、**モバイルで操作困難な箇所**が残存
- ホーム画面（地図＋リスト）は概ね良好だが、細部のタッチ操作性・文字サイズ・余白に改善余地がある
- **解決したい課題：**
  1. 管理画面のモーダル（UserDetailModal等）がモバイルで窮屈
  2. 管理画面ボトムナビが8項目で窮屈
  3. タッチターゲットが44px未満の箇所がある
  4. フォント・余白のスマホ最適化が不十分
  5. ダークモード時のコントラスト不足箇所がある

### スコープ
**今回対象とする範囲：**
- 全画面のモバイル（375px〜）・タブレット（768px〜）・PC（1024px〜）レスポンシブ対応
- タッチターゲット44px以上の保証
- セーフエリア（ノッチ・ホームバー）対応の統一
- ローディング・空状態・エラー状態のモバイル表示
- モーダル・ダイアログのモバイル最適化
- 管理画面ボトムナビの改善

**対象外（明示的に除外）：**
- 新機能追加（レスポンシブ改善に直接関係ないもの）
- バックエンド/DB変更
- PWAオフライン機能の改善
- デスクトップ専用の新レイアウト

### 前提条件・制約
- **技術スタック:** Next.js 15 + React 19 + TypeScript + Tailwind CSS 3
- **ブレークポイント:** xs(375px), sm(640px), md(768px), lg(1024px), xl(1280px)
- **モバイルファースト:** デフォルトスタイルはモバイル、`sm:`/`md:` で上書き
- **既存パターン遵守:** `cardCls()`, `pageBg()`, `faint()` 等のテーマユーティリティ
- **地図ライブラリ:** Leaflet（タッチ操作はライブラリ側で対応済み）
- **アクセシビリティ:** WCAG 2.1 AA準拠（コントラスト比4.5:1以上）
