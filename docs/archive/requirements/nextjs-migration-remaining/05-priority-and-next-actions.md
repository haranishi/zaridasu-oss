## 実行優先度と依存関係

```
Phase A (クリーンアップ)  ←── 最優先・他の Phase に依存なし
    ↓
Phase B (TypeScript)     ←── Phase A 完了後
    ↓
Phase C (テスト)         ←── Phase B 完了後
    ↓
Phase D (PWA)            ←── Phase A 完了後（B と並行可）
```

| Phase | 優先度 | ファイル数 | 推定工数 |
|-------|--------|-----------|---------|
| **A: クリーンアップ** | P1 | ~10 削除 + 85 修正 | S |
| **B: TypeScript** | P1 | 85 JSX + 28 JS | XL |
| **C: テスト修正** | P2 | 6 テスト + 2 設定 | M |
| **D: PWA** | P2 | 3 設定 | M |

---

## 次のアクション

1. **Phase A を即時実行** — Vite 旧コード削除 → ESLint 修正 → ビルド確認
2. **Phase B を段階実行** — B-1〜B-3（基盤）→ B-4〜B-10（コンポーネント）→ B-11（ビュー）
3. **Phase C・D を並行実行** — テスト修正と PWA 対応
