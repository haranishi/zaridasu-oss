## 非機能要件

### パフォーマンス
- 無限スクロール: DOM要素数500件以下を維持
- ObjectURL: 写真変更ごとに旧URLを即座にrevoke
- アイコンキャッシュ: 実質10エントリ以下（種類×infoType）

### セキュリティ
- Admin認可: middleware（サーバーサイド）で `app_metadata.role` を検証
- 環境変数: 秘密情報はgit管理外、`NEXT_PUBLIC_` プレフィックスで公開可否を制御
- XSS: React + i18next の標準エスケープに依存（`escapeValue: false` はReact環境では安全）
- RLS: 既存の Supabase RLS ポリシーを維持

### アクセシビリティ
- WCAG 2.1 AA 準拠:
  - 画像に意味のあるalt属性
  - モーダルにフォーカストラップ
  - `aria-modal="true"` + `aria-labelledby`
  - Escapeキーでモーダル閉じ

### 可用性
- オフライン時: ジオコーディング・天気取得失敗を明示し、手動入力へフォールバック
- API失敗時: エラーメッセージ + リトライ手段を提供
