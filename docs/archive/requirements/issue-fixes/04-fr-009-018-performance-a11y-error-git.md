### FR-009: ObjectURL メモリリーク修正
- **説明:** `usePostForm` で写真変更時に旧 ObjectURL が revoke されない
- **現状コード:** cleanup が unmount 時のみ実行
- **処理:**
  1. `photoPreviews` 変更時に旧URLを `URL.revokeObjectURL()` で解放
  2. unmount 時にも最終的な cleanup を実行
- **バリデーション:** DevTools の Memory タブでリークがないこと

### FR-010: 無限スクロール上限の追加
- **説明:** `usePostList` で DOM 要素数が無制限に増加する問題
- **処理:**
  1. 表示上限（例: 500件）を設定
  2. 上限到達時に「さらに読み込む」ボタンに切り替え
  3. 既存の `QUERY_LIMIT_POSTS = 2000` はDB側制限として維持
- **バリデーション:** 500件以上の投稿がある場合に上限メッセージが表示されること

### FR-011: アイコンキャッシュのクリーンアップ
- **説明:** `MapView.tsx` のモジュールレベルアイコンキャッシュが無制限に成長
- **処理:**
  1. キャッシュサイズの上限を設定（例: 100エントリ）
  2. 上限到達時に古いエントリを削除（LRU方式）
- **備考:** 現実的にはキャッシュエントリ数は種類数 × infoType数 で限定的（最大10程度）なので、実害は軽微。対応優先度は低い。

### FR-012: 画像alt属性の追加
