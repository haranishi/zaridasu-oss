## ユーザーストーリー

### US-001: セキュリティ基盤の強化
**As a** システム管理者,
**I want to** APIキーの露出を防ぎ、Admin権限をサーバーサイドで検証したい,
**So that** 不正アクセスやAPIキー悪用を防止できる.

**受け入れ条件:**
- [ ] AC-1: `.env` / `.env.local` がgit履歴に含まれないこと
- [ ] AC-2: `/admin/*` へのアクセスがmiddlewareでroleチェックされること
- [ ] AC-3: Google Analytics IDが環境変数から読み込まれること
- [ ] AC-4: i18nのescapeValueがtrueであること

**優先度:** 高
**見積もり:** M

---

### US-002: ビルド・テスト環境の復旧
**As a** 開発者,
**I want to** `next build` と `vitest run` が正常に通る状態にしたい,
**So that** CI/CDパイプラインが正常動作し、安全にデプロイできる.

**受け入れ条件:**
- [ ] AC-1: `next build` がエラーなく完了すること
- [ ] AC-2: 全テストがパスすること
- [ ] AC-3: `tsc --noEmit` がエラー0件であること
- [ ] AC-4: ESLintにNext.jsプラグインが含まれること

**優先度:** 高
**見積もり:** L

---

### US-003: パフォーマンスの改善
**As a** エンドユーザー,
**I want to** 長時間使用してもアプリが重くならないようにしたい,
**So that** 快適にマップ閲覧・投稿ができる.

**受け入れ条件:**
- [ ] AC-1: 写真変更時にObjectURLが適切にrevokeされること
- [ ] AC-2: 無限スクロールにDOM要素数の上限があること
- [ ] AC-3: アイコンキャッシュに上限・クリーンアップがあること

**優先度:** 中
**見積もり:** M

---

### US-004: アクセシビリティの改善
**As a** スクリーンリーダー利用者,
**I want to** 画像やモーダルが適切にアナウンスされるようにしたい,
**So that** 視覚障害があってもアプリを利用できる.

**受け入れ条件:**
- [ ] AC-1: 種の画像に適切なalt属性があること
- [ ] AC-2: モーダルにフォーカストラップとaria属性があること

**優先度:** 中
**見積もり:** M

---

### US-005: エラーハンドリングの改善
**As a** エンドユーザー,
**I want to** エラー発生時に原因と対処法がわかるようにしたい,
**So that** 問題が起きても適切に対応できる.

**受け入れ条件:**
- [ ] AC-1: 逆ジオコーディング失敗時にリトライUIが表示されること
- [ ] AC-2: 天気API失敗時にユーザーへ通知されること
- [ ] AC-3: 位置情報タイムアウトと拒否で異なるメッセージが表示されること

**優先度:** 中
**見積もり:** S

---

### US-006: Git管理の正常化
**As a** 開発者,
**I want to** 移行済みファイルがコミットされ、旧設定が除去された状態にしたい,
**So that** クリーンなコードベースで開発を継続できる.

**受け入れ条件:**
- [ ] AC-1: TSXファイルが全てコミット済みであること
- [ ] AC-2: 旧JSXファイルの削除がコミット済みであること
- [ ] AC-3: Vite関連の不要設定が除去されていること

**優先度:** 高
**見積もり:** S
