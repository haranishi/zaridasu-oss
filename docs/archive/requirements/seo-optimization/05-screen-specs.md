## 画面仕様

### SC-001: 地域別ランディングページ (`/area/[municipality]`)
- **URL:** `/area/akita-shi`, `/area/yokote-shi` 等
- **用途:** 市区町村ごとの外来生物情報を集約表示

**レイアウト:**
```
+------------------------------------------+
| ヘッダー（グローバルナビ）                  |
+------------------------------------------+
| パンくず: ホーム > 地域別 > {市区町村名}     |
+------------------------------------------+
| H1: {市区町村名}の外来生物情報              |
| 概要テキスト（投稿数・最終更新日）           |
+------------------------------------------+
| 地図（該当地域にズーム）                    |
+------------------------------------------+
| 種別フィルター                             |
| [アメリカザリガニ] [ウシガエル] ...          |
+------------------------------------------+
| 投稿一覧（カード形式）                     |
| +--------+ +--------+ +--------+         |
| | 投稿1  | | 投稿2  | | 投稿3  |         |
| +--------+ +--------+ +--------+         |
+------------------------------------------+
| 関連地域リンク                             |
| 隣接する市区町村へのリンク                  |
+------------------------------------------+
| フッター                                  |
+------------------------------------------+
```

- **コンポーネント一覧:**

| コンポーネント | 説明 | 状態 |
|---------------|------|------|
| Breadcrumb | パンくずナビ | 新規 |
| AreaHeader | 地域情報ヘッダー | 新規 |
| AreaMap | 地域絞り込み地図 | 新規（MapView 拡張） |
| SpeciesFilter | 種別フィルター | 既存流用 |
| PostCardGrid | 投稿カードグリッド | 既存流用 |
| RelatedAreas | 関連地域リンク | 新規 |

- **画面遷移:**
  - 種別クリック → SC-002 (`/area/[municipality]/[species]`)
  - 投稿カードクリック → 投稿詳細ページ (`/post/[id]`)
  - パンくず → 各階層ページ

### SC-002: 地域×種別 詳細ページ (`/area/[municipality]/[species]`)
- **URL:** `/area/akita-shi/american` 等
- **用途:** 特定地域×種別の詳細情報

**レイアウト:**
```
+------------------------------------------+
| ヘッダー                                  |
+------------------------------------------+
| パンくず: ホーム > 地域別 > {市区町村}       |
|          > {種別名}                       |
+------------------------------------------+
| H1: {市区町村名}の{種別名}情報             |
| 統計: 目撃{N}件 / 捕獲{N}件              |
+------------------------------------------+
| 分布地図                                  |
+------------------------------------------+
| 月別推移グラフ                             |
+------------------------------------------+
| 投稿一覧                                  |
+------------------------------------------+
| 関連リンク（同地域の他種別、同種別の他地域）  |
+------------------------------------------+
| フッター                                  |
+------------------------------------------+
```
