## 機能要件

### FR-001: 地域×種別 ランディングページ生成
- **説明:** 市区町村×外来生物種別の組み合わせで静的ランディングページを自動生成し、ロングテールキーワードを獲得する
- **入力:** Supabase の投稿データ（位置情報＋種別）
- **処理:**
  - 秋田県の市区町村ごとに投稿を集約
  - 種別（アメリカザリガニ、ウシガエル等）× 地域のページを生成
  - ISR で定期更新（revalidate: 3600）
- **出力:**
  - `/area/[municipality]` - 市区町村別の外来生物情報ページ
  - `/area/[municipality]/[species]` - 市区町村×種別の詳細ページ
- **SEO要素:**
  - タイトル: `{市区町村名}の{種別}情報 | ザリダス`
  - メタディスクリプション: 投稿数・最新情報を含む動的生成
  - JSON-LD: `Place` + `Dataset` スキーマ
  - canonical URL 設定
- **バリデーション:**
  - 投稿が0件の地域×種別ページは生成しない（noindex 設定）

### FR-002: パンくずナビゲーション コンポーネント
- **説明:** 全ページに視覚的なパンくずナビゲーションを表示する（JSON-LD は実装済み）
- **入力:** 現在のページパス・タイトル
- **処理:**
  - ルート構造に基づきパンくずを自動生成
  - 各階層のリンクをクリック可能にする
- **出力:** パンくずUIコンポーネント
- **パンくず構造例:**
  - ホーム > 投稿詳細 > {投稿タイトル}
  - ホーム > 地域別 > {市区町村名} > {種別}
  - ホーム > トレンド
  - ホーム > ランキング

### FR-003: 構造化データ拡充
- **説明:** 既存の JSON-LD に加え、追加の構造化データを実装する
- **追加スキーマ:**
  - `FAQPage`: 「使い方」ページのFAQセクション
  - `Event`: 目撃情報を時系列イベントとして
  - `Dataset`: 地域別統計データ
  - `Organization`: サイト運営者情報
  - `ImageObject`: 投稿写真のメタデータ
- **バリデーション:**
  - Google Rich Results Test でエラーなし
  - Schema.org バリデーターで検証通過

### FR-004: Core Web Vitals 最適化
- **説明:** ページ表示速度とユーザー体験を改善する
- **対策項目:**
  - 画像最適化: Next.js Image コンポーネントの適切な使用、WebP/AVIF 対応
  - フォント最適化: `next/font` による最適読み込み
  - JavaScript バンドルサイズ削減: 動的インポート、tree shaking
  - CSS の最適化: 未使用スタイルの削除
  - Prefetch/Preload: 重要リソースの事前読み込み
  - Leaflet 地図の遅延読み込み（LCP 改善）
- **目標値:**
  - LCP (Largest Contentful Paint): < 2.5秒
  - FID (First Input Delay): < 100ms
  - CLS (Cumulative Layout Shift): < 0.1
  - TTFB (Time to First Byte): < 800ms

### FR-005: 内部リンク構造最適化
- **説明:** サイト内のリンク構造を最適化し、クローラビリティと PageRank の配分を改善する
- **対策項目:**
  - 関連投稿リンク: 投稿詳細ページに同地域・同種別の関連投稿を表示
  - サイドバー/フッターに主要ページへのリンク
  - タグ・カテゴリページからの内部リンク
  - 「この地域の他の投稿」セクション

### FR-006: Open Search 対応
- **説明:** ブラウザの検索バーからザリダスを直接検索できるようにする
- **処理:**
  - `/opensearch.xml` を追加
  - `<link rel="search">` タグをヘッダーに追加
- **出力:** ブラウザのアドレスバーで「ザリダス」と入力後Tab キーでサイト内検索が可能
