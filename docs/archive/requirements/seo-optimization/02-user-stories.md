## ユーザーストーリー

### US-001: 検索エンジンからの流入
**As a** 秋田県の住民・研究者,
**I want to** 「秋田 ザリガニ 目撃情報」等で検索してザリダスを見つけたい,
**So that** 地域の外来生物情報を確認・投稿できる.

**受け入れ条件:**
- [ ] AC-1: 主要キーワードで Google 検索上位10位以内に表示される
- [ ] AC-2: 検索結果にリッチスニペット（構造化データ）が表示される
- [ ] AC-3: 地域名＋種別でのロングテール検索に対応するページがある

**優先度:** 高
**見積もり:** L

### US-002: SNSシェア時の表示最適化
**As a** 情報を共有したいユーザー,
**I want to** 投稿をSNSでシェアした時に魅力的なプレビューが表示されてほしい,
**So that** より多くの人に情報が広まる.

**受け入れ条件:**
- [ ] AC-1: 各投稿ページのOGP画像に投稿写真が使用される（実装済み）
- [ ] AC-2: OGPタイトル・説明文が投稿内容を適切に反映する（実装済み）
- [ ] AC-3: 動的OGP画像生成（写真がない場合のフォールバック改善）

**優先度:** 中
**見積もり:** M

### US-003: サイト内ナビゲーションの改善
**As a** 検索エンジンのクローラー / サイト訪問者,
**I want to** サイト構造を明確に理解したい,
**So that** 目的の情報に素早くたどり着ける.

**受け入れ条件:**
- [ ] AC-1: パンくずナビゲーションが全ページに表示される
- [ ] AC-2: 内部リンクが適切に配置されている
- [ ] AC-3: サイトマップが全公開ページを網羅している

**優先度:** 高
**見積もり:** M

### US-004: ページ表示速度の最適化
**As a** モバイルユーザー,
**I want to** ページが素早く表示されてほしい,
**So that** ストレスなく情報を確認できる.

**受け入れ条件:**
- [ ] AC-1: Core Web Vitals が全指標「Good」（LCP < 2.5s, FID < 100ms, CLS < 0.1）
- [ ] AC-2: Lighthouse Performance スコア 90以上
- [ ] AC-3: 画像の遅延読み込み・最適サイズ配信

**優先度:** 高
**見積もり:** M
