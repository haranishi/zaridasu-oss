## 3. ユーザーストーリー＆機能要件

---

### US-01: オンボーディング・ウォークスルー

```
As a 初回訪問者,
I want to アプリの使い方をステップバイステップで案内してもらいたい,
So that 迷わずに最初の投稿ができる.

受け入れ条件:
- [ ] 初回訪問時（localStorage フラグ未設定）にウォークスルーが自動起動する
- [ ] 3〜4 ステップで地図操作・投稿方法・会員メリットを説明する
- [ ] 各ステップでハイライト対象のUI要素をスポットライト表示する
- [ ] 「スキップ」ボタンでいつでも閉じられる
- [ ] 完了/スキップ後に localStorage にフラグを保存し再表示しない
- [ ] 「ヘルプ」メニューから再表示可能
```

**優先度: 高** | **影響度: 大** | **実装コスト: 中**

---

### US-02: 匿名→会員登録コンバージョン強化

```
As a 匿名ユーザー,
I want to 会員登録のメリットを適切なタイミングで知りたい,
So that 登録する価値を判断できる.

受け入れ条件:
- [ ] 匿名投稿完了後に「会員登録でバッジ獲得・投稿管理が可能」バナーを表示
- [ ] 投稿詳細ページで「いいね」タップ時に未ログインなら AuthModal を表示
- [ ] SignupBanner にバッジアイコンと投稿管理のプレビュー画像を追加
- [ ] A/Bテスト可能なバナーデザインを2パターン用意する
- [ ] コンバージョン率をGA4カスタムイベントで計測する
```

**優先度: 高** | **影響度: 大** | **実装コスト: 小**

---

### US-03: Supabase Realtime による投稿リアルタイム反映

```
As a 地図を閲覧中のユーザー,
I want to 新しい投稿がリアルタイムで地図に表示されてほしい,
So that 最新の出没情報を見逃さない.

受け入れ条件:
- [ ] Supabase Realtime で posts テーブルの INSERT/UPDATE を購読する
- [ ] status が approved に変更された投稿を地図上にアニメーション付きで追加する
- [ ] 投稿一覧にも新着投稿を先頭に追加（「新着N件」バッジ表示）
- [ ] 管理画面では pending 投稿のリアルタイム通知（ベルアイコンにバッジ）
- [ ] WebSocket 接続エラー時はポーリング（30秒間隔）にフォールバック
- [ ] コンポーネントアンマウント時にチャネルを確実にクリーンアップする
```

**技術仕様:**
```typescript
// hooks/useRealtimePosts.ts
const channel = supabase
  .channel('posts-realtime')
  .on('postgres_changes', {
    event: '*',
    schema: 'public',
    table: 'posts',
    filter: 'status=eq.approved'
  }, (payload) => {
    // INSERT → 地図にマーカー追加 + トースト
    // UPDATE → マーカー更新
    // DELETE → マーカー削除
  })
  .subscribe()
```

**優先度: 高** | **影響度: 大** | **実装コスト: 中**
