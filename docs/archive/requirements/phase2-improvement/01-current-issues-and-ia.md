## 1. 現状の課題サマリー

| # | カテゴリ | 課題 | 影響度 |
|---|---------|------|--------|
| C-01 | ユーザー獲得 | 初回訪問者→会員登録の転換導線が弱い。チュートリアルなし | 大 |
| C-02 | リアルタイム性 | Supabase Realtime未活用。新規投稿に手動リロードが必要 | 大 |
| C-03 | 通知 | メール通知のみ。プッシュ通知・アプリ内通知センターなし | 大 |
| C-04 | 検索・発見性 | フルテキスト検索なし。ilike による部分一致のみ | 中 |
| C-05 | データ活用 | CSV エクスポートのみ。GeoJSON / 公開API なし | 中 |
| C-06 | 監視・可観測性 | Sentry 等未導入。本番エラーの検知が遅れる | 大 |
| C-07 | E2E テスト | ユニットテストのみ。主要フローの自動回帰テストなし | 中 |
| C-08 | データ品質 | 重複投稿検知・位置情報精度検証が不十分 | 中 |
| C-09 | コミュニティ | 投稿者同士の交流手段が限定的 | 小 |
| C-10 | アクセシビリティ | WCAG 2.1 AA 準拠が部分的。aria-live 欠落多数 | 中 |

## 2. 情報アーキテクチャ（改善後）

### 2.1 サイトマップ（追加・変更部分）

```
/ (ホーム)
├── /post/[id] (投稿詳細)
├── /ranking (ランキング)
├── /trends (トレンド)
├── /area (地域一覧)
│   └── /area/[municipality]
├── /search ★NEW: 全文検索ページ
├── /dashboard (マイダッシュボード)
│   ├── /dashboard/notifications ★NEW: 通知センター
│   └── /dashboard/settings ★NEW: 通知設定
├── /profile / /profile/[userId]
├── /api/v1 ★NEW: 公開API
│   ├── /api/v1/posts
│   ├── /api/v1/posts/[id]
│   ├── /api/v1/stats
│   └── /api/v1/export (GeoJSON)
├── /admin (管理画面)
├── /about, /terms, /privacy
└── /offline
```

### 2.2 主要ユーザーフロー（改善対象）

**オンボーディングフロー（NEW）**
```
[初回訪問 /] → [地図表示 + ウォークスルーオーバーレイ]
    → ステップ1: 地図の見方
    → ステップ2: 投稿の仕方
    → ステップ3: 会員登録のメリット
    → [CTA: 会員登録 or スキップ]
        → 登録 → [AuthModal] → [ダッシュボード]
        → スキップ → [地図操作] → [投稿試行] → [SignupBanner 表示]
```

**リアルタイム投稿反映フロー（NEW）**
```
[ユーザーA: 投稿送信] → [Supabase INSERT]
    → [Realtime Channel: posts_approved]
    → [ユーザーB: 地図にマーカー追加 + トースト通知]
    → [管理者: 管理画面にバッジ通知]
```

**通知フロー（NEW）**
```
[トリガーイベント] → [notifications テーブル INSERT]
    → [Realtime → アプリ内通知ベル更新]
    → [Web Push API → プッシュ通知送信]
    → [ユーザー: 通知センターで確認 → 既読マーク]
```
