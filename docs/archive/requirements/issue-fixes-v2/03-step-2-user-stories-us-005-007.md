### US-005: PWA強化
**As a** フィールドワーカー,
**I want to** 圏外でもアプリとして快適に使いたい,
**So that** 山間部や河川沿いでも情報を記録・閲覧できる.

**受け入れ条件:**
- [ ] AC-1: Service Worker がインストールされ、静的アセットがキャッシュされる
- [ ] AC-2: オフライン時に /offline ページが自動表示される
- [ ] AC-3: PWA マニフェストにPNGアイコン・screenshots・shortcuts がある
- [ ] AC-4: iOS Safari で「ホーム画面に追加」が適切に動作する

**優先度:** 中
**見積もり:** L

### US-006: コード品質向上
**As a** 開発者,
**I want to** 型安全性とエラー検知を強化したい,
**So that** バグの早期発見とリファクタリング時の安心感を得られる.

**受け入れ条件:**
- [ ] AC-1: TypeScript strict モードが有効で、any型が排除される
- [ ] AC-2: 全コンポーネントの props に型定義がある
- [ ] AC-3: グローバル error.tsx が存在し、未ハンドルエラーをキャッチする
- [ ] AC-4: 全言語の翻訳キーが同期している

**優先度:** 中
**見積もり:** L

### US-007: データ整合性確保
**As a** 管理者,
**I want to** データ操作の信頼性を確保したい,
**So that** 重複データやサイレント失敗が発生しない.

**受け入れ条件:**
- [ ] AC-1: useAdminStats の全クエリでエラーが表示される
- [ ] AC-2: いいね操作が連続クリックで重複しない
- [ ] AC-3: オフラインキューの容量が監視され、上限超過時に通知される
- [ ] AC-4: 「すべて送信」が排他制御され、重複送信されない

**優先度:** 高
**見積もり:** M
