### FR-019: Service Worker 実装
- **説明:** next-pwa またはカスタム SW でオフラインキャッシュを実装
- **対象ファイル:** 新規 `public/sw.js` または next-pwa 設定
- **処理:**
  - キャッシュ戦略: App Shell (Cache First) + API (Network First)
  - 静的アセット: /_next/static/*, /images/*, /icon-*.svg → Cache First
  - API: Supabase 呼出し → Network First（フォールバック: IndexedDB キャッシュ）
  - オフライン: ナビゲーション失敗時に /offline を返却
  - Service Worker 登録: layout.tsx で `navigator.serviceWorker.register('/sw.js')`
