## Step 1: 要件概要

### 背景・目的

ザリダス（秋田県外来生物情報マップ）は Vite SPA → Next.js 15 App Router への移行を完了し、本番稼働中（https://zaridasu.com）。
移行後の包括的調査で **41件の品質課題** を検出した。これらを体系的に修正し、セキュリティ・パフォーマンス・アクセシビリティ・SEO・PWA・コード品質・データ整合性の各面で本番運用水準に引き上げる。

### スコープ

**対象範囲:**
- セキュリティヘッダー・RLS・入力バリデーション・ミドルウェア強化
- Next.js Image最適化・Context メモ化・非同期処理のキャンセル制御
- WCAG 2.1 AA 準拠（フォーカストラップ・コントラスト・ARIA・label）
- メタデータ・JSON-LD・サイトマップ・OG画像の最適化
- Service Worker・PWAマニフェスト・iOS対応
- TypeScript strict化・型安全性・error.tsx・翻訳キー補完
- hooks エラーハンドリング・競合状態・排他制御

**対象外:**
- 新機能開発（プッシュ通知、リアルタイム更新等）
- テストカバレッジ拡大（別タスクとして管理）
- UI デザインリニューアル
- Edge Function の新規追加

### 前提条件・制約

- **技術スタック:** Next.js 15.3.4 / React 19.1.0 / TypeScript 5.9.3 / Supabase / Tailwind CSS 3
- **ホスティング:** Vercel（サーバーレス）
- **DB:** Supabase PostgreSQL（RLS 必須）
- **既存テスト:** 124テスト全パス維持が必須
- **後方互換:** 既存ユーザーのセッション・データに影響しないこと
