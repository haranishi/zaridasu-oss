## Step 2: ユーザーストーリー

### US-001: セキュリティ強化
**As a** サイト運営者,
**I want to** XSS・MITM・セッション改ざん等の攻撃ベクトルを最小化したい,
**So that** ユーザーの個人情報と投稿データを安全に保護できる.

**受け入れ条件:**
- [ ] AC-1: CSP / HSTS / X-XSS-Protection ヘッダーが全レスポンスに含まれる
- [ ] AC-2: postsテーブルのRLSポリシーが一意で矛盾がない
- [ ] AC-3: count, lat/lng, reason等の入力値がサーバーサイドで検証される
- [ ] AC-4: ミドルウェアでJWT署名が検証される

**優先度:** 高
**見積もり:** L

---

### US-002: パフォーマンス最適化
**As a** 一般ユーザー,
**I want to** ページ遷移やデータ読み込みが速くなってほしい,
**So that** フィールドでもストレスなく情報を確認・投稿できる.

**受け入れ条件:**
- [ ] AC-1: 画像が Next.js Image で最適化される（WebP/AVIF自動変換）
- [ ] AC-2: Context の値変更時のみ子コンポーネントが再レンダリングされる
- [ ] AC-3: ページ離脱・フィルタ変更時に進行中のリクエストがキャンセルされる
- [ ] AC-4: 管理画面チャートが遅延読み込みされる
- [ ] AC-5: 静的アセットに適切なCache-Controlが設定される

**優先度:** 高
**見積もり:** L

---

### US-003: アクセシビリティ向上
**As a** スクリーンリーダー利用者 / キーボード操作ユーザー,
**I want to** モーダル・フォーム・ボタンが適切に操作できる,
**So that** 障がいの有無に関わらずサービスを利用できる.

**受け入れ条件:**
- [ ] AC-1: 全モーダルでフォーカスがトラップされ、Escapeで閉じられる
- [ ] AC-2: ダークモードで WCAG AA (4.5:1) のコントラスト比を満たす
- [ ] AC-3: 全インタラクティブ要素に aria-label または可視ラベルがある
- [ ] AC-4: フォーム入力に関連付けられた label 要素がある
- [ ] AC-5: ボタンに適切な type 属性がある
- [ ] AC-6: 全画像に意味のある alt 属性がある

**優先度:** 高
**見積もり:** M

---

### US-004: SEO最適化
**As a** サイト運営者,
**I want to** 検索エンジンとSNSからの流入を最大化したい,
**So that** より多くの市民が外来生物情報を活用できる.

**受け入れ条件:**
- [ ] AC-1: 全ページに適切な title / description / canonical がある
- [ ] AC-2: JSON-LD が環境変数ベースの URL を使用する
- [ ] AC-3: サイトマップに全公開ルートが含まれる
- [ ] AC-4: OG画像が絶対URLで指定される

**優先度:** 中
**見積もり:** M
