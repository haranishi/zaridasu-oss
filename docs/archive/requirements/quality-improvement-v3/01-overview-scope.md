## Step 1: 要件概要

### 背景・目的

ザリダスは v2 品質改善（TypeScript strict 化、CSPヘッダー設定、RLS統合、AbortController 導入等）を経て安定性が向上したが、以下の領域に未解決の課題が残存する：

1. **セキュリティ**: CSP で `unsafe-inline`/`unsafe-eval` が依然許可されており XSS 耐性が不十分。編集投稿のバリデーション欠如
2. **パフォーマンス**: RPC 呼び出しのキャンセル不可、メモリリーク（キャッシュ無制限増加）、スケルトン UI 不在
3. **アクセシビリティ**: PostForm モーダルのフォーカストラップ未実装、動的画像の alt 不足
4. **PWA**: Service Worker キャッシュバージョニングなし、Background Sync 未使用
5. **コード品質**: any 型残存、エラーハンドリング不統一、管理画面エラーバウンダリ不在
6. **データ整合性**: オフラインキュー競合状態、バリデーション共有なし
7. **UX**: 空状態メッセージ不在、天気エラー非表示、ロング読み込みタイムアウトなし
8. **インフラ**: 環境変数ビルド時検証なし、モニタリング未導入、外部キー CASCADE 不整合

### スコープ

**対象（38件）:**
- セキュリティ強化（5件）
- パフォーマンス改善（6件）
- アクセシビリティ向上（5件）
- SEO 改善（1件 — OG 画像検証のみ。generateMetadata/動的サイトマップは実装済み）
- PWA 強化（4件）
- コード品質向上（6件）
- データ整合性改善（4件）
- UX/UI 改善（4件）
- インフラ整備（3件）

**対象外:**
- 新機能開発（プッシュ通知、リアルタイム更新等）
- UI デザインの大幅変更
- テストカバレッジの大規模拡張（個別修正に伴うテスト追加は対象内）
- Supabase Edge Functions の新規作成
- モバイルネイティブアプリ開発
