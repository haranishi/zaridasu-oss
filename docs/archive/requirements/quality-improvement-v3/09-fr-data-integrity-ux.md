### FR-028: オフラインキュー排他制御
- **説明:** useOfflineQueue の sendAll に mutex パターンを実装し、同時実行を防止する
- **入力:** sendAll 呼び出し
- **処理:**
  1. `sendingRef` に加え、`lockRef` を導入
  2. sendAll 開始時に `lockRef.current = true` を設定
  3. 完了/エラー時に `lockRef.current = false` に戻す
  4. `lockRef.current === true` の場合は即座にリターン
  5. finally ブロックで確実にロック解除
- **出力:** 重複送信が防止された送信処理
- **関連:** US-006/AC-1

### FR-029: オフラインキューバリデーション
- **説明:** offlineStore.addPendingPost でデータバリデーションを実行する
- **入力:** 投稿フォームデータ
- **処理:**
  1. FR-005 で作成した `validatePostData()` を使用
  2. バリデーション失敗時は IndexedDB に保存せずエラーを返す
  3. エラーメッセージをユーザーに表示
- **出力:** バリデーション済みのオフラインキューエントリ
- **関連:** US-006/AC-3

### FR-030: 楽観的更新
- **説明:** usePostList に楽観的更新を実装し、投稿直後に一覧へ即時反映する
- **入力:** 新規投稿成功イベント
- **処理:**
  1. 投稿成功時に `setPosts(prev => [newPost, ...prev])` で先頭に追加
  2. DB 確認後に差分があれば更新
  3. 失敗時はロールバック（楽観的に追加したエントリを削除）
- **出力:** 即座に更新された投稿リスト
- **エラーハンドリング:** ロールバック時に Toast でエラー通知
- **関連:** US-006/AC-4

### FR-031: 空状態メッセージ
- **説明:** PostList でフィルタ結果が 0 件の場合に適切なメッセージを表示する
- **入力:** フィルタ適用後の投稿リスト（空配列）
- **処理:**
  1. `posts.length === 0 && !loading` の場合に EmptyState コンポーネントを表示
  2. フィルタ有りの場合: 「条件に一致する投稿はありません」+ フィルタリセットボタン
  3. フィルタなしの場合: 「まだ投稿がありません」+ 投稿ボタン
  4. イラスト（🦞 or 🐸）付き
- **出力:** コンテキスト付き空状態 UI
- **関連:** US-007/AC-1

### FR-032: 天気エラー表示
- **説明:** useWeather の天気取得失敗時にユーザーへフィードバックを表示する
- **入力:** 天気 API エラー
- **処理:**
  1. useWeather の戻り値に `weatherError: boolean` を追加
  2. PostForm で `weatherError === true` の場合に小さな警告テキストを表示
  3. 表示例: 「⚠️ 天気情報を取得できませんでした」
  4. 天気選択は手動で可能にする（既存機能）
- **出力:** 天気エラーの視覚的フィードバック
- **関連:** US-007/AC-2

### FR-033: ロング読み込みタイムアウト
- **説明:** 10 秒以上の読み込みが継続する場合にタイムアウト表示とリトライボタンを追加する
- **入力:** ローディング状態の継続
- **処理:**
  1. `useLoadingTimeout(loading, timeoutMs = 10000)` フックを作成
  2. loading が timeoutMs 継続した場合に `isTimeout: true` を返す
  3. タイムアウト時の UI: 「読み込みに時間がかかっています」+ リトライボタン + ホームへ戻るリンク
  4. 主要ページ（HomePage, DetailPage, DashboardPage）に適用
- **出力:** タイムアウト付きローディング UI
- **関連:** US-007/AC-3

### FR-034: 削除確認ダイアログ
- **説明:** 投稿削除前に確認ダイアログを表示する
- **入力:** 削除ボタンクリック
- **処理:**
  1. 既存の `DeleteDialog` コンポーネントを投稿削除にも適用
  2. 確認メッセージ: 「この投稿を削除しますか？この操作は取り消せません。」
  3. キャンセル/削除ボタン
- **出力:** 確認後の削除実行
- **関連:** US-007/AC-4
