### FR-012: PostForm フォーカストラップ
- **説明:** PostForm モーダルにフォーカストラップを実装し、Tab/Shift+Tab でモーダル内をサイクルさせる
- **入力:** キーボードイベント（Tab, Shift+Tab, Escape）
- **処理:**
  1. モーダルオープン時に最初のフォーカス可能要素にフォーカス
  2. Tab で最後の要素→最初の要素、Shift+Tab で最初→最後にループ
  3. Escape でモーダルクローズ
  4. モーダル外の要素に `aria-hidden="true"` と `inert` を設定
- **出力:** フォーカスがモーダル内に閉じ込められた状態
- **関連:** US-003/AC-1

### FR-013: 動的画像 alt テキスト生成
- **説明:** 投稿写真に投稿メタデータからコンテキストのある alt テキストを自動生成する
- **入力:** 投稿データ（species, info_type, municipality, 写真インデックス）
- **処理:**
  1. `generatePhotoAlt(post, index)` ユーティリティを作成
  2. 出力例: 「アメリカザリガニの目撃写真 1/3 - 秋田市」
  3. 種類・情報種別の日本語ラベルを使用
- **出力:** コンテキスト付き alt 文字列
- **関連:** US-003/AC-2

### FR-014: Toast aria-atomic 追加
- **説明:** Toast コンポーネントの各通知アイテムに `aria-atomic="true"` を追加する
- **入力:** Toast 通知表示イベント
- **処理:** 個別 Toast アイテムの div に `aria-atomic="true"` を追加
- **出力:** スクリーンリーダーが通知全体を読み上げる
- **関連:** US-003/AC-3

### FR-015: PostForm label 要素追加
- **説明:** PostForm の全フォームフィールドに `<label>` 要素を追加し、`htmlFor` で関連付ける
- **入力:** フォームフィールド定義
- **処理:**
  1. 各 input/select/textarea に一意の `id` を付与
  2. 対応する `<label htmlFor="...">` を追加
  3. 既存の `aria-label` は `<label>` に統合
- **出力:** セマンティックなフォーム構造
- **関連:** US-003/AC-4

### FR-016: Header aria-label 追加
- **説明:** Header 内のアイコンのみボタン（言語切替、テーマトグル、メニュー等）に `aria-label` を追加する
- **入力:** Header コンポーネント定義
- **処理:**
  1. 言語セレクター: `aria-label="言語を変更"`
  2. テーマトグル: `aria-label="ダークモードを切り替え"`
  3. メニューボタン: `aria-label="メニューを開く"`
  4. ユーザーメニュー: `aria-label="ユーザーメニュー"`
- **出力:** アクセシブルなヘッダー
- **関連:** US-003/AC-5

### FR-017: OG 画像検証・最適化
- **説明:** OG 画像が存在し、推奨サイズ（1200x630px）であることを確認する
- **入力:** public/og-image.png
- **処理:**
  1. ファイル存在確認
  2. 画像サイズが 1200x630px であること検証
  3. 不足/不適切な場合は適切なサイズで再作成
  4. 絶対 URL で参照されていることを確認
- **出力:** 最適化された OG 画像
- **関連:** US-001 の SEO 要件
