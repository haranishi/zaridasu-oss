## Step 5: 画面仕様（変更が必要な画面）

### SC-001: ホームページ（投稿リスト改善）
- **URL:** `/`
- **用途:** 投稿リストの空状態・タイムアウト表示の改善
- **変更点:**
  ```
  +---------------------------+
  | Header                    |
  +---------------------------+
  | FilterBar                 |
  +---------------------------+
  | StatsBar                  |
  +---------------------------+
  | Map / PostList            |
  |                           |
  | [空状態: EmptyState]      | ← NEW
  | [タイムアウト: RetryUI]    | ← NEW
  +---------------------------+
  | BottomNav                 |
  +---------------------------+
  ```
- **新コンポーネント:**
  | コンポーネント | 説明 | 状態 |
  |---------------|------|------|
  | EmptyState | フィルタ結果0件の表示 | フィルタあり/なし |
  | LoadingTimeout | 10秒超の読み込み表示 | タイムアウト |
  | MapSkeleton | 地図読み込みスケルトン | 読み込み中 |
- **状態管理:**
  - ローディング: MapSkeleton + PostCardSkeleton
  - 空状態: EmptyState（フィルタリセットボタン付き）
  - タイムアウト: LoadingTimeout（リトライボタン付き）
  - エラー: ErrorBoundary

### SC-002: 投稿フォーム（アクセシビリティ改善）
- **URL:** モーダル（`/` 上のオーバーレイ）
- **用途:** PostForm のアクセシビリティ・バリデーション改善
- **変更点:**
  - フォーカストラップ追加
  - 全フィールドに `<label>` 要素追加
  - 天気エラー表示追加
- **新コンポーネント:**
  | コンポーネント | 説明 | 状態 |
  |---------------|------|------|
  | WeatherError | 天気取得失敗の警告 | エラー |

### SC-003: 管理画面エラーバウンダリ
- **URL:** `/admin/*`
- **用途:** 管理画面のクラッシュ隔離
- **レイアウト:**
  ```
  +---------------------------+
  | Admin Header              |
  +---------------------------+
  | 🦞 エラーが発生しました     |
  |                           |
  | [エラー詳細(digest)]       |
  | [リトライ] [ダッシュボード]  |
  +---------------------------+
  ```
