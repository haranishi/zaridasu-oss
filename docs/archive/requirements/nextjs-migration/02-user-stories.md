## Step 2: ユーザーストーリー

### US-001: SEO 最適化された投稿詳細ページ
**As a** 検索エンジンユーザー,
**I want to** Google検索で「秋田市 ザリガニ 目撃」と検索したときに個別投稿が検索結果に表示される,
**So that** 直接目的の情報にアクセスできる.

**受け入れ条件:**
- [ ] AC-1: `/post/:id` ページが SSR でレンダリングされ、完全な HTML が返される
- [ ] AC-2: 投稿の種類・場所・日時が `<title>` と `<meta description>` に含まれる
- [ ] AC-3: JSON-LD 構造化データ（Report スキーマ + BreadcrumbList）が HTML に含まれる
- [ ] AC-4: Google Search Console でインデックス登録が確認できる

**優先度:** 高 | **見積もり:** M

### US-002: SNS シェア時の動的 OGP
**As a** ユーザー,
**I want to** 投稿をTwitter/LINEでシェアしたときに投稿の写真・タイトル・場所がカードで表示される,
**So that** フォロワーが興味を持ってクリックしてくれる.

**受け入れ条件:**
- [ ] AC-1: `/post/:id` の og:title に種類・場所が含まれる
- [ ] AC-2: og:image に投稿写真（あれば）またはデフォルト画像が設定される
- [ ] AC-3: Twitter Card (summary_large_image) が正しく表示される
- [ ] AC-4: LINE のリンクプレビューで正しく表示される

**優先度:** 高 | **見積もり:** M

### US-003: 初回表示の高速化
**As a** 初めてサイトを訪問するユーザー,
**I want to** 3秒以内にページコンテンツが表示される,
**So that** 離脱せずに情報を閲覧できる.

**受け入れ条件:**
- [ ] AC-1: トップページの LCP（Largest Contentful Paint）が 2.5 秒以下
- [ ] AC-2: FCP（First Contentful Paint）が 1.8 秒以下
- [ ] AC-3: CLS（Cumulative Layout Shift）が 0.1 以下
- [ ] AC-4: Lighthouse Performance スコアが 80 以上

**優先度:** 高 | **見積もり:** L

### US-004: 動的サイトマップ
**As a** サイト運営者,
**I want to** 全承認済み投稿が含まれるサイトマップが自動生成される,
**So that** Google がすべてのページを効率的にクロールできる.

**受け入れ条件:**
- [ ] AC-1: `/sitemap.xml` に静的ページ + 全承認済み投稿 + 調査依頼が含まれる
- [ ] AC-2: `lastmod` フィールドが正しい更新日時を反映する
- [ ] AC-3: Google Search Console でサイトマップ送信・インデックス状況が確認できる

**優先度:** 高 | **見積もり:** S

### US-005: 既存機能の完全移植
**As a** 既存ユーザー,
**I want to** 移行後も全ての機能（投稿・地図・コメント・いいね・バッジ・管理画面等）が同じように使える,
**So that** 移行による機能ロスがない.

**受け入れ条件:**
- [ ] AC-1: 全 19 ページが正常に動作する
- [ ] AC-2: 投稿フォーム（写真アップロード・位置選択・天気取得）が動作する
- [ ] AC-3: Google OAuth + メール/パスワード認証が動作する
- [ ] AC-4: 管理者ページ（投稿審査・ユーザー管理・ログ）が動作する
- [ ] AC-5: PWA（オフライン対応・インストール）が動作する
- [ ] AC-6: 4言語切替が動作する
- [ ] AC-7: ダークモードが動作する

**優先度:** 高 | **見積もり:** XL

### US-006: 多言語 SEO 対応
**As a** 外国語話者,
**I want to** 自分の言語で検索したときにザリダスのページが検索結果に表示される,
**So that** 日本語が分からなくても情報にアクセスできる.

**受け入れ条件:**
- [ ] AC-1: hreflang タグが全ページに含まれる
- [ ] AC-2: 言語別 URL（`/en/post/:id` 等）または代替手段で言語バリアントが認識される
- [ ] AC-3: メタデータが各言語で出力される

**優先度:** 中 | **見積もり:** M
