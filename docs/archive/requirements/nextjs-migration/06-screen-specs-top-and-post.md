## Step 5: 画面仕様

### SC-001: トップページ（`/`）

- **URL:** `/`
- **レンダリング:** SSR + Client Hydration
- **用途:** 地図と投稿一覧で秋田県の外来生物情報を閲覧・投稿

```
+------------------------------------------+
| ヘッダー (Header)                         |
+--------+---------------------------------+
| フィルター (FilterBar)                    |
+--------+---------------------------------+
| タブ: 地図 | リスト                       |
+--------+---------------------------------+
| 地図 (MapView - dynamic import)          |
| [投稿マーカー] [調査依頼マーカー]          |
|                                          |
+--------+---------------------------------+
| 投稿一覧 (PostList - infinite scroll)    |
+--------+---------------------------------+
| フッター (Footer)                        |
+------------------------------------------+
| BottomNav (mobile only)                  |
+------------------------------------------+
```

- **Server Component 部分:** ページシェル、初期投稿データ取得、メタデータ
- **Client Component 部分:** MapView、FilterBar、PostForm、AuthModal、PostList（インタラクション）
- **データ取得:**
  - サーバー: 最新50件の承認済み投稿（初回表示用）
  - クライアント: フィルター変更時の再取得、無限スクロール追加読込、調査依頼一覧

### SC-002: 投稿詳細ページ（`/post/[id]`）

- **URL:** `/post/:id`
- **レンダリング:** SSR
- **用途:** 個別投稿の詳細表示（SEO 最重要ページ）

```
+------------------------------------------+
| ヘッダー                                  |
+------------------------------------------+
| パンくず (トップ > 投稿詳細)               |
+------------------------------------------+
| 写真ギャラリー (PhotoViewer)              |
+------------------------------------------+
| 投稿情報 (種類, 場所, 日時, 天気)          |
+------------------------------------------+
| コメント (CommentSection)                 |
+------------------------------------------+
| いいね・シェア (LikeShareSection)         |
+------------------------------------------+
| AI分析結果 (ある場合)                      |
+------------------------------------------+
| フッター                                  |
+------------------------------------------+
```

- **Server Component 部分:** 投稿データ取得、メタデータ生成、JSON-LD、写真URL
- **Client Component 部分:** CommentSection、LikeShareSection、EditDialog、PhotoViewer
