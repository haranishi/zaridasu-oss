## 5. 週次レビューの型（AC-08・cadence 固定・3 行）

> ダッシュボードは見るだけでは 1 円も生まない。**毎週同じ曜日・時間**に回し、「数字 → なぜ → 打ち手」を **3 行**で残す。打ち手は**1 つだけ**に絞る。

**cadence**: 毎週○曜 10:00（固定）／所要 10 分。

**手順:**
1. `/admin/kpi` を開く（ファネル/品質=直近30日、コホート=12ヶ月）。
2. **NSM の WoW** を見る（緑/横ばい/赤）。続いてガードレール（却下率・完全率・正確率）が赤に振れていないか確認。
3. コホート表で**直近コホートの M1/M2 継続**が前コホートより落ちていないか確認。
4. 量×質ペアで「量が増えて質が落ちる」Goodhart の兆候がないか確認。
5. 下記テンプレを 3 行で記録する。

**記録テンプレ（3 行）:**
