## 4. PII 非送出・外部送信規律の点検（AC-07）

### PII を GA4 に送らない（規約違反＝プロパティ全データ削除リスク）
- 氏名・メール・電話番号、およびそれらを含む URL クエリ（`?q=`・`?email=` 等）を **GA4 へ送らない**。
- 具体的なリダクション実装（フォーム値・URL クエリの除去・GTM 設定）は **REQ-232** が主管。本書は運用点検のみ。
- 点検: GA4 → DebugView と「探索」でイベントパラメータに PII が混入していないか定期確認。混入を見つけたら即リダクション。
- **`search` イベントは検索語そのものを送らない（2026-08-06 変更）。** 検索対象にコメント本文が含まれるため任意の自由入力が入り、氏名・メール・電話番号が混入し得る。パターン照合では人名を検出できないため、`search_term` を廃止し識別性のない `search_term_length`（文字数）のみを送る。GTM 側の汎用 GA4 イベントタグでも `search_term` は転送対象に含めていない。

### 外部送信規律（改正電気通信事業法・2023年6月施行）
- 日本は GDPR のような同意バナー必須ではないが、**外部送信について「通知・公表」が必要**。
- 対応: プライバシーポリシー（`src/views/PrivacyPage.tsx`）に「アクセス解析と外部送信について」セクションを掲載済み（送信先 Google・送信情報・目的・保持14ヶ月・オプトアウト導線）。**ポリシー更新時は本チェックも見直す。**
- EU/UK 向けトラフィックを本格的に想定する場合のみ、同意バナー＋Consent Mode v2 を別途検討（**現状は国内前提**）。
