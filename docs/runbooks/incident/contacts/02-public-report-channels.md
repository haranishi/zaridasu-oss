## 3. 公的・第三者の相談 / 通報窓口（日本）

> いずれも相談は基本無料。**迷ったら早めに相談**する。電話番号・URL・受付時間は変わるため、**かける前に公式で確認**（⚠️要確認）。

| 窓口 | 主な用途 | 入口（⚠️要確認） |
|---|---|---|
| **個人情報保護委員会（PPC）** | 個人データ漏洩等の**報告（義務の判断・速報 / 確報）**・相談 | `https://www.ppc.go.jp/` 漏えい等報告フォーム / 個人情報保護法相談ダイヤル。**報告義務の有無・期限・該当類型は必ず最新を確認**（→ [04-personal-data-breach.md](./04-personal-data-breach.md)） |
| **JPCERT/CC** | インシデントの届出・調整（攻撃・侵害） | `https://www.jpcert.or.jp/` インシデント報告 |
| **IPA 情報セキュリティ安心相談窓口** | 不正アクセス・マルウェア・一般的なセキュリティ相談 | `https://www.ipa.go.jp/security/anshin/` |
| **警察（サイバー犯罪相談窓口）** | 不正アクセス・恐喝・なりすまし等の**犯罪**としての相談 | 都道府県警サイバー犯罪相談窓口 / 緊急性が低い相談は **#9110**（警察相談専用電話）/ 緊急は 110 |
| **フィッシング対策協議会** | フィッシング URL・なりすましメールの報告 | `https://www.antiphishing.jp/` |
| **JPCERT/CC または各 CSIRT** | 第三者からの脆弱性報告の受け / 調整 | 上記 JPCERT/CC |

> 個人情報保護委員会への報告は、フォーム提出が基本。**速報（速やかに）→ 確報（原則 30 日。不正の目的によるおそれがある漏えい等は 60 日 など類型により異なる）** の二段構えが想定されるが、**閾値・期限・該当類型・本人通知の要否は 2026 年時点の最新を必ず公式で確認**し、断定しないこと（→ [04-personal-data-breach.md](./04-personal-data-breach.md)）。
