## 最初の 15 分でやること（最小保全チェックリスト）

```
[ ] 発見の記録: 発見時刻(TZ付き)・発見者・きっかけ・現象・関連 URL をメモ開始
[ ] 該当画面のキャプチャ: 異常が見えている画面・請求額・アラートを「今」スクショ（時刻が写るように）
[ ] 揮発しやすいログから順に書き出す（下表の優先度 高 → 低）
[ ] 書き出したファイルは読み取り専用にし、調査はコピーに対して行う
[ ] 可能なら各ファイルの SHA-256・取得者・取得時刻・保存場所を記録（chain of custody）
[ ] ここまで終えてから封じ込め（失効・削除・公開停止）に進む
```

### 記録テンプレ（コピーして使う）

```
インシデント記録 / Incident log
- 発見時刻      : 2026-__-__ __:__ JST
- 発見者        : <ハンドル / 役割>
- きっかけ      : アラート / 請求 / 通報 / 自分で発見 / その他(______)
- 現象（事実）  : 
- 関連 URL/ID   : 
- 暫定の影響推定: （不明なら「不明・調査中」）
- 操作ログ（時系列・追記していく）:
    __:__ JST  <やったこと / 見たこと>
    __:__ JST  ...
```
