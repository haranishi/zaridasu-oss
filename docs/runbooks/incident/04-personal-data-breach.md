---

## いつ使うか

- ザリダスが保持する**個人データが外部に出た / 出た疑い**がある
- 誤公開（本来非公開のデータを公開設定にしてしまった）、誤送信（メールの宛先 / 添付ミス）
- 不正アクセス / 秘密漏洩 / 乗っ取りによる**データ持ち出し**の可能性
- 第三者 / 利用者から「自分の情報が見える」と通報があった

> ザリダスは **メール・IP・位置情報・写真 / 音声・プロフィール**という複数種の PII を保持している。これらの漏洩は「起こり得る」前提で、**事実確認と証拠保全を最優先**に動く。

---

## 主要な決定事項（要点）

- **順序は「記録 → 保全 → 封じ込め」。** 消せばなかったことにはならない。データ拡散が続いているときだけ最小スクショで封じ込めを先に進める。
- **影響範囲は保守的に（最悪ケース寄りに）見積もる。** 「第三者に取得された可能性を否定できない」なら漏洩として扱う。
- **報告義務の判断を一人で抱えない。** トリガ類型に当たる「おそれ」の時点で速報の準備を始め、迷えば個人情報保護委員会・専門家に相談する（相談は無料）。
- **法令の閾値・期限・記載事項は本書で断定しない。** 対応時に必ず公式の最新情報で確認する。
- **本人通知 / 公表は影響範囲と記載事項が固まってから。** 断定・補償の確約は文面に入れない。
