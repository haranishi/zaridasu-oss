## 0. 注意

- **このファイルに実在の個人名・私用電話番号・私用メールアドレスを書かない。** 関係者連絡先はプレースホルダのまま運用し、必要なら本人だけがアクセスできる別の安全な場所（パスワードマネージャ等）に控える（NFR-220-01）。
- 公的窓口・各社サポートの URL や電話番号は変更され得る。**かける / 送る前に公式サイトで最新を確認**する。

## これは何か

インシデント対応中に「誰に・どこへ連絡するか」と「何を書いて出すか」をまとめたページ。各 runbook の連絡・エスカレーション節はここを参照する。

## 主要な決定事項（要点）

- **実値（個人名・私用連絡先）はこのファイルに書かない。** プレースホルダ運用し、実値はパスワードマネージャ等で管理する（NFR-220-01）。
- **窓口情報は変わり得る前提で扱う。** URL・電話番号・受付時間は使う直前に公式で確認し、最終確認日を更新する。
- **公的窓口への相談は基本無料。迷ったら早めに相談する。** 個人情報保護委員会への報告は速報 → 確報の二段構えが想定されるが、閾値・期限・該当類型は断定せず最新を公式で確認する。
- **一次連絡では原因・影響範囲・賠償を確約しない。** 「確認中・追って続報」に留め、秘密値と PII は本文に書かない。
