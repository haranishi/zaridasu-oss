## 0. この runbook の使い方（最初に読む）

事故は「本番が見られない・頭が真っ白・一人」という状況で起きる。この文書は **考えずに上から順に読んで動く**ためのもの。

- まず本ページの **[共通初動チェックリスト](#共通初動チェックリスト8-ステップ)** を上から実行する。
- 並行して **[事象 → 該当 runbook 対応表](#事象--該当-runbook-対応表)** で自分のケースのページを開く。
- 各 runbook は **初動チェックリスト → 詳細手順 → 事後対応** の順。最初のチェックリストだけで初動は回せる。
- このフォルダは Markdown 単体で読めるよう書いてある（外部レンダリング不要）。**スマホ・印刷でも初動と連絡先が読める**ことを意図している（NFR-220-02）。いざというときに開けるよう、リポジトリの場所を控えておくこと。

### 大原則（すべての runbook に共通）

1. **緊急時ほど削除を急ぐと証拠を失う。** 「とりあえず消す・上書きする」の前に、まず記録・保全する → [evidence-preservation.md](./evidence-preservation.md)。
2. **push / 送信した秘密は漏洩済みとみなす。** 「たぶん大丈夫」では扱わない（→ [01-secret-leak.md](./01-secret-leak.md)）。
3. **事実確認の前に賠償・原因・影響範囲を確約しない。** 一次連絡は「確認中であること」を伝えるに留める。
4. **秘密値・実ユーザーの個人データを runbook・チケット・スクショ・チャットに残さない。** 識別はメタデータ（プロバイダ名・末尾数文字・キー ID・所有者）で行う（NFR-220-01）。
5. **判断に迷ったら止めて相談する。** 公的窓口・各社サポートは [contacts.md](./contacts.md)。法令該当性は専門家へ。
