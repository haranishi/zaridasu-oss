## 終了条件（「対応したつもり」で閉じない）

- [ ] 漏洩経路を**塞いだ**（公開停止 / リンク失効 / 送信停止 / キー失効）ことを確認した
- [ ] 漏れたデータの**種別・対象人数・件数・期間・取得有無**を特定した（不明箇所は明記）
- [ ] 秘密漏洩 / 乗っ取り起因なら [01](./01-secret-leak.md) / [02](./02-account-takeover.md) の対応も完了した
- [ ] 個人情報保護委員会への**報告義務の有無を最新の公式情報で確認**し、判断（報告する / しない / 相談する）を記録した
- [ ] 報告対象なら**速報を期限内に提出**し、**確報の期限**を管理している
- [ ] **本人通知 / 公表の要否**を判断し、必要なら文面（断定・補償確約なし）を準備・実施した
- [ ] 必要に応じて専門家（弁護士等）・個人情報保護委員会に相談した
- [ ] 原因（RLS の穴 / 公開設定ミス / 誤送信 / 漏洩キー）を特定し、**恒久対策**（RLS 修正・公開設定の見直し・送信時チェック・secret scanning）を実施した
- [ ] 証拠（漏洩経路・ログ・該当データ・報告控え）を保全し、タイムラインを記録した
