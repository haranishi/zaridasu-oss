## 個人情報保護委員会への報告 / 本人通知の判断 ⚠️要確認

> 以下は一般的な整理であり**断定ではない**。**該当性・閾値・期限・記載事項は対応時に必ず公式（個人情報保護委員会）で確認**し、迷えば専門家に相談する。

### 報告義務のトリガ（類型・概要）

個人データの漏えい等のうち、一定の類型に当たる場合は個人情報保護委員会への**報告義務**が生じ得るとされる。代表的な類型の考え方:

| 類型 | ザリダスでの当てはめ例 |
|---|---|
| **要配慮個人情報を含む**漏えい等 | 該当データを意図的に集める設計ではないが、写真 / 音声 / 位置の組み合わせで機微情報を推認させ得る場合は慎重に判断 |
| **財産的被害が生じるおそれ**がある漏えい等 | 決済情報は保持していない。ただし可能性を否定する前に確認 |
| **不正の目的による**おそれがある漏えい等（不正アクセス・故意の持ち出し等） | 漏洩キー / 乗っ取り / 攻撃に起因する流出はこの類型に当たり得る（→ [01](./01-secret-leak.md)/[02](./02-account-takeover.md) 起因のとき特に注意） |
| **一定人数を超える**本人に係る漏えい等 | 大量のメール / IP / 位置情報が一度に流出した場合。**人数の閾値は最新を要確認** |

> 上記いずれかに当たる**おそれ**がある時点で、報告に向けた準備（速報の検討）を始める。**「確証が取れてから」では遅い**ことがある。

### 報告の期限（目安・⚠️要確認）

- **速報**: 漏えい等の事態を知った後、**速やかに**（概ね数日程度＝目安 3〜5 日とされることが多いが**最新を要確認**）。判明している範囲で提出し、続報で補う。
- **確報**: 原則 **30 日以内**（**不正の目的によるおそれがある**漏えい等は **60 日以内**とされる類型がある）。**日数・起算点は最新を必ず公式で確認**。
- 提出は個人情報保護委員会の**漏えい等報告フォーム**から（→ [contacts.md](./contacts.md)）。

### 本人通知

- 報告対象となる類型では、**本人への通知**（または本人が容易に知り得る状態に置く措置＝公表等の代替措置）が求められ得る。
- 通知 / 公表の**文面・タイミング・記載事項**は影響範囲が固まってから。初報の雛形は [contacts.md](./contacts.md) §4-2。**断定・補償の確約は入れない**。

### 判断フロー（迷ったらこの順）

```
漏れた(疑い)？ ── No → 記録だけ残してクローズ（誤報の経緯も記録）
   │ Yes
   ▼
種別・人数・経路・不正目的の有無を特定（保守的に）
   │
   ▼
上のトリガ類型のいずれかに当たる「おそれ」？ ── 迷う → 個人情報保護委員会 / 専門家に相談（無料）
   │ Yes（おそれあり）
   ▼
速報の準備を開始（速やかに）→ 確報（期限内）→ 本人通知 / 公表の要否と文面を確認
```
