## A. 一般ユーザーのアカウント乗っ取り

### 封じ込め（本人 / サポートとして）

1. **パスワード変更**（推測されない強固なものへ）。
2. **全セッションからログアウト**（他端末・他ブラウザの既存セッションを無効化）。
   - Supabase Auth は管理側からの強制サインアウトが可能。対象ユーザーの refresh token を失効させる（Dashboard → Authentication → 該当ユーザー、または Admin API）。
3. **MFA を再設定**（使っていれば再登録。攻撃者が登録した要素があれば削除）。
4. **連携している OAuth アプリ / 外部連携を見直す**（Google 連携等。攻撃者が追加した連携を解除）。
5. **同じパスワードを使い回している他サービスも変更**（漏洩前提で）。

### 影響範囲

- そのユーザーが見られた範囲（自分の投稿・プロフィール・メール）に攻撃者が触れた可能性。
- 投稿の改ざん / 削除、なりすまし投稿・コメントの有無を確認。
- ユーザーのメール（`auth.users.email`）等の PII が見られた可能性があれば [04-personal-data-breach.md](./04-personal-data-breach.md) の判断へ。
