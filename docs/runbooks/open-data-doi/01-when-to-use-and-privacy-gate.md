## いつ使うか

- 公開データセット（`/dataset` の CSV / GeoJSON）の**バージョン付きスナップショット**を学術リポジトリへ登録して DOI を取りたいとき
- 既存 DOI 版に対して**大きめの更新**（収録期間の延長・列追加・粗化方針変更など）を反映して新バージョン DOI を発行したいとき
- 卒論・論文・他研究からデータセットを正式引用できるようにしたいとき

> 日次の CSV/GeoJSON 更新（`revalidate=86400`）は自動で行われる。本手順は **「特定時点のスナップショットを固定し DOI を振る」** ためのものであり、毎日実行する必要はない（節目・公開時・大改訂時のみ）。

## 最重要（実行前に必ず確認）

DOI を振ったスナップショットは**取り消せない**前提で扱う。一度公開した版に PII や生座標が混入すると恒久的な事故になる（DOI・キャッシュ・第三者のコピーに残り回収不能）。**アップロード前に下記「事前確認（プライバシー）」を必ず通すこと。**

- PII（`user_id` / メール / `reporter_ip` / 自由記述 `comment` / `photos`）が含まれていないこと
- 座標が**粗化済み**（生 lat/lng でない）こと
- `status = 'approved'` のデータのみであること

これらはコード（`src/app/dataset/zaridasu.csv/route.ts` の `fetchPublicDataset` / `coarsenCoord` / `SELECT_COLUMNS`）で機械的に保証しているが、**スナップショットでは人手で再確認する**（粗化の最後の砦）。
