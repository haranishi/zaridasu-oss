# 🦞🐸 ザリダス — プロジェクト背景

「ザリダス」は、秋田県の豊かな自然を守るため、市民の力で外来生物の分布を明らかにするプラットフォームです。

## 1. 開発の動機
秋田県には、鳥海山や雄物川、八郎湖など、美しい水辺の生態系が広がっています。しかし現在、その豊かな多様性が**アメリカザリガニ**や**ウシガエル**といった外来生物の脅威にさらされています。

かつて食用や鑑賞用として持ち込まれたこれらの生物は、驚異的な繁殖力で生息域を広げ、在来の希少種（メダカ、サンショウウオ、水生昆虫など）を捕食し、環境を激変させています。

## 2. 解決したい課題
現在、外来種の調査には以下のような壁があります：

- **情報の断片化**: 目撃情報はあっても、個人や一部の専門家の間に留まり、地域全体の実態が見えにくい。
- **調査コスト**: 行政や専門家だけで全県的な分布をリアルタイムに把握するのは困難。
- **被害の深刻化**: 「農業被害（あぜ道への穴あけ等）」も報告されているが、迅速な対策に繋がっていない。

## 3. プロジェクトの目的
ザリダス（Zaridasu）は、**「市民参加型（シチズン・サイエンス）」**のアプローチで、これらの課題を解決します。

1. **情報の可視化**: 誰もが簡単にスマートフォンから投稿でき、地図上でリアルタイムの分布を共有。
2. **データの蓄積**: 季節ごとの推移やホットスポットの特定を行い、効果的な駆除計画の策定を支援。
3. **認識の向上**: 投稿や統計を通じて、地域住民が外来種問題（2023年のアメリカザリガニ規制を含む）を自分ごととして捉えるきっかけを作る。

## 4. 目指す未来
私たちの目標は、外来生物を単に「排除する」ことだけではありません。

データの力で被害を最小限に抑え、秋田の次世代に「ザリガニばかりの池」ではなく、**「多様な生き物が息づく豊かな水辺」**を引き継いでいく。

市民一人ひとりの「目」が集まって、秋田の自然を守る大きな盾となる。それが「ザリダス」のビジョンです。
