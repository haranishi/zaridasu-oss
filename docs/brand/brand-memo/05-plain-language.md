## 6. やさしい言葉の Do / Don't（文例）

`docs/archive/lp-copy.md` の言い換え表より。むずかしい言葉は、やさしい言いかえを初出で添える。

| ✕ つかわない | ○ つかう |
|---|---|
| 市民科学プラットフォーム | みんなでつくる生きものマップ |
| 生態系 | 秋田の自然 / 生きものたち |
| 目撃情報・分布 | 「見つけた」の報告 / どこにいるか |
| 外来生物 | もともと日本にいなかった生きもの（初出で言い換えを添える） |
| データを投稿してください！ | 見つけたら、のせてみませんか |
| エラーが発生しました | うまくいきませんでした。もう一度ためしてみてください |

**良い文の例**: 「写真がなくても大丈夫です。『見かけた』だけでも大切な報告になります。」
**悪い文の例**: 「目撃情報の投稿には位置データの登録が必須です！」（むずかしい・命令・ビックリマーク）
