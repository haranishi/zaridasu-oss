## 2. 色覚多様性・コントラスト（誰にでも区別できる）

下敷き: `02_notes/デザイン基礎/データ可視化の基礎.md`（色覚バリアフリー・Wong パレット）。

### 主役 2 種は「色だけ」に依存しない（FR-224-03）

- 旧 `american=#DC2626`（赤）/ `bullfrog=#16A34A`（緑）は **赤×緑**で P/D 型色覚に最も識別困難だった。
- **Wong 色覚安全パレットの「青×オレンジ」へ変更**：
  - アメリカザリガニ = **青 `#0072B2`**（`--chart-1` / `--species-american`）
  - ウシガエル = **オレンジ `#D55E00`**（`--chart-2` / `--species-bullfrog`）
- 色に加えて **形 + グリフ** を持たせる（`SPECIES.shape` / `SPECIES.glyph`）：
  - 地図マーカー＝雫型（ザ）/ 角丸四角（ガ）で形が異なり、中央に白縁グリフ。**白黒でも判別可能**。
  - 凡例＝色＋形＋グリフ＋種名を併記。
- データ可視化パレットは `--chart-1…7`（Wong 順）。赤×緑・緑×黄の素朴な対比を避ける。

### 状態は「色 + アイコン + テキスト」の 3 点セット（FR-224-05）

- 成功＝`--color-success`、警告＝`--color-warning`、エラー＝`--color-error`、情報＝`--color-info`。
- 必ずアイコン（✅/⚠️/⛔ や lucide）とテキストを併記する。`Toast` がリファレンス実装。
- 緑×赤・緑×黄の「色のみ」対比をやめる（基調は青×オレンジ）。

### コントラスト基準（FR-224-07）

- テキスト **4.5:1 以上** / UI 部品・グラフ要素 **3:1 以上**。
- `themeClasses.ts` の `faint()` は旧 `text-gray-400`(≈2.8:1) をやめ `--color-text-faint`(≈4.6:1) を返す。
  これを使う既存箇所はトークン調整だけで自動的に底上げされる。
- グラフのトラック/軸ラベルはダーク非対応の `#f3f4f6`/`#d1d5db` をやめ、
  `--chart-track`（=`--color-border`）/ `--color-text-faint` を使う。

### 検証手順（NFR-224-03）

1. **グレースケール変換**で 2 種・状態が判別できるか（情報が色だけに乗っていないか）。
2. **WebAIM Contrast Checker** 等でテキスト 4.5:1 / UI・グラフ 3:1。
3. **色覚シミュレータ（P 型・D 型）**で 2 種・状態が区別できるか。
