# ザリダス 1枚ブランドメモ

> このメモが、ザリダスのブランド表現の唯一の正本（Single Source of Truth）です。
> UI・OGP・通知・SNS・LP のすべては、この1枚と矛盾しないように作ります。
> 関連: 確定コピー方針は `docs/archive/lp-copy.md`。色のCSS変数化・コントラスト/色覚対応の実装は REQ-224 が担当します。

ザリダスは、秋田の水辺で見つけた生きもの（アメリカザリガニ・ウシガエル）を、スマホで撮ってのせるだけで地図にできる、だれでも無料で使えるサービスです。

---

## 主要な決定事項（要点）

- **アーキタイプは「庶民（The Everyman）」**。専門家ではなく「秋田の自然が好きなふつうの人」の距離感で話す。
- **「大学」「研究室」「卒業研究」「研究プロジェクト」はブランド表現で一切使わない**。学生がつくったことは `docs/archive/lp-copy.md` ⑤の表現の範囲だけで伝える。
- **です・ます調／むずかしい言葉なし／ビックリマークなし／数値は実データだけ**。Voice は 4 言語（ja/en/ko/zh）共通の判断基準。
- **色の配分は 70 / 25 / 5**。主色はブランド赤 `#dc2626`。ウシガエルの緑 `#16A34A` は種別を見分けるデータ色で、ブランドの面には使わない。
- **書体は 2 つだけ**（和文＝OS 標準ゴシックスタック、ラテン・数字＝Inter）。Web フォントの追加読み込みは本 REQ では行わない。
- **マスコットのドミナントシェイプは丸、識別フックはハサミと尾扇の 2 つ**。絵文字は使わずパスで描く。
- **16〜48px は単純化シンボル、64px 以上はフルマスコット**（シルエットテストで 20px はフル版が識別不能と判定）。
- **色の CSS 変数化・コントラスト / 色覚多様性の担保は REQ-224 が担当**（このメモでは扱わない）。`/api/og` の実装更新は REQ-027 / REQ-042、空状態 UI の実装は REQ-222 へ引き継ぐ。
