# ザリダス デザインガイド（タイポ・余白・色トークン運用）

> このガイドは **REQ-224** が担当する「実装の運用ルール」です。
> ブランドの正本（公式 HEX・書体方針・ロゴ規定）は `docs/brand/brand-memo.md`（REQ-225）が Single Source of Truth。
> ここでは重複させず、brand-memo を**実装トークンに落とし込む際の運用ルール**だけを補完します。
> 色・余白・サイズの値の正本は `src/app/globals.css` の CSS カスタムプロパティ、
> Tailwind はそれを `var(--…)` 参照します（`tailwind.config.js`、NFR-224-04: 二重定義しない）。

---

## 主要な決定事項（要点）

- **値の正本は `src/app/globals.css` の CSS カスタムプロパティ**。Tailwind は `var(--…)` で参照するだけで、二重定義しない（NFR-224-04）。
- **配分は 60-30-10**（ベース / メイン / アクセント）。アクセントは**主 CTA 専用の 1 色**で、`btnPrimaryCls` だけが使う。
- **赤を「なんとなく」使わない**。ブランド・エラー・種色のどれなのかを意識し、対応するトークンを選ぶ。
- **主役 2 種の色を赤×緑から青×オレンジへ変更**（Wong 色覚安全パレット）。アメリカザリガニ = `#0072B2`、ウシガエル = `#D55E00`。赤×緑は P/D 型色覚で最も識別困難だったため。
- **情報を色だけに乗せない**。種別は色＋形＋グリフ、状態は色＋アイコン＋テキストの 3 点セット。
- **コントラストはテキスト 4.5:1 / UI・グラフ要素 3:1 以上**。`faint()` はトークン経由にしたので既存箇所も自動で底上げされる。
- **本文 16px・行間 1.5・1 行 35〜50 字**。情報を担う要素は 14px 以上、12px は補助メタ情報のみ。
- **余白は 8 の倍数に寄せ、内側の余白 ≤ 外側の余白**にする。
- **ダークモードは `.dark` クラスのトグルのみ**（JS 再計算なし＝ランタイムコストゼロ）。
