# 紹介・資料・補助画面：迷ったときの入口

[画面ガイドへ戻る](README.md)。アプリを知る画面と、利用中に必要になる資料・手続きをまとめます。

## アプリと生きものを知る

| 画面 | 誰が何を知るか | 次に進む先 |
|---|---|---|
| `/lp` 紹介ページ | 初めての人が、何に使えるアプリかを知る | 地図や参加の入口 |
| `/about` アプリの説明 | 目的・使い方・データの活用を読み直す | 地図や関連資料 |
| `/species/[species]` 種の説明 | アメリカザリガニ・ウシガエルについて読む | 対象種の地図や記録 |
| 初回案内 | 地域を選び、地図の意味を知って操作を始める | [地図・投稿](account.md) |

紹介ページ、参照資料、初回案内は別の役割です。
`/lp` を読まなければ地図を使えない、という一本道にはしていません。

## 利用条件と公開範囲

`/terms` は利用規約、`/privacy` は個人情報とデータの扱いを説明する画面です。
投稿・アカウント・位置情報・研究利用の条件を知りたい場合に確認します。
開発者向けの実装上の説明は [位置の現行仕様](../current/privacy.md)、利用者向けの本文は各画面を参照してください。

## 認証とメールの手続き

| 画面 | 役割 |
|---|---|
| `/auth/callback` | 確認メールや認証から戻り、処理や再設定へ進む。[認証ガイド](account.md) |
| `/u/unsubscribe` | メールから開き、カテゴリまたは全体の配信停止を反映する |

配信停止はログイン不要ですが、メールリンクの識別情報が必要です。
URLを一般向けの例として転載するときは、実際の配信停止tokenを含めません。
メールとPushの設定・実際に参照する購読列は異なるため、[通知の契約](../current/notifications.md) も確認します。

## 通信不能・見つからない・表示エラー

対応ブラウザでは、インストールの案内からホーム画面への追加へ進めます。端末やブラウザによって利用できる操作が異なります。
インストール案内は画面内のバナー等で、独立したページではありません。

| 状態 | 表示の役割 |
|---|---|
| `/offline`・オフライン案内 | 通信できないことと、使える控え・送信待ちの確認先を示す |
| 404 | URLや対象を見つけられなかったことを示す |
| 取得エラー | 再試行できるよう、通信失敗を空の結果と区別する |
| 画面の表示エラー | 復帰や再読込の入口を用意する。URL固有の新しい画面ではない |

圏外の案内が表示されても、すべての記録や地図タイルを端末に保存してあるとは限りません。
端末の下書きとサーバー保存の違いは [本人の活動](personal.md)、仕組みは [オフライン設計](../architecture/offline.md) を参照してください。
