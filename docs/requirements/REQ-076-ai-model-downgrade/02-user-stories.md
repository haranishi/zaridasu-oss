## ユーザーストーリー

### US-076-01: 開発者として安全にモデルを切り替えたい
**As a** 開発者,
**I want to** 評価データセット上で複数モデルを比較し、許容範囲内なら本番に適用したい,
**So that** 精度低下を最小化しつつコストを下げられる.

**受け入れ条件:**
- [ ] AC-1: 切替候補モデル（少なくとも 2 つ：Flash-Lite, Flash 8B 等）の比較レポートが存在
- [ ] AC-2: 各モデルの precision / recall / 推定コスト / 平均レイテンシが一覧化されている
- [ ] AC-3: 切替後 7 日間は元モデルへの即時 rollback 手順がドキュメント化されている

**優先度:** 高
**見積もり:** S

### US-076-02: 運用者として preview 依存リスクを除去したい
**As a** 運用者,
**I want to** `analyze-image` のモデルが preview 版（突然提供終了の可能性あり）から GA 版に変わってほしい,
**So that** 突然の API エラーで画像判定が完全停止するリスクを回避したい.

**受け入れ条件:**
- [ ] AC-1: `analyze-image/index.ts:29` のハードコードが解消
- [ ] AC-2: 環境変数 `GEMINI_IMAGE_MODEL` で制御
- [ ] AC-3: デフォルトは GA 版モデル（`gemini-2.5-flash-lite` 等）

**優先度:** 高
**見積もり:** XS
