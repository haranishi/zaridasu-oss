## 1. 要件概要

### 背景・目的
ザリダス（zaridasu.com）は現在、ルート `/` が地図アプリ本体（HomeShell → HomeInteractive）であり、初めて訪れたユーザーは**サービスの価値・目的・使い方を理解する前に、いきなり操作画面に放り込まれる**。広告・SNS・チラシ等からの流入では、文脈を知らない訪問者が「何のサイトか分からない」まま離脱するリスクが高い。

本要件では、アプリ本体の前段に**価値訴求 → 信頼形成 → 行動喚起**の順で構成されたマーケティングLPを `/lp` に新設し、新規訪問者のコンバージョン（会員登録・アプリ閲覧）を最大化する。

### コンバージョン目標（合意済み）
| 優先 | CV目標 | 計測イベント |
|---|---|---|
| 主CV | **新規会員登録**（LP経由のサインアップ） | `lp_cta_signup` → `sign_up`（GA4） |
| 副CV | **アプリ閲覧**（地図を見る） | `lp_cta_map` |

### スコープ
- `/lp` ルートの新設（Next.js App Router、静的生成）
- LP内セクション一式（ヒーロー / 課題共感 / 特徴 / 使い方3ステップ / 実績・社会的証明 / FAQ / 最終CTA）
- LP → アプリへの導線（会員登録モーダル直接起動・地図閲覧）
- GA4/GTM によるCV計測（CTAクリック・スクロール深度・LP経由登録のアトリビューション）
- SEO/OGP/JSON-LD/サイトマップ登録
- レスポンシブ対応（モバイルファースト：広告・SNS流入はモバイル比率が高い想定）

### 対象外（明示的に除外）
- ルート `/` の構成変更（地図アプリのまま**現状維持**。合意済み）
- 研究者・行政向け問い合わせフォーム（CV目標から除外と合意。将来の別REQ）
- LPのA/Bテスト運用（基盤連携の準備のみ。実験設計は REQ-175 の実験測定基盤側で別途）
- 多言語版LP（初期リリースは **ja のみ**。en/ko/zh は将来対応 — 後述 NFR-176-06）
- 広告出稿・クリエイティブ制作自体

### 前提条件・制約
- 技術: Next.js 15 App Router / React 19 / Tailwind CSS 3 / lucide-react / Supabase（既存スタック厳守）
- デザイントークン: 既存 `tailwind.config.js` の primary（red系 `#dc2626`）・Inter フォント・ダークモード（`dark:` クラス）・`prefers-reduced-motion` 尊重
- LPは**ログイン不要・誰でも閲覧可**（middleware の保護対象 `/dashboard` `/admin` に含めない）
- パフォーマンス: 静的生成（`force-static` または ISR）。地図・Leaflet 等の重量ライブラリは**LPに読み込まない**
- 実績数値（投稿数等）はビルド時/ISR時取得とし、クライアントから直接DBを叩かない
