## 6. API仕様

### API-176-01: LP実績数値の取得（サーバー内部・ISR時）
- **Method/形態:** Supabase クエリ（RSCのサーバーサイドで実行。公開APIエンドポイントは新設しない）
- **認証:** anon キー（RLSで閲覧可能な範囲の集計のみ）
- **取得内容:**
  ```
  total_posts:  承認済み投稿の総数
  total_users:  公開プロフィールを持つユーザー数（または投稿者ユニーク数）
  municipalities: 25（定数でよい）
  ```
- **実装方針:** 既存の集計RPC（REQ-147〜164 で導入済みの集計RPC群）に流用可能なものがあればそれを使用。なければ `count` クエリ2本（`head: true, count: 'exact'`）で足りる。**新規RPC作成は原則不要（要確認）**
- **Response（内部）:** `{ totalPosts: number, totalUsers: number } | null`（null時は LpStats 非表示）
- **キャッシュ:** ルートの `revalidate = 86400` に従う

### API-176-02: 新規エンドポイント
- **なし。** LPはフォーム送信・書き込みを一切持たない
