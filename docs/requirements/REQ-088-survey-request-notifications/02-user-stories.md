## ユーザーストーリー

### US-088-01: 近隣ユーザーとして新規依頼に気づきたい
**As a** 同一市区町村に住む opt-in ユーザー,
**I want to** 新しい調査依頼が立った時にメール通知が届く,
**So that** アプリを開かなくても近所の依頼に気づける.

**受け入れ条件:**
- [ ] AC-1: 自分の市区町村と一致する依頼が立つと 30 秒以内にメールが届く
- [ ] AC-2: メール本文に種別 / 緊急度 / 依頼へのリンクが含まれる
- [ ] AC-3: opt-out している場合は届かない
- [ ] AC-4: 自分が立てた依頼の通知は自分には届かない

**優先度:** 高 ／ **見積もり:** M

### US-088-02: 依頼者として結果投稿に気づきたい
**As a** 依頼を立てた投稿者,
**I want to** 自分の依頼に結果投稿があった時にメール通知が届く,
**So that** すぐに状況確認できる.

**受け入れ条件:**
- [ ] AC-1: status が `open → responded` に遷移した瞬間に通知メールが送信される
- [ ] AC-2: 結果投稿者の display_name と冒頭文が含まれる
- [ ] AC-3: opt-out していない依頼者にのみ送信

**優先度:** 高 ／ **見積もり:** S

### US-088-03: ユーザーとして通知を停止したい
**As a** メール通知を望まないユーザー,
**I want to** 設定画面で通知を opt-out できる,
**So that** メール疲れにならない.

**受け入れ条件:**
- [ ] AC-1: 設定画面に通知 opt-out トグルがある
- [ ] AC-2: メール本文末尾に「通知を停止する」ワンクリックリンクがある
- [ ] AC-3: opt-out 後は新規通知が届かない

**優先度:** 中 ／ **見積もり:** S

### US-088-04: 依頼者として応答スパムでメール疲れしたくない
**As a** 依頼者,
**I want to** 応答通知は 1 日 1 通ダイジェストで届く,
**So that** 連投されてもメールが大量に飛んでこない.

**受け入れ条件:**
- [ ] AC-1: 応答通知は当日内に発生したものをまとめて 1 通で送る
- [ ] AC-2: 結果投稿通知（重要度高）は即時、応答通知（軽量）はダイジェスト

**優先度:** 中 ／ **見積もり:** M
