## 非機能要件

### パフォーマンス
- 即時通知は **依頼作成 / 結果投稿から 30 秒以内** に送信完了
- 1 イベントで 100 件配信する場合でも Edge Function は 5 秒以内に完了
- ダイジェストは深夜帯（JST 03:00 など）に実行

### セキュリティ
- メールに **位置情報の生座標 / 個人特定情報を含めない**（市区町村粒度まで）
- unsubscribe トークンは JWT で署名 + 短い TTL（30 日）
- Resend API キーは Edge Function 環境変数のみで管理、ログに残さない
- pg_net Webhook 用の SERVICE_ROLE_KEY は Edge Function 内部のみで使用

### 信頼性
- Resend API 失敗時は audit_logs に記録、依頼作成 / 応答自体は成功させる（フェイルオープン）
- 同一 event_id を二重受信した場合の重複送信を防ぐ
- スパム判定避けるため 1 ユーザーへの送信は 1 日 5 通までキャップ

### コスト
- Resend Free tier（3000 通/月）を想定。超えたら Paid に移行
- 同一市区町村への一斉送信は BCC か個別送信（個人情報配慮で個別送信推奨）
