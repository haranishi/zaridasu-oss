## 背景

### 問題A: 1440pxにデスクトップナビが無い 🔴

モバイル用ボトムタブが **386px幅で画面下中央に浮いている**（1440・768とも）。
**第2周（REQ-320）でボトムナビを全ページへ広げたときに、レスポンシブ分岐を入れなかった副作用。**
`BottomNav.tsx` は `max-w-md mx-auto` で中央寄せされるため、広い画面では「浮いた島」になる。

### 問題B: コントラスト未達が残っている 🔴

**うち「JOIN US」は第2周でも 2.84:1 として指摘されていたが、第3周・第4周の要件に入れ損ねた。**
直せなかったのではなく**狙わなかった**もの。本周で必ず消す。

| 箇所 | 前景/背景 | 実測 | 必要 |
|---|---|---:|---:|
| LP 最終CTA「JOIN US」 | `#EAAFAF` / `#C93636` | 2.77:1 | 4.5:1 |
| LP マーキー | `#EC8888` / 白 | 2.49:1 | 4.5:1 |
| LP マーキー | `#D1D5DB` / 白 | 1.47:1 | 4.5:1 |

原因は**白背景用の eyebrow スタイルを赤背景に流用している**こと。modifier を分けて解く。

### 問題C: 地図ホームのFVに「何の地図か」が書かれていない 🔴

ヘッダーは「ザリダス」だけ。初回シートは「どんなサービス？」と**問い返す**だけで答えていない。
シートを閉じると説明が完全に消える。

### 問題D: 種別色がページごとに違う 🟡

`trends` のドーナツは 青`#0072B2`/橙`#D55E00` なのに、`about` の外来生物法カードは
**同じ2種がピンク/アンバー**。`constants.ts` の `SPECIES[].color` と CSS が繋がっていない。
また `trends` のデータバーがCTAと同じブランド赤で、「量」と「行動」が同色になっている。

### 問題E: 390pxで44px未満のタップ要素が残っている 🟡

地図ズーム40px・トグル38px・検索38px。「あとで」「今は不要」「ログイン」「今後表示しない」は
枠線も背景も無く、押せると分からない。

### 問題F: 「壊れて見える」表示が残っている 🟡

- `dataset` に「ここにDOIを掲示します」という**プレースホルダー文が本番に出ている**
- `trends` の12ヶ月グラフに**ベースライン（0の軸線）も目盛も無い**。11列が空で1本だけ立っている

## 機能要件

- **FR-323-01**: **1024px以上でヘッダー水平ナビに切り替え、ボトムタブを消す。**
  ナビ項目は現行の5つ（地図・トレンド・投稿・ランキング・マイページ）。
  1023px以下は現行のボトムナビを維持する。`isBottomNavVisible` の対象パス判定は変えない。
  `BottomNavSpacer` も同じブレークポイントで無効化し、下部に無駄な余白が残らないようにする。
- **FR-323-02**: 問題Bの3点を是正する。LPの eyebrow は**白背景用と赤背景用で modifier を分ける**
  （赤背景上は白 `#FFFFFF` = 5.17:1）。マーキーの2色も4.5:1以上へ。
- **FR-323-03**: 地図ホームのFVに、**シートを閉じても消えない説明行**を常時表示する。
  「秋田の外来生物 目撃マップ」相当の一言で、390/768/1440すべてで見えること。
  地図の可視領域を圧迫しないよう、ヘッダー内かヘッダー直下の1行に収める。
- **FR-323-04**: 再訪時シートの見出しを、**投稿依頼の前にサービスの中身を一言で言う**形にする
  （現状は「どんなサービス？」と問い返すだけ）。
- **FR-323-05**: 種別色を**CSS変数として単一定義**し、`about`・`trends`・地図凡例のすべてで同じ色を使う。
  `constants.ts` の `SPECIES[].color` と CSS 変数の一致をテストで結ぶ（REQ-322 で `SURVEY_STATUS` に
  対して同じことをしている。それに倣う）。
- **FR-323-06**: **ブランド赤をCTAとリンクだけに限定**し、データバー・グラフ要素から外す。
  データバーは **`#4B5563`（白地 7.56:1）の濃い無彩色**にする。
  > **なぜ無彩色か（第3周と往復しないための記録）**: 第1周は `#D6D9DF`（1.1:1）で「読み込み失敗に見える」
  > と減点され、第3周でブランド赤にしたら第4周は「量と行動が同色」と減点された。
  > 問題は**薄すぎたこと**であって無彩色であること自体ではない。濃い無彩色なら両方を満たす。
  > 評価者は「量＝`#0072B2`」を提案しているが、**その青はアメリカザリガニの種別色**なので採用しない
  > （凡例の「青＝アメリカザリガニ」と衝突する）。
- **FR-323-07**: 390pxで**すべてのタップ要素を44×44px以上**にする（地図ズーム40px・トグル38px・検索38px）。
  REQ-203 の擬似要素方式（見た目は変えずヒットエリアだけ広げる）を前例にしてよい。
- **FR-323-08**: 「あとで」「今は不要」「ログイン」「今後表示しない」に**枠線または背景**を与え、
  押せると分かる形にする。離脱手段は **× ＋ 1つ**に整理する（現状は複数あって迷う）。
- **FR-323-09**: `dataset` から「ここにDOIを掲示します」という**プレースホルダー文を削除**し、
  DOI未発行の間は暫定引用形式だけを通常の本文として提示する。
- **FR-323-10**: `trends` の12ヶ月グラフに**ベースライン（0の軸線）と最大値の目盛**を入れる。
  データが1ヶ月しか無い場合は「3月に8件」を主役にした表示（数値＋説明文）に切り替える。
- **FR-323-11**: 地図のアイコンのみのボタン（ズーム・レイヤー・現在地）に `aria-label` があることを確認し、
  無ければ付ける。
- **FR-323-12**: FR-323-02/05/06 で変えた色を `src/lib/__tests__/contrast.test.ts` に追記する。
