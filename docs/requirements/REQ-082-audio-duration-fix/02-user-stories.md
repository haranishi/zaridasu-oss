## ユーザーストーリー

### US-082-01: 投稿者として録音直後に時間を確認したい
**As a** 投稿者,
**I want to** 録音をやめた瞬間に「3.4 秒」「8.0 秒」のように長さが表示される,
**So that** 録音を聞き返さなくても十分な長さで録れたか即判断できる.

**受け入れ条件:**
- [ ] AC-1: 録音停止 → preview audio に正しい duration が表示される（`0:00 / 0:00` にならない）
- [ ] AC-2: 録音時間ヘッダ（`X.X 秒`）と inline player の duration がほぼ一致

**優先度:** 高
**見積もり:** S

### US-082-02: 自分の投稿で正しい再生時間を見たい
**As a** 投稿者,
**I want to** マイページで自分の投稿音声の duration が正しく表示される,
**So that** いつ録音した音声がどの長さか一覧でわかる.

**受け入れ条件:**
- [ ] AC-1: 録音由来の webm 音声に正しい duration が表示される
- [ ] AC-2: 「音声の読み込みに失敗しました」のフォールバックメッセージは、**実際に再生不可能な場合のみ**表示される
- [ ] AC-3: 既存の古い投稿（duration 未 patch）でも seek workaround で表示が出るか、もしくは出なくても再生は可能

**優先度:** 高
**見積もり:** S

### US-082-03: ライブラリ追加でバンドルサイズを膨らませたくない
**As a** 開発者,
**I want to** webm duration fix のための追加 dep が最小サイズに留まる,
**So that** モバイル UX に影響しない.

**受け入れ条件:**
- [ ] AC-1: 追加 dep は **gzipped 5KB 以内**
- [ ] AC-2: `next build` の First Load JS が +10KB 以内

**優先度:** 中
**見積もり:** XS（fix-webm-duration は 2KB gzipped）
