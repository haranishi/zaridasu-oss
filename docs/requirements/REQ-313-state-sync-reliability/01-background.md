## 背景

REQ-192 / REQ-193 / REQ-273 で「失敗を空状態や成功に見せない」方針は確立している。本 REQ は**その方針から個別に漏れた4箇所**を扱う。共通する失敗の形は次の2つである。

1. **失敗を「0」や「空」として表示する**（`count || 0` / `error ? [] : …`）。ユーザーは誤った値を真値だと信じる。
2. **サーバーへ反映されていない状態を UI で確定として見せる**。とくに通知の OFF 操作では、UI が OFF なのに通知が届き続ける。

模範実装は同じ画面の中にある。ランキングの兄弟タブ（`RankingPage.tsx:188-191` の `diversityError` / :357-360 の `rankingError`）は `LoadErrorState` ＋再試行を出しており、**品質タブだけが REQ-192 の修正から漏れている**。
