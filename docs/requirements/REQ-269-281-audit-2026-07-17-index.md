## 観点別の主要発見（要約）

### セキュリティ
- 監視系Edge Function 2本（`notify-ai-anomaly`/`notify-gemini-key-failure`）だけ webhook 認証が無く、`notify-ai-anomaly` はユーザーUUID入り内部メトリクスを応答で返す（REQ-270）
- pg_net 送出側（migrations内のSQLラッパ全数）が `x-webhook-secret` を送らないため、REQ-240 の運用手順（secret設定→enforce有効化）を実行すると通知系10関数が全て401で無言停止する（REQ-270）
- `/api/nearby-water` は認証・恒久レート制限なしの外部Overpassプロキシ（REQ-281 に運用検討として記載）
- 本番依存の既知脆弱性: Next.js 15.5.14（Middlewareバイパス GHSA-492v-c6pp-mqqv / GHSA-267c-6grr-h53f、RSCキャッシュポイズニング、画像最適化DoS 等）、ws 8.19.0、postcss 8.4.31（REQ-269）
- クリーン確認済み: middleware認可・RLS本体・XSS・CSRF・SW・環境変数露出・オープンリダイレクト

### UX・アクセシビリティ
- ドロワー「調査を依頼する」が Collection/Ranking/Trends/Dashboard の4画面で存在しない `/survey` に遷移し404（REQ-271）
- トレンド画面はフェッチ失敗時に「全部0件」の空グラフを無言表示（`useStats` の error を破棄）。ホーム投稿一覧の失敗も消えるトースト1回のみ・日本語ハードコード（REQ-273）
- 調査依頼「クローズ」が確認なし・catchなし・二重押下防止なし（REQ-273）
- i18n半翻訳: 調査依頼・地域・マイページ・トレンド・Footer・AudioRecorder・404等で言語切替後も日本語が残る。date-fnsロケール `ja` 固定4ファイル（REQ-277）

### コード品質
- 観測日の既定値/max が UTC由来で JST 0:00-8:59 に「今日」を選べない。天気の forecast/archive 分岐・CSVファイル名・DateRangePicker表示も同根（REQ-272）
- `usePostList` にAbortControllerが無くフィルタ高速切替で古い結果が勝つ。逆ジオコーディング/天気も stale 上書き。AudioRecorder のカウントダウン interval がクリーンアップ漏れ（REQ-274）
- コメント送信の同期二重送信ガード欠如、AI再解析トリガー失敗の無言破棄（REQ-273/274）
- 投稿フロー本体（usePostForm のオーケストレーション）に直接テストなし（REQ-281 に記録）

### SEO・PWA
- `/privacy`・`/terms` が noindex なのに sitemap 掲載の自己矛盾（REQ-275）
- 実装済みの動的OG画像 `/api/og` がどのページからも未配線（REQ-276）
- ホーム/ランキングに h1 なし、トレンドは h2 始まり。`/dataset` が `<main>` 二重入れ子。`/requests` canonical 欠如（REQ-275）

### パフォーマンス
- DrawerMenu が閉じたまま全ページ遷移のたびに進捗RPCを発火（REQ-278）
- `/post/[id]` だけ AuthModal 静的import（他は dynamic 統一済み）（REQ-278）
- ランキングが表示1タブに対し3系統RPCを一斉フェッチ（REQ-278)
- ホットテーブル（posts/comments/likes/user_profiles）のRLSが `auth.uid()`/`auth.jwt()` を行ごと再評価（`(select ...)` ラップ未適用。新しめのmigrationは適用済みで、古いコアだけ未バックフィル）（REQ-279）

### バックエンド・インフラ
- 追記専用ログ（ai_call_logs/audit_logs/lifecycle_email_log）に保持・パージ機構なし（REQ-279）
- ライフサイクルメールの冪等性が非アトミック（二重送信の窓）、notify-comment がResendエラー生文を応答に返す（宛先メール漏洩の恐れ）、analyze-image の冪等ガードがwebhookペイロード参照でGemini二重課金の窓（REQ-280）
- CI が migrations を順次適用せず schema.sql 直接適用のみ＝移行ドリフト無検知。バックアップの復元検証なし・失敗無通知。CodeQL/dependency-review は private リポで実質無効（REQ-281）
