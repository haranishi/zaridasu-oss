## ユーザーストーリー

### US-077-01: 投稿者として無駄な投稿で不快な思いをしたくない
**As a** 投稿者,
**I want to** 無音や真っ暗写真など明らかに使えない素材は投稿前に教えてほしい,
**So that** 投稿後に「却下されました」通知を受けてやり直す手間が無くなる.

**受け入れ条件:**
- [ ] AC-1: 無音音声（RMS が閾値以下）は投稿前にトーストで「音が小さすぎます」と警告
- [ ] AC-2: 録音時間 1 秒未満は投稿前に「短すぎます」と警告
- [ ] AC-3: 解像度 < 200x200 の画像は警告
- [ ] AC-4: 極度のブレ（Laplacian variance < 閾値）は警告
- [ ] AC-5: 警告は強制弾きではなく「それでも投稿する」を許可

**優先度:** 中
**見積もり:** L

### US-077-02: 開発者として AI に送るデータ量を最小化したい
**As a** 開発者,
**I want to** AI 判定に必要十分なサイズに事前圧縮してから Edge Function に送りたい,
**So that** 入力トークン数を削減し API コストを下げられる.

**受け入れ条件:**
- [ ] AC-1: 音声は 16kHz mono、Opus 32kbps へ自動変換
- [ ] AC-2: 画像は長辺 1024px、JPEG q=85 へ自動リサイズ
- [ ] AC-3: 元データは既存 bucket に保持し、AI バリアントは別 path に保存
- [ ] AC-4: Edge Function は AI バリアントを優先 fetch、無ければ元データに fallback
- [ ] AC-5: フィーチャーフラグ `AI_INPUT_COMPRESSION_ENABLED` で段階ロールアウト可能

**優先度:** 中
**見積もり:** L
