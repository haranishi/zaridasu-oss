## ユーザーストーリー（全体俯瞰）

### US-084-01: 投稿者として依頼の進捗を追跡したい
**As a** 調査依頼を立てた投稿者,
**I want to** 自分の依頼に誰が反応し、どんな結果が集まっているかを一覧で確認したい,
**So that** 依頼が放置されているかどうかが一目で分かる.

**受け入れ条件:**
- [ ] AC-1: マイページから自分が立てた依頼の一覧に到達できる
- [ ] AC-2: 依頼ごとに status / 応答数 / 関連投稿数が表示される
- [ ] AC-3: 結果投稿が来たら通知が届く

**優先度:** 高 ／ **見積もり:** L（Phase 1〜4 にまたがる）

### US-084-02: 近隣ユーザーとして依頼に気づいて協力したい
**As a** 同じ市区町村に住む別のユーザー,
**I want to** 自分の生活圏で立った調査依頼を能動的に発見できる,
**So that** 地域のコミュニティに貢献できる.

**受け入れ条件:**
- [ ] AC-1: 同一市区町村で新規依頼が立ったら通知が届く（opt-in）
- [ ] AC-2: `/requests?municipality=秋田市` のように絞り込みが可能
- [ ] AC-3: 「協力する」を押すと応答数がインクリメントされ、後で投稿者に通知が届く

**優先度:** 中 ／ **見積もり:** L

### US-084-03: 全体ユーザーとして依頼と結果のループを追える
**As a** 一般ユーザー,
**I want to** 調査依頼の詳細ページで「これに対する結果投稿」を直接読みたい,
**So that** 調査依頼が単発で終わらず、地域の生態調査ログとして蓄積される.

**優先度:** 中 ／ **見積もり:** M
