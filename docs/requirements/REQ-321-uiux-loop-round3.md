## 背景（裏取り済み）

### 問題A: 画面内の数字が説明なく食い違う 🔴

- `trends`: KPI「累計投稿数 **8件**」に対し、「報告のあった市区町村（1件）」の由利本荘市が **7件**。
  差の1件がどこへ行ったか画面から分からない（市町村未入力レコードと推測されるが**注記が無い**）。
- `species-american`: 「現在 **6件** のアメリカザリガニの報告があります」に対しリンクが **5件**。
  REQ-227 が「head-count + **最新数件**のみ」と設計しているので**リストが短いこと自体は正しい**。
  問題は**「最新5件」と言っていない**ことで、読者には数え間違いに見える。

**どちらもデータのバグではなく、ラベル（注記）の欠落。** データを弄って合わせてはいけない。

### 問題B: 色が7系統に増えている 🔴

評価者の実測で 赤・紺・緑 `#10B981`・青 `#0072B2`・橙 `#D55E00`・珊瑚 `#F7636B`/`#F05E5C`・灰・amber が同居。
このうち**青 `#0072B2` と橙 `#D55E00` は REQ-224 が定めた種別色なので廃止できない**（データ可視化専用色として維持）。
削るべきは:

- 緑 `#10B981`（`RankingPage` の `text-emerald-500`＝Sparkles・🏅・「あなた」）。REQ-224 の赤緑NGにも抵触
- 珊瑚 `#F7636B` / `#F05E5C`（`trends` の棒グラフ。ブランド赤 `#DC2626` と**別の赤**を2種使っている）
- amber 系の装飾

### 問題C: 絵文字アイコンが混在している 🟡

`trends` のKPIに 📍📅🗾 等のフルカラー絵文字。OSごとに描画が変わり、線アイコン（`lucide-react`・既存依存）と混在して統一感を壊す。

### 問題D: ボトムナビが等分でなく、FABが中央にない 🔴

`BottomNav.tsx:87` が `flex items-end justify-around` で、**子要素の幅が不揃い**
（FABは `w-14`=56px、ラベルは「地図」2文字〜「マイページ」5文字）。
`justify-around` は各要素の**周囲**に等しい余白を配るため、幅が違うと**視覚的な中心が不等間隔**になる。
実測: 390pxでラベル中心間が **62 / 66.5 / 83.5 / 94px**、投稿FABは中央から **32.5px 左**にずれる。
**第2周でナビを全ページに出したため、この欠陥がサイト全域に波及した。**

### 問題E: 1文字だけ次行に落ちる 🟡

`lp` で「…すぐ地図にの／る」「…分かっていませ／ん」が390と1440の両方で発生。
768では「秋田県の全25市／町村」と地名が割れる。

## 機能要件

- **FR-321-01**: `trends` の市区町村内訳に、合計と一致しない理由の注記を出す。
  例:「市区町村が特定できた **7件** / 累計 8件」。**データ側は変更しない**。
- **FR-321-02**: `species/[species]` の件数表記を、リストの実長と読者が照合できる形にする。
  例:「現在 6件 の報告があります（最新 5件 を表示）」。REQ-227 の head-count 方式は維持する。
- **FR-321-03**: `RankingPage` の `text-emerald-500`（Sparkles・🏅・「あなた」）から緑を廃し、
  ブランド赤またはグレースケールへ寄せる。REQ-224 の赤緑NGを守る。
- **FR-321-04**: `trends` の棒グラフの赤 `#F7636B` / `#F05E5C` を **`#DC2626`（brand-600）** に寄せる。
  1画面に3種類の赤が出ている状態を解消する。
- **FR-321-05**: `trends` KPI等のフルカラー絵文字アイコンを `lucide-react` の線アイコンに置き換える。
  **新規依存は追加しない**（`lucide-react` は既存）。
- **FR-321-06**: `BottomNav` を **5等分のグリッド**（`grid grid-cols-5`）にし、各セルで中央寄せする。
  FABが画面中央に来て、5つのラベル中心が等間隔になること。
  REQ-203 の44pxタップ域と `isBottomNavVisible` の判定は維持する。
- **FR-321-07**: `lp` の主要見出し・本文で「1文字だけ次行に落ちる」折返しを解消する
  （`text-wrap: balance/pretty` か禁則の調整。**文言を削って辻褄を合わせない**）。
- **FR-321-08**: FR-321-03/04 で変えた色を `src/lib/__tests__/contrast.test.ts` に追記する。
