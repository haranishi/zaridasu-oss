## 非機能要件

### パフォーマンス
- 権限チェックは録音ボタン押下後 **300ms 以内**に判定
- Permissions API 呼び出しは結果をキャッシュ（同セッション中の再判定省略）

### UX
- 権限拒否されてもユーザーが「詰まない」（必ず代替手段を提示）
- 文言は柔らかく、ユーザーを責めない（「許可してください」ではなく「必要な場合は…」）

### セキュリティ
- Permissions-Policy: `microphone=(self)` を維持（third-party iframe からの横取り防止）
- マイクストリームは録音停止時に確実に `stop()` で解放（既存挙動維持）
- マイクへのアクセス頻度をログに残さない（プライバシー）

### 互換性
- iOS Safari 16+ / Android Chrome 110+ / Desktop Chrome / Firefox / Edge / Mac Safari
- in-app browser は明示的に「未サポート」として扱い外部ブラウザ誘導

### アクセシビリティ
- エラー表示は `role="alert"` でスクリーンリーダーに通知
- 「許可方法を見る」モーダルは `<dialog>` または `role="dialog"` + フォーカストラップ
- キーボードのみで全操作可能
