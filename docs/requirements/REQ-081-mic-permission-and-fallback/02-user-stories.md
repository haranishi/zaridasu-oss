## ユーザーストーリー

### US-081-01: 投稿者として正常な環境ではマイクで録音したい
**As a** 投稿者,
**I want to** ブラウザの権限ダイアログで「許可」を押せば普通に録音できる,
**So that** ウシガエルの鳴き声を投稿できる.

**受け入れ条件:**
- [ ] AC-1: HTTPS で開いた一般的な PC/モバイルブラウザで「鳴き声を録音」ボタンを押すと OS/ブラウザの権限ダイアログが表示される
- [ ] AC-2: ダイアログで「許可」を押すと即座に録音が始まる
- [ ] AC-3: 「拒否」を押した場合のみ「マイク権限が必要です」表示になる（事前にアプリ側で塞がない）

**優先度:** 高
**見積もり:** XS

### US-081-02: 投稿者として権限拒否後も投稿手段を失いたくない
**As a** 投稿者,
**I want to** マイク権限が無くても、PC で別途録音した音声ファイルをアップロードできる,
**So that** 機種・ブラウザ環境に左右されず投稿できる.

**受け入れ条件:**
- [ ] AC-1: 権限拒否時、UI が自動で「ファイルを選択」モードに切り替わるか、明示的に切替案内が出る
- [ ] AC-2: ファイルアップロード経路は権限拒否の影響を受けず動作する
- [ ] AC-3: 切替後でも一度「録音する」モードに戻る選択肢が UI に残る（権限を後から許可した場合の復帰用）

**優先度:** 中
**見積もり:** S

### US-081-03: 拒否時に再設定方法が分かるようにしたい
**As a** 投稿者（権限を誤って拒否してしまった人）,
**I want to** OS / ブラウザごとの再設定手順を案内してほしい,
**So that** 自力で復帰できる.

**受け入れ条件:**
- [ ] AC-1: 拒否時のメッセージから「許可方法を見る」リンクで詳細手順モーダル / セクションを開ける
- [ ] AC-2: User-Agent から判定した想定 OS / ブラウザ（iOS Safari, Android Chrome, Mac Safari, etc.）の手順が優先表示される
- [ ] AC-3: 一般手順（全 OS 共通）も表示される

**優先度:** 中
**見積もり:** S

### US-081-04: In-App ブラウザでの混乱を避けたい
**As a** SNS 経由でアプリを開いた投稿者,
**I want to** in-app ブラウザ（LINE, X, Instagram, Facebook）で開いた場合に、外部ブラウザで開き直すよう促されたい,
**So that** マイク権限の制限事項を理解した上で行動できる.

**優先度:** 中
**見積もり:** S
