### SC-283-07: 管理・フィールド運用

- **URL:** `/admin/field`
- **用途:** セル、ミッション、安全、品質を管理する。
- テーブル／地図の2表示を用意する。
- 公開／停止は確認ダイアログと監査ログを必須とする。

### SC-283-08: オフライン送信

- **URL:** `/dashboard/offline`
- **用途:** 端末保存した観察の状態確認、再送、修正、削除を行う。

```text
+--------------------------------+
| オフライン送信             2件 |
| 通信が戻ると自動送信します     |
+--------------------------------+
| 🦞 7/25 14:32                  |
| 端末に保存済み・未送信          |
| 写真3枚  4.8MB                 |
| 次回: 通信復帰時                |
| [今すぐ送信] [内容を見る]       |
+--------------------------------+
| 🐸 7/25 13:10                  |
| 要ログイン                     |
| データは端末に残っています      |
| [ログインして再開]              |
+--------------------------------+
| 保存保護: 有効／未確認           |
| [自動送信の設定]                |
+--------------------------------+
```

**状態:**

- `queued`: 端末保存済み・未送信
- `preparing/uploading/finalizing`: 送信中。アプリを閉じても記録は残る
- `retry_wait`: 回線または一時障害。次回試行時刻を表示
- `needs_auth`: 再ログインが必要。自動削除しない
- `needs_edit`: 修正対象と理由を表示
- `needs_review`: ミッション停止等。通常投稿への切替または管理確認を案内
- `synced`: サーバー受付済み。`postId` と審査状態へ遷移
- 状態は色だけでなくアイコンとテキストで示す
