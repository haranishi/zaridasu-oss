## 3. ユーザーストーリー

### US-283-01: 近くの探索候補を見つける

**As a** 生物に詳しくない一般利用者,  
**I want to** 現在地の近くにある短時間の探索候補を地図から選びたい,  
**So that** 何をすればよいか迷わず、散歩のついでに参加できる.

**受け入れ条件:**

- [ ] AC-1: 位置許可前でも秋田県全体の探索セルを閲覧できる。
- [ ] AC-2: 位置許可後は距離・所要時間・難易度・安全条件で近隣ミッションが並ぶ。
- [ ] AC-3: 表示は「最近確認」「過去確認」「未調査」「再調査」「制限」を色・形・テキストで区別する。
- [ ] AC-4: 「今ここにいる」と断言せず、最終確認日と情報確度を表示する。

**優先度:** 高  
**見積もり:** L

### US-283-02: 安全なミッションだけを開始する

**As a** 保護者または一般利用者,  
**I want to** 私有地や危険な護岸を避け、安全条件を確認してから開始したい,  
**So that** ゲームに誘導されても危険な行動を取らずに済む.

**受け入れ条件:**

- [ ] AC-1: ミッション詳細に公開アクセス、推奨時間帯、危険事項、子ども同伴条件を表示する。
- [ ] AC-2: 初回のみ安全・法律ガイドへの同意を求める。
- [ ] AC-3: `restricted / hidden / suspended` のセルは一般ユーザーが開始できない。
- [ ] AC-4: 「危険」「入れない」「私有地だった」を送信でき、当該ミッションを一時停止候補にする。

**優先度:** 高  
**見積もり:** M

### US-283-03: 現地で迷わず証拠写真を撮る

**As a** 生物同定の初心者,  
**I want to** 必要な写真を順番に案内してほしい,  
**So that** 専門知識がなくても審査可能な記録を提出できる.

**受け入れ条件:**

- [ ] AC-1: 「全身」「ハサミ／頭部等の特徴」「周辺の水辺」の3枠を順番に案内する。
- [ ] AC-2: 画像のぶれ、暗さ、被写体不足を送信前に警告する。
- [ ] AC-3: 生物に接触せず撮影できる案内文を表示する。
- [ ] AC-4: AI判定は「候補／確度／理由」とし、確定結果と誤認させない。

**優先度:** 高  
**見積もり:** L

### US-283-04: 発見できなかった調査も貢献として残す

**As a** フィールド参加者,  
**I want to** 見つからなかった場合も調査時間と状況を記録したい,  
**So that** 努力が無駄にならず、科学的に有用な不在情報を提供できる.

**受け入れ条件:**

- [ ] AC-1: ミッション開始後、いつでも「見つからなかった」を選べる。
- [ ] AC-2: 調査時間、確認した範囲、水面の見やすさ、天候を記録する。
- [ ] AC-3: 不在は「生物が存在しない」と断定せず「条件付きの不在確認」と表示する。
- [ ] AC-4: 承認後はREQ-248の不在確認XPへ接続する。

**優先度:** 高  
**見積もり:** M
