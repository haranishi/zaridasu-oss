### SC-283-04: 3枠スキャン

- **URL:** `/field/session/[sessionId]/scan`
- **用途:** 審査可能な証拠を順番に撮影する。

```text
+--------------------------------+
| 1/3 全身を撮影                  |
| ┌────────────────────────────┐ |
| │                            │ |
| │       カメラプレビュー      │ |
| │      ガイドシルエット       │ |
| │                            │ |
| └────────────────────────────┘ |
| [✓ 全身] [2 特徴] [3 水辺]     |
| 生き物には触れず撮影してください |
|           [撮影]               |
+--------------------------------+
```

**状態:**

- camera denied: ファイル選択と権限説明
- blur warning: 撮り直し／このまま進む
- unsafe: 撮り直しを強制せず終了可能
- offline: 端末保存表示
