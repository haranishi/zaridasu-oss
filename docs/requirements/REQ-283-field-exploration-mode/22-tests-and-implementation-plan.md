## 11. テスト要件

### 単体

- セル状態遷移、鮮度、再調査期限
- 報酬プレビューと正式XPの分離
- 写真役割バリデーション
- 不在確認の最低努力量
- experiment/controlフォールバック
- i18nキー一致
- Outbox状態遷移、指数バックオフ、`Retry-After`
- 同一 `client_submission_id` の再試行と内容不一致検出
- IndexedDB v2からの後方互換移行、古い `sending` のリース回収
- 容量不足、永続ストレージ拒否、Blob保存失敗

### DB / pgTAP

- 全新規テーブルのRLS
- anonから生座標・user_idを取得できない
- 本人以外のセッションを参照・更新できない
- admin以外がミッションを公開できない
- 同一postの貢献・XPが二重付与されない
- 同一 `(user_id, client_submission_id)` からpostsが二重作成されない
- 別ユーザーの同じキーは所有者単位で分離される
- suspendedミッションを開始できない

### E2E

1. 探索マップ → ミッション → セッション → 3枠 → pending
2. 不在確認 → 調査時間 → pending
3. 管理承認 → XP／図鑑／セル／地域進捗
4. 却下 → 理由・正式報酬なし
5. 位置拒否 → 地域選択
6. カメラ拒否 → ファイル選択
7. オフライン → Outbox原子保存 → 復帰 → 自動送信 → 受付確認
8. 写真2枚目で切断 → 再起動 → 同じパスから再開 → 重複投稿なし
9. finalize成功後に応答だけ消失 → status照合 → 同じpostIdで完了
10. Background Sync非対応 → 前景復帰／起動／手動で同期
11. 認証期限切れ → `needs_auth` → 再ログイン → 同期再開
12. 容量不足／永続ストレージ拒否 → 未保存を成功表示しない
13. ミッション停止中にオフライン観察 → 記録保持 → `needs_review`
14. 別ユーザーへ切替 → 前ユーザーの写真・位置を非表示
15. restricted／suspended／期限切れ
16. reduced motion／キーボード／スクリーンリーダー
17. 通常投稿と現行地図の回帰

### 安全・プライバシー

- 公開セルから生座標を逆算できない
- `hidden` 記録がセル・通知・共有画像へ漏れない
- 夜間／悪天候／高速移動時の抑制
- 危険報告による自動停止
- EXIF除去
- 同期ログ、GA4、Sentry、Service Worker consoleへ生座標・Blob・自由記述を出さない
- server ACK前に端末データが削除されない
- server ACK後に端末のBlob・正確位置が削除される
- XSS対策（CSP、入力サニタイズ）を回帰確認し、IndexedDBを同一オリジンの信頼境界外へ露出しない
