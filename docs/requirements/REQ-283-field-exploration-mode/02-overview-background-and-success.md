## 1. 要件概要

### 1.1 背景・目的

現在のザリダスは、秋田県内のアメリカザリガニ・ウシガエル等について、市民が投稿し、地図・写真・統計・調査依頼として閲覧できる市民科学プラットフォームである。既に次のゲーム基盤が実装済みである。

- 承認済み投稿と品質に連動したXP・貢献レベル（REQ-248）
- 中核投稿を阻害しない段階解放（REQ-249）
- 種図鑑・コレクション・2D/3D水槽（REQ-250）
- 品質・多様性クエスト、進捗、解放・レベルアップ演出、通知（REQ-251）
- 品質・多様性を重視するランキング／バッジ（REQ-171、REQ-235）
- 位置公開レベル、公開座標の粗化・非公開化、EXIF除去（REQ-243）
- GPS精度、空間バイアス誘導、定点観察、介入実験（REQ-172〜175）

一方、現在の中心行動は「すでに見つけた人が投稿する」であり、一般ユーザーが**外へ出て探索を始める理由**が弱い。XP・図鑑・クエストは投稿後の報酬として機能するが、「どこへ行くか」「何を探すか」「現地で何をすればよいか」をつなぐフィールド体験が存在しない。

本要件の目的は次のとおり。

1. 市民科学に関心が薄いユーザーにも、10〜20分の近所の冒険として参加理由を提供する。
2. 未調査地域・再調査が必要な地域へ参加を誘導し、空間バイアスを減らす。
3. 写真役割・位置精度・調査時間をガイドし、投稿品質を落とさず参加量を増やす。
4. 投稿が承認されたとき、地図・図鑑・XP・地域進捗が同時に変化する一貫したゲームループを作る。
5. 既存の実験基盤を使い、「探索UIが投稿開始・承認率・未調査セル被覆・継続率へ与える効果」を評価可能にする。
6. 山間部・水辺等の圏外や不安定回線でも観察を失わず、通信復帰後にユーザーが同じ投稿を作り直すことなく同期できるようにする。

### 1.2 成功定義

North Star Metric は、単純な投稿数ではなく次とする。

> **参加100時間あたりの「承認済み・新規または再調査対象セルへの有効貢献数」**

成功条件は、探索モード導入後に次を同時に満たすことである。

- ミッション開始率、初回提出率、未調査セル被覆率が改善する。
- 承認率、位置精度、写真要件充足率が対照群より悪化しない。
- 重複・却下・不正・危険地点接近の比率が許容閾値を超えない。
- オフラインで送信操作が完了した記録の99%以上が端末Outboxへ保存され、オンライン復帰後24時間以内または次回アプリ起動中にサーバー確認済みへ移行する。
- 再試行による同一投稿・同一XP・同一セル貢献の二重作成を0件にする。
