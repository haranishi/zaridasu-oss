## 6. 画面仕様

### SC-283-01: 探索マップ

- **URL:** `/?mode=explore`
- **用途:** 近隣の侵入シグナルと調査不足セルを見つける。
- **P1コンテンツ:** 現在地、見る／探索切替、セル状態、近隣ミッション、地域進捗
- **P2コンテンツ:** フィルタ、情報鮮度、距離・時間
- **P3コンテンツ:** 写真ギャラリー導線、凡例詳細

```text
+--------------------------------+
| ☰  ザリダス・フィールド   Lv.7 |
| [見る] [探索]                   |
+--------------------------------+
|  秋田市の水辺調査 72%           |
|                                |
|      [霧]   ◎最近確認           |
|   ?未調査       ◯再調査         |
|              ◉ 現在地           |
|                                |
| ┌ 300m先・10分 ─────────────┐ |
| │ 未調査の水辺 +80XP見込み │ |
| │ [ミッションを見る]        │ |
| └───────────────────────────┘ |
+--------------------------------+
| 探索   統計    ＋    順位  マイ |
+--------------------------------+
```

**状態:**

- loading: 地図スケルトン＋リスト表示
- empty: 「この範囲に公開ミッションはありません」＋表示範囲変更
- error: 現行マップへフォールバック＋再試行
- location denied: 地域選択で利用可能
- restricted: 地図上に正確位置を出さず説明だけ表示

### SC-283-02: ミッション詳細

- **URL:** `/field/mission/[missionId]` または地図上のボトムシート
- **用途:** 価値・所要時間・安全性を理解して開始する。

```text
+--------------------------------+
| ← ミッション                   |
| 未調査の水辺を確認せよ          |
| 300m・約10分・初級              |
|                                |
| 最近の確認: なし                |
| 必要: 全身 / 特徴 / 水辺        |
| 成功見込み: +80XP               |
|                                |
| ⚠ 公開歩道から撮影              |
| ⚠ 水辺へ降りない                |
|                                |
| [10分だけ探索を始める]          |
+--------------------------------+
```

**画面遷移:**

- 開始 → SC-283-03
- 危険報告 → 報告ダイアログ
- 戻る → SC-283-01
