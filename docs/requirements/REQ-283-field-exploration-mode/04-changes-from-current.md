## 2. 現行から変わる要素

### 2.1 機能・画面の差分

| 領域 | 現行 | 追加後 | 互換方針 |
|---|---|---|---|
| ホーム地図 | 承認投稿・依頼・水辺・ヒートマップを閲覧 | 「見る / 探索」切替、探索セル、侵入シグナル、ミッションカード | 現行の見るモードを残す |
| 地図マーカー | 投稿単位のマーカー中心 | セル単位の「最近確認／過去確認／未調査／不在調査／制限」 | 投稿詳細表示は現行維持 |
| 投稿開始 | ヘッダー／中央FABから長い投稿フォーム | 通常投稿と、ミッション経由の短い3段階フローに分岐 | `entry_mode` で分ける |
| 位置選択 | GPS・EXIF・手動ピン | ミッションではセルを固定し、現地精度と距離だけ確認 | 手動変更は原則不可、離脱で通常投稿へ |
| 写真 | 最大枚数内で自由選択 | 全身・特徴・水辺の役割別スロット＋品質フィードバック | 既存 `photos` は維持 |
| 通信圏外 | 通常投稿を端末下書きへ保存し、復帰後に手動送信 | フィールドパック、送信確定Outbox、自動再送、冪等な分割アップロード | 既存IndexedDBを後方互換移行 |
| 投稿結果 | 送信完了・審査待ち | 仮発見カード、仮コレクション表示、審査状態 | 仮報酬は正式XPに加えない |
| 承認後 | XP・バッジ等へ反映 | XP・図鑑・セル開放・地域進捗・クエストへ同時反映 | 既存承認トリガーへ追加 |
| クエスト | 品質・多様性クエスト | 未調査セル、一定期間後の再調査、不在確認へ誘導 | 生投稿数クエストは禁止 |
| 図鑑／水槽 | 承認投稿で収集 | 「どの探索セルで発見したか」「初発見」履歴を追加 | 正確座標は表示しない |
| 通知 | 承認・コメント・週次等 | 安全な近隣ミッション、再調査時期、一斉調査を追加 | 日中・頻度上限・明示オプトイン |
| 管理 | 投稿審査・公開レベル管理 | セル、ミッション、安全性、公開期限、推奨報酬を管理 | `audit_logs` に記録 |
| 研究計測 | 投稿行動・実験群の計測 | ミッション表示→開始→到着→提出→承認のファネル | REQ-175を再利用 |

### 2.2 情報アーキテクチャ

```text
[ホーム /]
 ├─ 見る
 │   ├─ 現行マップ
 │   └─ 写真ギャラリー
 └─ 探索
     ├─ 探索セル／侵入シグナル
     ├─ ミッション詳細
     ├─ 安全確認／オフライン準備
     ├─ フィールドセッション
     │   ├─ 到着確認
     │   ├─ スキャン
     │   └─ 不在確認
     ├─ 端末保存／送信待ち
     ├─ 仮発見（サーバー受付後）
     └─ 審査結果
         ├─ XP
         ├─ 図鑑／水槽
         ├─ セル開放
         └─ 地域進捗

[マイページ /dashboard]
 ├─ 現行進捗
 ├─ 今週の探索
 ├─ 地域探索率
 └─ オフライン送信
     ├─ 送信待ち
     ├─ 要ログイン／要修正
     └─ 送信済み

[管理 /admin]
 └─ フィールド運用
     ├─ 探索セル
     ├─ ミッション
     ├─ 安全・公開制御
     └─ ファネル／品質指標
```

### 2.3 主要UXフロー

```text
[探索マップ]
  → セルをタップ
  → [ミッション詳細]
  → 安全確認・位置許可
  → [フィールドセッション]
  → 到着
  → [3枠スキャン]
  → AI補助フィードバック
  → [投稿確認]
  → online
      → [サーバー受付済み・仮発見・審査待ち]
  └→ offline / unstable
      → [端末保存済み・送信待ち]
      → 通信復帰／アプリ再開／手動送信
      → [サーバー受付済み・仮発見・審査待ち]
  → approved
  → [正式発見・地域進捗]

  └→ 未発見
      → 調査時間・範囲を確認
      → 不在確認として投稿
      → approved後に有効貢献
```
