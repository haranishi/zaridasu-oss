## 背景

ザリダス（秋田県の外来生物＝アメリカザリガニ／ウシガエルの市民科学情報マップ、卒研 PF）は、市民が現地でスマホから生物の写真・音声と観察情報を投稿することで成り立つ。投稿フォーム（`PostForm`）・認証モーダル（`AuthModal`）・調査依頼フォーム（`SurveyRequestForm`）が「入力のしやすさ」と「迷わなさ」を欠くと、せっかく現地で生物を見つけた利用者がその場で離脱し、研究データそのものが集まらない。フォーム改善はこの卒研 PF のデータ獲得 KPI に直結する。

本 REQ の下敷きは Obsidian ノート：

- `02_notes/デザイン基礎/フォームデザイン.md`: フォームの基本原則 ＝ **欄を最小限に・1 カラムに・ラベルは欄の外に常時表示（プレースホルダーをラベル代わりにしない）・検証は blur で行い解消は即時・CTA は常に押せてクリック時にエラーを集約**。NN/g の調査では、これらに準拠したフォームは一発成功率 78%、非準拠は 42% という差が報告されている（出典は同ノート）。
- `02_notes/デザイン基礎/アクセシビリティとUXライティング.md`: モバイルキーボード最適化（`type` / `inputmode` / `autocomplete`）、入力欄フォントを 16px 以上にして iOS の自動ズームを防ぐ、エラーは `aria-live` / `role="alert"` で支援技術にも伝える。
- `02_notes/人に伝わる力/02_writing_copywriting.md`: ボタン文言は「動詞＋成果」（「送信」ではなく「投稿する」）、エラー文は「何が・なぜ・どう直すか」を具体例つきで書く。

ザリダスのフォームは、既存 REQ で**機能面（検証ロジック・ラベル関連付け・a11y）**が段階的に整備されてきた一方、**(A) フォーム構造（1 カラム / ラベル外出し / タップ領域 / 二重送信防止）**、**(B) モバイル入力最適化（`inputmode` / `enterkeyhint` / 16px ズーム防止）**、**(C) マイクロコピー（CTA＝動詞＋成果、エラー文の具体化）の 4 言語（ja/en/ko/zh）統一** は横断的に点検されていない。本 REQ はこの 3 点に集中する。**検証ロジックそのものは REQ-029 / REQ-213 に委ね、本 REQ は「入力体験と文言」に限定**する（→「影響範囲」「差分（重複回避）」で明記）。
