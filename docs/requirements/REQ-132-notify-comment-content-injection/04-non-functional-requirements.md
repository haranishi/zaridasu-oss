### 非機能要件

- [ ] **NFR-132-01: セキュリティ**
  - エラーレスポンスから「comment_id が存在しないのか / 自分のものでないのか」を区別できない応答にする（200 `{ skipped: '...' }` または 403 を統一）
  - レート制限超過時のレスポンスは攻撃者に有用な情報（残り回数等）を返さない
  - service-role の使用範囲を最小化（select / insert のみ）

- [ ] **NFR-132-02: パフォーマンス**
  - 追加 DB クエリは `comments` 取得 (PK) + `comment_notification_log` insert の 2 つで合計 5ms 程度
  - 全体レスポンスタイム < 500ms（Resend 送信込み）

- [ ] **NFR-132-03: 後方互換**
  - 旧クライアント（`comment_content` を送る古いブラウザキャッシュ）からの呼出も Edge Function 側で安全に処理（payload は無視）
  - 1〜2 週間の移行期間後、明示的に 400 を返す

- [ ] **NFR-132-04: 可観測性**
  - 403 / 429 はログに残し、`admin_alerts` で異常頻度を検知
  - 既送 skip のメトリクスを集計
