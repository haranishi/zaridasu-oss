## 機能要件

- **FR-304-01**: 問題A の 17 箇所（＋着手時の再走査で確定した利用者向け箇所）の `aria-label` / `alt` / `sr-only` を `t()` 経由へ移行する。追加キーは ja/en/ko/zh の4言語すべてに追加する。既存キーで意味が一致するもの（例: `common.close`）は再利用し、キーを重複させない。
- **FR-304-02**: `alt={`写真 ${n}`}` のような**補間を含む文言**は、番号を i18n の補間変数として渡す（`t('photoViewer.photoAlt', { index: n })` 形式）。連番を文字列連結で日本語に埋め込む実装を残さない。
- **FR-304-03**: SSR 段階の `<html lang>` を利用者の言語と一致させる。次のいずれかを採る（採用方式は着手時に決定する。**要確認**）。
  - (a) 言語選択を Cookie に永続化し、`src/app/layout.tsx` のサーバー側で Cookie から `lang` を決定する。
  - (b) 少なくともハイドレーション前に `lang` を設定するインラインスクリプトを `<head>` に置く（JS 無効時と Googlebot の初期 HTML 評価は救済されないため (a) の下位互換策）。
  - いずれの場合も `src/lib/i18n.ts:113,119` のクライアント側上書き（REQ-145 の `languageChanged` フック）と競合しないこと。
- **FR-304-04**: `src/app/providers.tsx:101` の未送信下書きバナーを `t()` 経由にする。`dashboard.canSendNow` を再利用できるかを判断し、件数の提示が必要なら**count 補間付きの新規キー**を4言語で追加する（i18n の複数形処理を利用する）。
- **FR-304-05**: `app.offline` の値から先頭の `⚠️` を4言語すべてで除去し、警告記号は JSX 側（`providers.tsx:121` の `aria-hidden="true"` な span）に一元化する。ロケール JSON の値に装飾記号を埋め込まない方針を明文化する。
- **FR-304-06**: 管理画面側の日本語 `aria-label`（網羅の補足に列挙）は**別フェーズ**として扱い、本要件では対象範囲と件数の記録のみ行う。内部向け画面のため優先度は最低とし、FR-304-07 の lint 導入時に例外扱いにするか一括対応するかを判断する。
- **FR-304-07**: 再発防止として、**`aria-label` / `alt` / `title` に日本語リテラル（ひらがな・カタカナ・漢字）を直書きすることを禁止する lint ルールまたはスクリプト**を導入する。これは REQ-277 FR-277-03（`src/views`・`src/components` のハードコード日本語検出）の**サブセットとして設計し、二重実装しない**。意図的な JP 固定（SEO 目的の固定ページ等）は REQ-277 FR-277-03 と同じアノテーション方式で除外する。
- **FR-304-08**: `scripts/check-i18n-parity.ts` の検証範囲（**キー集合 diff のみ**）を README またはスクリプト冒頭のコメントに明記し、「値の未翻訳」「ソース側ハードコード」は FR-304-07 / REQ-277 FR-277-03 が担う旨を書き添える。検出責任の境界を文書上で確定させる。

## 受入基準

- **AC-01**: 言語を en に切り替えた状態で、写真ビューア・位置確認マップ・パンくず・地図読み込み中の状態表示・調査依頼の FAB・データセットページの「ホームに戻る」が、**スクリーンリーダーで英語として読み上げられる**（日本語文字列が渡らない）。
- **AC-02**: 上記画面の `aria-label` / `alt` / `sr-only` に日本語リテラルが残っていない（`grep` で確認できる。管理画面は FR-304-06 により対象外）。
- **AC-03**: `localStorage` に `en` を持つ状態でページを再読み込みしたとき、**初期 HTML（JS 実行前のレスポンス本文）の `<html lang>` が `en`** である（`curl` などで初期 HTML を確認する）。方式 (b) を採る場合は、ハイドレーション前に `lang` が更新されることを確認し、初期 HTML が `ja` のままである制約を本要件内に記録する。
- **AC-04**: オフラインから復帰して未送信下書きがある状態で、言語 en のときにバナーが英語で表示される。件数が正しく補間される。
- **AC-05**: オフラインバナーの表示が「⚠️ オフラインです。…」であり、**⚠️ が二重に表示されない**。4言語すべてで確認する。支援技術には警告記号が本文として読み上げられない。
- **AC-06**: FR-304-07 の lint が有効で、`aria-label="閉じる"` のような日本語リテラルを新規に追加すると検出される（意図的な違反コードで確認する）。
- **AC-07**: 追加した i18n キーが ja/en/ko/zh 4言語すべてに存在し `npm run i18n:check` がパスする（パリティ 4言語一致を維持）。
- **AC-08**: `lint` / `type-check` / 既存652テストがパスする。
