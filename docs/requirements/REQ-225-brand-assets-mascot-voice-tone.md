# REQ-225: ブランド資産（マスコット / シェイプ言語 / Voice & Tone / OGP・favicon 体系）の整備

これは何か: ザリダスに固有のマスコット・組み合わせ型ロゴ・favicon 体系・1枚ブランドメモ・OG 構図ガイドラインを与える要件定義。本文は分割ファイルに逐語で保管し、ここは入口（索引）。

## 目的・背景（要約）

REQ-027 / REQ-181 / REQ-042 は「メタタグの**入れ物**」と「動的生成の安全性」を整えたが、その器に載せる**ブランド表現そのもの**は未定義のままである。現状の視覚的アイデンティティは「赤背景＋ OS 標準のロブスター絵文字 🦞」という間に合わせで、①OS ごとに描画が変わり一貫性が成立しない、②🦞（ロブスター）はアメリカ**ザリガニ**ではなくサービス名と図像が一致しない、③favicon サイズ（16〜20px）で細部が潰れシルエットテストに通らない、という三重の問題を抱える。本REQはマスコット SVG・組み合わせ型ロゴ・favicon 体系・1枚ブランドメモ・OG 被写体/構図ガイドライン・空状態への転用方針を、卒研 PF として作り切れる範囲で定義する。

## 主要な決定事項（要点）

- **ドミナントシェイプは丸（曲線）＝可愛い・安全・親しみ**。識別フックは**1つに絞る**（特徴的なハサミ または 曲がった尾）。**ロブスター絵文字 🦞 は使用しない**。
- **シルエットテストを合格条件にする**（100%黒 × 256/64/20px）。20px で潰れるなら favicon 専用の単純化シンボルを別途用意する。
- **組み合わせ型ロゴ（ワードマーク＋シンボル）と、シンボル単独の2形態**を SVG で用意し、クリアスペース・最小サイズ・Do/Don't を明記する。
- **公式 HEX はブランド赤 `#dc2626` 基準**。種別色（アメリカザリガニ `#DC2626`／ウシガエル `#16A34A`）は**データ可視化用であってブランド主色ではない**と役割を区別する。
- **1枚ブランドメモを唯一の正本（Single Source of Truth）にする**。形容詞3〜5個＋アーキタイプ1つ、Voice（不変の人格）と Tone（状況可変）の区別、HEX、2書体、ロゴ Do/Don't、やさしい言葉の良い/悪い文例を含む。
- **ブランド禁止語を厳守**: **大学名・研究室名・「卒業研究」「研究プロジェクト」を使わない**（`docs/lp-copy.md` 確定事項）。学生が作ったことは「秋田の自然が大好きなひとりの大学生がつくった」の範囲に留める。
- **担当範囲の線引き**: 動的 OG の生成ロジックは REQ-027/REQ-042、OG タグの出し分けは REQ-027/REQ-181、CSS 変数化と色覚・コントラスト a11y は REQ-224、空状態の3状態 UI 実装は REQ-222 が主管。本REQはブランド資産とガイドラインの提供に限定する。
- **壊れた参照の解消**: `public/favicon.ico` は存在しないのに `opensearch.xml` が参照しており、ホストも旧 `zaridasu.vercel.app` のまま。実在ファイルと正本ドメイン `zaridasu.com` に統一する。
- 緊急度 Medium / 重要度 High。一度作れば OG・トークン・空状態・SNS シェアがすべて同じ正本を参照できる。
