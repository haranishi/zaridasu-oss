## 受入基準

- **AC-01**: `EditProfileModal` の保存ボタン・`ReportModal` の送信ボタン・管理画面の一括承認/一括削除を**連打しても送信が1回しか走らない**（`disabled` が反映される前の連打を含む）。
- **AC-02**: UI 言語を en / zh / ko に切り替えた状態で未送信下書き一覧を開くと、日時が**その言語のロケール書式**で表示される（`ja-JP` 固定でない）。表示する項目（月/日/時/分）は変わらない。
- **AC-03**: 未送信下書きの写真プレビューで生成された blob URL が、コンポーネントのアンマウント時に `revokeObjectURL` される。再レンダーごとに新しい blob URL が積み上がらない。
- **AC-04**: サインアウトが失敗する状況（ネットワーク断）でログアウトを押すと、**エラーが表示され、ログイン状態のままドロワーだけが閉じることがない**。成功時は従来どおりドロワーが閉じる。unhandled rejection がコンソールに出ない。
- **AC-05**: アカウント削除の処理中（`deleting`）に背景をタップしてもモーダルが閉じない。Escape も効かない。処理が完了するか、失敗してエラーが表示されるまでモーダルが表示され続ける。`EditProfileModal` の保存中も同様。
- **AC-06**: メール確認完了画面（`/auth/callback` の `confirmed` 表示）が出てから3秒以内に別ページへ移動した場合、**`/dashboard` への遷移が起きない**。
- **AC-07**: `providers.tsx` の下書き通知バナーと `LikeShareSection` のコピー済み表示のタイマーが、アンマウント時に `clearTimeout` される（アンマウント後の `setState` 警告が出ない）。
- **AC-08**: `/dashboard` の DOM に `<h1>` がちょうど1個存在する。**画面の見た目が変わらない**（sr-only）。既存の h2 以下の階層が変わっていない。
- **AC-09**: `vercel.json` に `regions` が明示されており、リポジトリを読むだけで実行リージョンが判別できる。runbook に Supabase リージョンとの一致方針と実測値が記録されている。
- **AC-10**: 追加・変更した i18n キー（FR-315-02 / FR-315-04 のエラー文言 / FR-315-07 の h1）が ja / en / ko / zh の4言語すべてに存在し、`npm run i18n:check` がパスする。
- **AC-11**: `lint` / `type-check` / 既存652テストがパスする。
