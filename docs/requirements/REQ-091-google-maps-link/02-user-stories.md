## ユーザーストーリー

### US-091-01: 調査依頼の応答者として現地への経路をすぐ見たい
**As a** 調査依頼に「協力する」と表明したユーザー,
**I want to** 依頼詳細から 1 タップで Google Maps の経路案内を開く,
**So that** すぐに現地に向かえる.

**受け入れ条件:**
- [ ] AC-1: `/request/[id]` の地図エリア直下にボタンが見える
- [ ] AC-2: タップで Google Maps が新しいタブ / アプリで開き、目的地ピンが正しい座標に立つ
- [ ] AC-3: モバイル端末で Google Maps アプリが入っていればアプリで開く
- [ ] AC-4: PC では新しいブラウザタブで開き、ザリダスのタブは残る

**優先度:** 高 ／ **見積もり:** XS

### US-091-02: 投稿閲覧者として目撃地点周辺の地形を確認したい
**As a** 投稿詳細を見ているユーザー,
**I want to** 1 タップで Google Maps の航空写真 / ストビュー対応マップで地点周辺を見る,
**So that** 「どんな場所で目撃されたか（用水路 / 田んぼ / 公園など）」を Leaflet より高解像度で確認できる.

**受け入れ条件:**
- [ ] AC-1: `/post/[id]` の地図カードにボタンが見える
- [ ] AC-2: タップで Google Maps が開き、ピンが投稿の座標に立つ
- [ ] AC-3: ズーム / 航空写真切替 / ストビューはすべて Google Maps 側の機能で自然に使える

**優先度:** 中 ／ **見積もり:** XS

### US-091-03: スクリーンリーダー利用者がボタンを把握できる
**As a** スクリーンリーダー / キーボード利用者,
**I want to** ボタンが「外部リンクで Google Maps を開く」ことを音声 / フォーカスリングで把握できる,
**So that** 不意の画面遷移にならない.

**受け入れ条件:**
- [ ] AC-1: `aria-label` がボタンの動作を明示する（例: 「Google Maps で経路を表示（新しいタブで開く）」）
- [ ] AC-2: 外部リンクであることを視覚的にも示す（外部リンクアイコン or 「↗」）
- [ ] AC-3: Tab で到達でき、Enter / Space で発火、フォーカスリング可視

**優先度:** 中 ／ **見積もり:** XS

### US-091-04: ボタンが他の主要 CTA を邪魔しないで欲しい
**As a** 依頼詳細ページのオーナー（依頼者）,
**I want to** Google Maps ボタンが「クローズ」「結果を投稿する」など主要アクションを視覚的に圧迫しない,
**So that** 主要動線が壊れない.

**受け入れ条件:**
- [ ] AC-1: ボタンは地図エリア直下に小さめ（`py-2` 程度）で配置され、主要 CTA（`py-3` フル幅グラデ）より控えめな見た目
- [ ] AC-2: モバイル幅でも 1 行に収まる
- [ ] AC-3: ダーク / ライトモードで違和感のないコントラスト

**優先度:** 中 ／ **見積もり:** XS
