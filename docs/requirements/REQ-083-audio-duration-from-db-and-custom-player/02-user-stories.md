## ユーザーストーリー

### US-083-01: 投稿者として再生時間を必ず確認したい
**As a** 投稿者,
**I want to** 投稿前 / 投稿後どの画面でも音声プレーヤーに正しい再生時間が表示される,
**So that** 0:00 / 0:00 で「壊れている」と感じなくて済む.

**受け入れ条件:**
- [ ] AC-1: 録音直後の preview に `0:06` のように duration が表示される
- [ ] AC-2: マイページ・投稿詳細でも duration が表示される
- [ ] AC-3: 既存音声（duration_ms NULL）は audio.duration が読めれば表示、不可なら「--:--」表示で再生は可能

**優先度:** 高
**見積もり:** M

### US-083-02: ベストエフォートのフォールバック
**As a** 開発者,
**I want to** ネイティブ `<audio>.duration` が読めればそれも採用、無理なら DB 値を使う,
**So that** 既存音声でも将来音声でも切れ目なく動く.

**優先度:** 中
**見積もり:** XS
