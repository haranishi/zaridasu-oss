## 受入条件

- [ ] **AC-152-01**: **Given** パスワードリセットの recovery 画面、**When** 新パスワードに `abc123`（6 文字、英字+数字だが 8 文字未満）を入力して送信、**Then** 「8 文字以上」を要求するエラーが表示され、`supabase.auth.updateUser` は呼ばれない。
- [ ] **AC-152-02**: **Given** 同画面、**When** `12345678`（8 文字だが数字のみ、英字なし）を入力、**Then** 英字を要求するエラーが表示され更新されない。
- [ ] **AC-152-03**: **Given** 同画面、**When** `password1`（8 文字以上＋英字＋数字）を入力、**Then** 強度チェックを通過し、確認一致なら `updateUser` が実行される。
- [ ] **AC-152-04**: **Given** サインアップ経路とリセット経路、**When** それぞれ同じ弱いパスワード `abc123` を入力、**Then** 両経路とも同一の理由で拒否される（強度ポリシーが一致している）。
- [ ] **AC-152-05**: **Given** 共通関数 `validatePasswordStrength`、**When** ユニットテストで境界値（7 文字 / 8 文字 / 英字なし / 数字なし / 両方あり）を検証、**Then** 期待通り valid/invalid を返す。
- [ ] **AC-152-06**: **Given** recovery フォームの入力欄、**When** レンダリング、**Then** `minLength={8}` で placeholder が「8文字以上」相当になっている。
