## 背景

ザリダス（秋田県の外来生物＝アメリカザリガニ／ウシガエルの市民科学情報マップ、卒研 PF）は、いいね・コメント・投稿・バッジ・ランキングといった「市民を巻き込む」仕組みを一通り備えている。しかし、ユーザーの行動に対する**即時の手応え（達成感のフィードバック）**が弱い。市民科学の文脈では「参加し続けたくなるか（継続動機）」が研究データの質と量を左右し、先行研究レビュー（research-rq1：内発的動機の整合）でも示されたとおり、ゲーミフィケーションの**視覚的フィードバック面**は離脱率に効く。本 REQ-226 は、既存の機能はそのままに、操作直後の体感を「軽量なマイクロインタラクション」で底上げすることに集中する。

設計の下敷きは Obsidian の 2 ノート：

- `デザイン基礎/マイクロインタラクションとモーション.md` — マイクロインタラクションの 4 構造（トリガー → ルール → フィードバック → ループ/モード）、入場アニメは ease-out、duration は 100〜300ms、アニメ対象は `transform` / `opacity` のみ（`width` / `top` / `margin` 等は reflow を誘発して重い）、`prefers-reduced-motion` では即時表示にフォールバックする、という原則。
- `Web制作_3D表現/03_軽量な疑似3Dと質感.md` — バッジ解放などの「ご褒美」表現を、重い 3D ではなく `transform: scale()` / `box-shadow` / グラデーションといった軽量な疑似 3D・質感で出す方針。

現状のコードは、達成感に直結する 3 つの場面で次の課題を抱えている：

1. **いいね・コメントが「楽観的 UI」になっておらず、応答を待ってから画面が変わる**ため、押した瞬間の手応えが無く、低速回線では「効いていない」体感になる。
2. **バッジは静的表示のみ**で、節目（初投稿・種同定・観察数）でアンロックされても解放の演出が無く、達成感が伝わらない。
3. **地域ページ等に観察の進捗を示すカウンタが無い**ため、「自分／みんなで N 種を観察した」という積み上げが可視化されていない。

React 19 を採用しており `useOptimistic` が利用可能だが、リポジトリ全体で `useOptimistic` は**未使用**（`grep -rn "useOptimistic\|optimistic" src` のヒントは `usePostForm.ts:150` のストレージ rollback ログのみ）。`prefers-reduced-motion` は REQ-015 で `globals.css:63-70` のグローバル `@media` により全アニメ/トランジションを抑制済みで、本 REQ もこの土台を尊重する。
