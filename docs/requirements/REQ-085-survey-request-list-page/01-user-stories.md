## ユーザーストーリー

### US-085-01: 一般ユーザーとして地図を開かずに依頼を探したい
**As a** 一般ユーザー,
**I want to** `/requests` で調査依頼を一覧で見たい,
**So that** 地図を開かなくても近所の依頼に気づける.

**受け入れ条件:**
- [ ] AC-1: `/requests` にアクセスすると open + responded の依頼が新しい順に最大 200 件表示される
- [ ] AC-2: 各カードには種別 / 市区町村 / 緊急度 / 経過時間 / 応答数（あれば）が表示される
- [ ] AC-3: カードをタップ・クリックすると `/request/[id]` に遷移する
- [ ] AC-4: 未ログインでも閲覧可能（既存 SELECT RLS により）

**優先度:** 高 ／ **見積もり:** S

### US-085-02: 投稿者として自分の依頼一覧を見たい
**As a** 依頼を立てた投稿者,
**I want to** マイページから自分の依頼一覧に飛び、status / 応答数を確認したい,
**So that** 何件のうち何件が responded / closed か即把握できる.

**受け入れ条件:**
- [ ] AC-1: マイページに「自分が立てた依頼」リンクがあり、`/requests?owner=me` 等に遷移する
- [ ] AC-2: 自分の依頼のみがフィルタされて表示される
- [ ] AC-3: closed も含めて全 status を表示できる

**優先度:** 中 ／ **見積もり:** S

### US-085-03: 緊急依頼を優先的に発見したい
**As a** 協力したい近隣ユーザー,
**I want to** 緊急（urgent）依頼を上に表示するソート,
**So that** 急ぎの依頼から取り組める.

**受け入れ条件:**
- [ ] AC-1: ソート切替で「緊急優先」を選ぶと urgent → normal の順、同 urgency 内では新しい順
- [ ] AC-2: デフォルトソートは新しい順（既存挙動と一致）

**優先度:** 中 ／ **見積もり:** XS
