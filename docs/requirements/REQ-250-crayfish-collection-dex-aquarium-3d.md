# REQ-250: ザリガニ・コレクション／図鑑／水槽と 3D ビュー（所有権・収集要素）

## 背景
ユーザーは「投稿すると自分のものとして貯まっていく所有・収集要素」を求めており、具体像として**ザリガニを 3D モデル化して『ここにザリガニがいますよ』と動かす**イメージを挙げている。ザリダスには既にこの土台になる素材がある——プロフィールの**バッジ図鑑（解放/未解放をグレーで並べるショーケース）**（`src/views/ProfilePage.tsx:235-260`）、多様性ランキングを**「あなたのコレクション」**と呼ぶ枠組み（`src/views/RankingPage.tsx:161-176`）、手描き 2D SVG のザリガニ（`src/components/ui/CrayfishIllustration.tsx`）、マスコット SVG（`public/mascot*.svg`）、種の画像/メタデータ（`SpeciesOption`＝label/color/shape/glyph/emoji/scientificName/sameAs、`src/lib/constants.ts:117-121`）。本 REQ はこれらを「所有できるコレクション」として束ね、収集・図鑑・水槽（ビオトープ）と、段階導入の 3D ビューを定義する。

**現実の制約（正直な設計）**:
- **収集対象の種は現状 2 種のみ**（`american`/`bullfrog`、DB CHECK 固定 `schema.sql:37`）。純粋な「種集め」は浅いので、コレクションの深さは **種 ×（info_type 5 種 `constants.ts:157-163`）×（市町村 25 `:175-181`）× 初観察の記録**で作る（多様性軸が既にこの構造をモデル化している）。
- **3D/WebGL スタックは皆無**（`package.json` に three / model-viewer 等なし。Leaflet 2D＋SVG のみ）。**size-limit は極小**（`/`=10KB・`/trends`=5KB gzip 等、`.size-limit.json`）、**Lighthouse は CLS error≤0.1・a11y error≥0.9 をハードゲート**（`.lighthouserc.json`）。three.js（~150KB gzip）や GLTF モデル（0.5–5MB）は現行バジェットを ~20 倍超過するため、**段階導入と厳格な分離が必須**。
- **倫理的枠組み（重要）**: 対象は特定外来生物であり、**外来生物法で飼養・運搬・放出は原則禁止**。したがって「集めて飼う」欲求は**バーチャルなコレクションで安全に受け止める**べきで、同時に「なぜ問題の生き物か／実物を飼ってはいけない・逃がしてはいけない」という**教育メッセージを必ず載せる**。収集は学びの面であって、外来種を軽々しく愛でる企画にしない。

## 現状の問題（機会）
（ファイルパス:行番号つき）

1. **収集/所有の概念が図鑑（バッジ）以外に無い**: 観察の成果が「自分のコレクション」として貯まり、眺めて動かせる場所が無い。既存の「あなたのコレクション」（多様性）は数値で、視覚的な所有物になっていない。
2. **ザリガニのビジュアルは 2D 静止のみ**: `CrayfishIllustration.tsx` は空状態・About・404 で使う静止 SVG。ユーザー要望の「動く／3D」に応える演出・3D ビューが無い。
3. **3D を素朴に入れると全バジェットを破壊する**: 依存追加・アセット配信・CLS/a11y/TBT を無計画に入れると `.size-limit.json`・`.lighthouserc.json` のハードゲートに抵触する。

## 目的
観察の成果を「所有できるコレクション（図鑑＋水槽）」として DB 権威で貯め、段階的に 3D で見て動かせるようにする。市民科学の学び（外来種の理解）と収集動機を両立させ、性能・a11y・4 言語・ブランド声の制約を守る。

## 要件

### 機能要件
- [ ] FR-250-01: **図鑑（コレクション）データモデル**。ユーザーの検証済み観察から「観察カード」を解放する。カードの単位は **種 × info_type × 市町村**（＋初観察日時）。既存のバッジ図鑑（`ProfilePage.tsx:235-260`）の解放/未解放グリッドの UI パターンを踏襲する。`SpeciesOption` のメタ（和名/学名/色/絵文字/`sameAs`）をカード表示に流用。
- [ ] FR-250-02: **所有権（DB 権威・改竄不能）**。コレクション状態（解放済みカード、水槽の内容・デコレーション）は新テーブル（例 `user_collection`）に保存し、`user_badges`/`user_progress` と同じく**トリガー/サーバーのみ書き込み**（クライアント改竄不可、RLS は本人＋`is_public` 時公開読み取り）。プロフィールに「あなたのコレクション」として表示（所有＝アカウント紐付け）。
- [ ] FR-250-03: **水槽／ビオトープ**。自分の観察した生き物が暮らす個人の水槽ビューを設ける。**容量・デコレーションはレベル（REQ-249）で解放**。ここが「所有物を眺める・動かす」体験の中心。
- [ ] FR-250-04: **ザリガニを『動かす』——段階導入**:
  - **フェーズ1（バジェット内・先行実装）**: 既存 2D SVG（`CrayfishIllustration.tsx`）・マスコット・種画像を **CSS キーフレーム**で動かす（遊泳・ハサミの開閉など。`globals.css` の既存アニメ様式に倣う）。`prefers-reduced-motion` で自動停止（`globals.css:212-220` により無償で準拠）。追加依存ゼロ・CLS 安全。ユーザー要望の「ここにザリガニがいて動く」を**まずこれで満たす**。
  - **フェーズ2（任意・将来）**: 実 3D モデル（`@google/model-viewer` もしくは react-three-fiber＋glTF）。**厳格な分離**を必須条件にする: (i) **コレクション/水槽ページ限定**で `dynamic()` 遅延読み込み（ホーム等の公開/ゲートルートのバンドルに載せない）、(ii) 専用の size-limit バジェット枠を新設、(iii) **2D フォールバック**（低スペック/`reduced-motion`/WebGL 不可/読み込み失敗時は SVG に自動退避）、(iv) **CLS 安全**（寸法予約）、(v) a11y（canvas に代替テキスト＋操作可能なコントロール）、(vi) モデルアセットはストレージ/CDN 配信で JS バンドルに含めない。
- [ ] FR-250-05: **教育メッセージの同梱（必須）**。図鑑カード・水槽・3D ビューに、対象種が特定外来生物であること／**実物を飼育・放出してはいけない（外来生物法）**／正しい対処（駆除・通報）への導線を、穏やかな文体で必ず併記する。収集体験が「飼育・放流の助長」に読めないようコピーで担保する。
- [ ] FR-250-06: **i18n**。図鑑/水槽/3D ビュー/教育文言を 4 言語に追加し `i18n:check` を通す。ブランド声（です・ます・「！」不使用）・**禁止語（大学/卒業研究 等）不使用**（`docs/brand/brand-memo.md`）。

### 非機能要件
- [ ] NFR-250-01: **性能バジェット厳守**。フェーズ1 は既存ルートのバジェットを悪化させない。フェーズ2 の 3D は必ず遅延・分離・専用バジェットで、`/`・`/trends`・`/about`（Lighthouse 対象）の LCP/CLS/TBT を悪化させない。CLS≤0.1・a11y≥0.9・seo≥0.9 のハードゲートを維持。
- [ ] NFR-250-02: **アクセシビリティ**。3D/アニメは `prefers-reduced-motion` を尊重（フェーズ2 は JS ループも明示チェック＝`achievement.ts:prefersReducedMotion()`）。図鑑の解放/未解放は色のみに依存せずテキストで判別可能（REQ-224）。
- [ ] NFR-250-03: **PWA/オフライン**。3D アセットはキャッシュ戦略を明示（`public/sw.js`）。大容量アセットがオフラインファースト姿勢（`offlineStore` 等）を壊さない。
- [ ] NFR-250-04: 収集ロジックは REQ-248 の承認ベース進行と同じアンチ Goodhart（未検証投稿でカードが増えない）。

## 受入条件
- [ ] AC-01: 検証済み観察（種 × info_type × 市町村）に応じて図鑑カードが解放され、プロフィールに「あなたのコレクション」として表示される。
- [ ] AC-02: コレクション/水槽の状態が DB 権威で保存され、クライアントから改竄できない（直接 UPDATE が RLS で拒否）。
- [ ] AC-03: フェーズ1 で、ページ上のザリガニ（SVG/マスコット）が CSS で動き、`reduced-motion` で停止する。既存ルートの size-limit/Lighthouse に回帰が無い。
- [ ] AC-04: （フェーズ2 実施時）3D はコレクション/水槽ページ限定で遅延読み込みされ、2D フォールバックが機能し、`/`・`/trends`・`/about` の性能・CLS・a11y ゲートに影響しない。
- [ ] AC-05: 図鑑/水槽/3D に外来種の教育メッセージ（飼育・放出禁止と正しい対処）が併記されている。
- [ ] AC-06: 関連文言が 4 言語に存在し `i18n:check` が通る。禁止語を含まない。

## 優先度
- **緊急度**: Low / **重要度**: Medium
- **理由**: ユーザー要望の「所有・収集・動くザリガニ」に最も直接応える体験だが、REQ-248/249 に依存し、3D は性能・a11y の重い制約を伴う。フェーズ1（既存 SVG の CSS アニメ＋図鑑/水槽）は低リスクで要望の核を満たせ、3D は段階導入で分離すればバジェットを守れる。市民科学の教育価値（外来種理解）と継続動機を両立させる中核企画。
