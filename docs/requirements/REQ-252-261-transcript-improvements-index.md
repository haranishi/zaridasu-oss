## 主要な決定事項の要点（2026-07-07 ユーザー方針）

- **REQ-254（AI判定モデルの更新・選定）は一旦保留**。REQ-253 の検証基盤ができてから再開が妥当。
- **アンケート・問い合わせは Google Forms で実施し、アプリ側はカスタム実装しない**
  （REQ-256 問い合わせ／REQ-261 環境教育／REQ-262 サービスFB の 3 本とも）。導線リンクのみ置く。
- **REQ-263（ゲーミフィケーション拡張）は取捨選択・追加アイデアがユーザー入力待ち**。
  設計時は**アンチGoodhart**（承認済み/品質を称え、量・いいねに流れない）と
  **中核貢献を壁で隠さない**（REQ-249 原則）を厳守する。
- **REQ-264（水域の3D表現）は 3D プレビューを一旦なしとし、2D の視認性UPのみ進める**。
- **REQ-265（地図上のザリガニ演出）は 3D 配置を一旦なしとし、軽量2Dアニメのみで進める**。
  特定外来生物のため「かわいく見せて放流を助長しない」＝キャプションで外来種問題を明示する。
- **優先度が最も高いのは REQ-259**（近くの水域検索＋進出前線の可視化）。実装は重いが訴求は最大。
- 旧監査の file:line は経時変化しうるため、**着手時に再確認すること**。
