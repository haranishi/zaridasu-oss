## リスク・トレードオフ

| リスク | 緩和策 |
|---|---|
| データセットが偏っており実環境と乖離 | 本番投稿の分布を可能な範囲で参考にする。各クラス最低 25 件確保 |
| 評価スクリプトが Edge Function ロジックと乖離 | `analyzeWithGemini` を共通 lib として切り出し、Edge Function とスクリプトで共有 |
| 評価のために Gemini API 課金が発生 | フィクスチャ件数を抑える（100 件で十分）、`--limit` で開発時は少件数で回す |
| audit_logs に大量書き込みで肥大化 | TTL（90 日で自動削除）or partition 検討、ただし当面は不要 |
