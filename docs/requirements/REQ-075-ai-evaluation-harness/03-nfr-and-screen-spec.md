## 非機能要件

### パフォーマンス
- 評価スクリプトは **100 件のデータセットを 5 分以内に処理** できること（Gemini API レイテンシに依存）
- ダッシュボードページの初回表示は 2 秒以内（30 日分の集計を SQL view で事前計算）

### セキュリティ
- フィクスチャに**位置情報・投稿者 ID・実名等の個人情報を含まない**こと
- 評価スクリプト実行時に Gemini API キーが標準出力やログファイルに残らない（`.env` 経由読み込みのみ）
- ダッシュボードは admin のみアクセス可能（既存 middleware で保護）

### 再現性
- 評価結果は決定論的（temperature=0、seed 指定可能なら使用）
- データセットは git 管理（LFS 検討、ただし合計サイズが <50MB なら通常管理で可）

## 画面仕様

### SC-075-01: AI コストダッシュボード
- **URL:** `/admin/ai-cost`
- **用途:** AI 判定 API の利用状況とコストを管理者が確認
- **レイアウト:**
  ```
  +-----------------------------------------+
  | 管理画面ヘッダー                         |
  +-----------------------------------------+
  | KPI カード x 3                          |
  | [今月推定コスト] [前月推定コスト] [呼出数]|
  +-----------------------------------------+
  | 折れ線グラフ: 日次呼び出し回数（30 日）   |
  +-----------------------------------------+
  | 折れ線グラフ: 日次推定コスト（30 日）    |
  +-----------------------------------------+
  | 表: モデル別 / Function 別内訳           |
  +-----------------------------------------+
  ```
- **コンポーネント:**
  | コンポーネント | 説明 |
  |---|---|
  | `KpiCard` | 既存の admin 用 KPI カードを再利用 |
  | `LineChart` | recharts 等を使用（要確認: 既存依存に含まれているか） |
  | `ModelBreakdownTable` | 新規 |
- **状態:** ローディング / データなし / エラー
- **画面遷移:** `/admin` ダッシュボードからリンク追加
