## 現状の問題

（ファイルパス:行番号、または「不在の事実」つき）

### 1. favicon・PWA アイコン・OG が「赤背景＋ OS 標準ロブスター絵文字」の間に合わせで、シルエットテストに通らない

- `public/icon-192.svg:3` / `public/icon-512.svg:3` は `<text ... font-size="110">🦞</text>` の形で、**赤角丸の上に OS 標準絵文字を 1 文字置いただけ**。マスコットとして設計された図像（パス）ではない。
- `public/og-image.svg:25` も同様に `<text ... font-size="96">🦞</text>`。さらに同 SVG のキャッチコピー（`og-image.svg:31`「秋田県ザリガニ出没・分布情報マップ」）は、`docs/lp-copy.md` の「むずかしい言葉を使わない」「外来生物→もともと日本にいなかった生きもの」という確定トーンと不整合（旧来の硬い文言が残存）。
- `src/app/api/og/route.tsx:48-50` の動的 OG も、絵文字（`emoji` 変数。アメリカザリガニ＝`🦞`／ウシガエル＝`🐸`／既定＝`🗺️`、定義は `src/lib/constants.ts:78-82`）を `fontSize: 80` で描くだけで、ブランドマスコット・ロゴが載らない。
- 絵文字は OS/ブラウザで描画が変わり、かつ favicon サイズ（16〜20px）では細部が潰れる。シェイプ言語ノート §3「黒ベタ＋親指サイズで識別できるか」を満たすブランドマークが**存在しない**。
- 影響: ブラウザタブ・ホーム画面アイコン・SNS シェアカードのいずれでも「ザリダスだ」と一目で分かる固有の図像がなく、ブランド VI ノート §6「見た瞬間あなたの投稿だと分かる」状態が未達。

### 2. 真の `favicon.ico` が存在せず、OpenSearch が壊れたパスと旧ドメインを指している

- `public/opensearch.xml:7` は `<Image ...>https://zaridasu.vercel.app/favicon.ico</Image>` を参照するが、`public/` に **`favicon.ico` は存在しない**（`find public -type f` の結果に `favicon.ico` なし。アイコンは `icon-192.svg` / `icon-512.svg` の SVG のみ）。検索バー登録時にアイコンが出ない/404 になる。
- 同ファイルはホスト名も `zaridasu.vercel.app`（`opensearch.xml:6-7`）で、正本ドメイン `https://zaridasu.com`（`src/lib/constants.ts:8` の `BASE_URL` 既定値）と**不一致**。ブランド資産の配信元が割れている。
- `src/app/layout.tsx:42-43` の `icons` も `icon: '/icon-192.svg'` / `apple: '/icon-192.svg'` のみで、`favicon.ico`（旧ブラウザ・一部クローラ向け）や `shortcut` の指定がない。

### 3. グラフィカルなロゴが一切なく、ブランドは素のテキスト「ザリダス」だけ

- LP ヘッダ（`src/views/LandingPage.tsx:220`）は `<span class="... text-primary-600">ザリダス</span>` ＋ ラテン副題「Zaridasu」（同 `:222`）の**素テキストのみ**。図形シンボルは無い。
- アプリ本体ヘッダ（`src/components/layout/Header.tsx:11-19` の `PAGE_TITLES`、`:34` の `pageTitle`）も**文字列でページ名を出すだけ**でロゴ画像を持たない。
- ブランド VI ノート §3 は新規・個人ブランドに**組み合わせ型（文字＋図形）**を推奨するが、現状は「ワードマークのみ」で、シンボル単独（favicon・アプリアイコン）に展開できる図形パーツが存在しない。アイコン（絵文字）とヘッダ（テキスト）の間に視覚的な連続性がない。

### 4. カラーパレットが「Tailwind の赤」止まりで、ブランドカラーとして HEX が文書化されていない

- ブランド色は `tailwind.config.js:13-19` の `primary`（`50:#fef2f2 / 100:#fee2e2 / 500:#ef4444 / 600:#dc2626 / 700:#b91c1c`）と、`src/app/layout.tsx:63` の `theme-color="#dc2626"`、`og-image.svg` のグラデ（`#dc2626→#991b1b`）に**散在**するのみ。
- ブランド VI ノート §4「Primary 1〜2 色／Secondary／Neutral を HEX で明記」、§7「CSS カスタムプロパティで一元管理」という形にはなっていない。種別色（アメリカザリガニ `#DC2626`／ウシガエル `#16A34A`、`src/lib/constants.ts:78-79`）との関係（ブランド赤と種別色の役割分担）も未整理。
- 補足: デザイントークン（CSS 変数化）と色覚多様性/コントラストの a11y 実装は **REQ-224 が主管**。本 REQ は「ブランドとして公式 HEX を確定し 1 枚メモに載せる」ことに限定し、トークン実装は REQ-224 に渡す（重複回避）。

### 5. 書体（タイポグラフィ）がブランドとして定義されていない

- フォントは `src/app/layout.tsx:9-13` で `Inter`（ラテン）を 1 書体読み込むのみ。`tailwind.config.js`（`fontFamily.sans` に `Inter` ＋ system フォント）でも 1 系統。
- 日本語が主言語（`<html lang="ja">`、`src/app/layout.tsx:61`）かつ ja/en/ko/zh の 4 言語なのに、**和文の見出し書体・本文書体が指定されておらず**、OS デフォルト（ヒラギノ/メイリオ/Noto 等）任せ。ブランド VI ノート §4「2〜3 書体（見出し/本文/UI）」が未定義で、OG 画像（`route.tsx:45` は `fontFamily: 'sans-serif'`）と UI で和文の見え方が揃わない。

### 6. Voice & Tone が「LP コピーの方針メモ」に留まり、ブランド全体の 1 枚メモになっていない

- `docs/lp-copy.md` 冒頭「トーン＆ボイス方針」に、です・ます調／むずかしい言葉を使わない／ベネフィット主導／誇張・ビックリマークなし、という優れた方針がある。だがこれは**LP 限定**で、アプリ本体の UI 文言（`src/locales/*/translation.json`）・通知・エラー・OG コピーまでを貫く**ブランド共通の 1 枚メモ**（形容詞 3〜5 個＋アーキタイプ 1 つ＋ HEX ＋ 2 書体＋ Do/Don't）としては存在しない（ブランド VI ノート §5・§9 末尾の「1 枚ブランドメモ」が未作成）。
- Voice（不変の人格）と Tone（状況で変える）の区別（ブランド VI ノート §2）が明文化されておらず、4 言語間でトーンがブレる懸念がある（例: `lp.hero.title` は ja「あなたの『見つけた』が、秋田の自然を守る。」／en「Your "I found one" helps protect Akita's nature.」／ko「당신의 "발견"이 …」／zh「你的一次"发现"，…」と、現状は語彙レベルでは概ね揃っているが、判断基準＝Voice ガイドが無いため今後の追記でブレうる）。

### 7. OGP・シェアカードに載せる「被写体・構図」のガイドラインが無い

- `og-image.svg` は「丸背景の絵文字＋サイト名＋キャッチ＋ URL」を**中央に積んだだけ**で、構図ノート §2「主役は一つ・明確に」「視線誘導 5 レバー」やリーディングラインの設計が無い（中央のど真ん中積み＝構図ノート §1「中央のど真ん中は基本避ける」に反する）。
- `/api/og`（`route.tsx`）も同様に縦積みレイアウト固定で、ページ種別（投稿詳細・地域・種別）ごとに「何を主役にするか（投稿写真か・マスコットか）」の方針が無い。REQ-027 が投稿写真を OG に使う方針を持つが、**マスコット/ロゴをどこに・どの大きさで重ねるか**（ブランドの一貫性）のガイドラインが欠けている。
