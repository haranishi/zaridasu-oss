## 背景

Dependabot は REQ-210 で導入され、weekly・グルーピング・PR 上限 5 という「一人運用で継続可能な負荷」に調整されている。2026-07-23 のコミット `174ff30`（`ci: Dependabot の依存更新PRを develop 宛てに変更`）で `target-branch: develop` を明示し、ブランチ運用ルールに整合させた。

しかしその設定変更**より前**に作られた PR が 4 本、`main` 宛てのまま残っている。加えてそれらはいずれもメジャーバージョン更新であり、`groups` の対象外（groups は minor/patch のみ）のため個別 PR として滞留している。

アプリコードの最終コミットは 2026-07-23 であり、以後 6 日間 PR は 1 本もマージされていない。依存更新が止まると、後でまとめて上げる際の破壊的変更の重なりが大きくなる。
