## 9. 優先度

- **緊急度**: **Low**
- **重要度**: Medium
- **理由**: **公開漏洩ではない**ため緊急ではない。露出したキーはリポジトリにも git 履歴にも無く、リポジトリは private、PostgREST は `pg_catalog` を公開しないため、読めたのは DB 管理者権限を持つ者だけだった。トリガー削除により DB 内からも消えている。したがって「今すぐ全ユーザーをログアウトさせてでも回す」性質の事案ではない。一方で有効期限 2036 年の長寿命キーが定義文に現れた事実は残り、レガシー JWT 方式はスコープ制御も失効もできない。新方式キーは既に発行済みで移行コストが低く、REQ-285 の再デプロイに相乗りできるため、**そのタイミングで一緒に片付けるのが合理的**である。なお FR-287-07（秘密値混入の検知手順）は移行を待たずに実施でき、再発防止として最も費用対効果が高い。
