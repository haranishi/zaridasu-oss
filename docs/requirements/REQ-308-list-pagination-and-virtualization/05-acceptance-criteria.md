## 受入基準

- **AC-01**: 表示範囲フィルタ ON で投稿 2000 件（写真 6000 枚相当）のデータを表示したとき、PhotoGallery の**画面外カードがレンダリング（レイアウト・ペイント）されない**ことを確認できる（`content-visibility` 採用時は DevTools の Rendering / Performance で、段階追加採用時は DOM ノード数が初期 100 件相当に収まることで確認）。**現状は最大 6000 枚が一括描画される。**
- **AC-02**: `format(new Date(...))` 相当の日付整形呼び出しが、最大 6000 回分の date-fns 呼び出しにならない（インスタンス再利用または文字列処理に置き換わっている）。表示される日付（`M/d`）が変わっていないこと。
- **AC-03**: **表示範囲フィルタ OFF（既定）のホームで、最新 50 件を超える投稿が地図とギャラリーに表示される**（追加読込またはページングのいずれかで）。50 件で打ち止めになっていないことを、51 件目以降のデータが到達することで確認する。
- **AC-04**: `PostList.tsx` / `PostCard.tsx` / `StatsBar.tsx` が「本番導線から使われている」か「リポジトリから削除されている」かのいずれかになっている（**dead code として残っていない**）。削除した場合は `src/views/__tests__/HomePage.test.tsx:61` の `vi.mock` も整理されている。
- **AC-05**: `/admin/reports` が **20 件単位のページング**で動作し、「未対応」「対応済み」両タブでページ送りできる。タブ切替でページが 1 ページ目に戻る。ネットワークタブで 1 リクエストの返却行数が 20 件（＋embed）に収まっている。
- **AC-06**: `/admin/reports` の `select` に `*` が含まれず、返却列が描画・集計に必要なものだけになっている。通報一覧の表示内容（IP 重複カウント含む）が従来どおり。
- **AC-07**: `get_admin_user_list` が `p_limit` / `p_offset`（＋検索語）を受け付け、`/admin/users` が **20 件単位**で表示・ページ送り・検索できる。**`AdminLogsPage` は全件 RPC を呼ばない**（ネットワークタブで確認）。監査ログの email 表示が従来どおり解決される。
- **AC-08**: `/admin/users` の DOM 上の**ユーザー行が 1 セットのみ**（現状は `:312` と `:386` で 2 セット）。モバイル幅・PC 幅の両方で表示とロール変更操作が従来どおり動く。
- **AC-09**: `npm run size` がパスする。**PhotoGallery は `HomePage.tsx:25` で `dynamic(ssr:false)` 済み**なのでホームの 10 kB 枠には直接載らないが、仮想化ライブラリを追加すると初回スクロール時に取得されるチャンクが増える（**CSS のみの手法を第一候補にする理由の一つ**）。/admin/posts 15 kB・/collection 15 kB 等の既存予算、および REQ-306 で追加された共有チャンク／ルート合算の予算もパスする。
- **AC-10**: `npm run schema:check`（`supabase/schema.sql` と型定義の同期）がパスする。RPC 変更後も admin 以外からの呼び出しが `Permission denied` で拒否される（`schema.sql:725-727` の JWT チェックが維持されている）。
- **AC-11**: `lint` / `type-check` / 既存 **652 テスト**がパスする。REQ-274 の AbortController / stale 上書き対策（`usePostList.ts:120-133, 148-151`）を壊していないこと。
