## 機能要件

- **FR-312-01（メタデータ生成ヘルパの新設 / 退行防止の本体）**: `src/lib/seo.ts` に、**パスを1つ受け取って `alternates.canonical` と `openGraph.url` を同じ値から生成する**ページメタデータヘルパ（例 `buildPageMetadata({ path, title, description, ogImage? })`）を追加する。ヘルパは shallow merge で失われる `type` / `siteName` / `locale` / `images` を**必ず含める**（既定値は `layout.tsx:22-31` および `seo.ts:6-8` の `SITE_NAME` / `DEFAULT_DESCRIPTION` / `DEFAULT_OG_IMAGE` から供給する）。canonical と og:url が**構造的に一致する**ことが本FRの目的であり、両者を別々に手書きできる状態を残さない。
- **FR-312-02（静的7ページへの適用）**: 問題Aの7ページ（`trends` / `ranking` / `area` / `about` / `terms` / `privacy` / `dataset`）を FR-312-01 のヘルパ経由に置き換え、og:title / og:description / og:url がページ固有値になるようにする。**og:image・og:site_name・og:type・og:locale を失わせない**（問題Bの再発防止）。
- **FR-312-03（`/requests` の欠落補完）**: `requests/page.tsx:12` の `openGraph: { url: '/requests' }` を FR-312-01 のヘルパ経由に置き換え、shallow merge で消えている og:image / og:site_name / og:type / og:locale を復元する。`title: { absolute: … }`（REQ-199 FR-199-02 のブランド二重付与回避）は維持する。
- **FR-312-04（twitter 方針の統一）**: 問題Cの C-1 / C-2 のいずれかを選び、**8ページで twitter:title / twitter:description がページ固有になる**状態に統一する。C-1（root の `twitter.title` / `twitter.description` を外して og フォールバックに任せる）を採る場合は **FR-312-02 / FR-312-03 の完了が前提**（og:image を持たないページで twitter:image が消えるため）。選んだ理由をコード上のコメントに残す（`lp/page.tsx:18-21` と同じ流儀）。
- **FR-312-05（パンくず名と遷移先 h1 の整合）**: 問題Dを解消する。`src/lib/seo.ts:135`（JSON-LD）と `species/[species]/page.tsx:101-105`（可視パンくず）の position 2 の名前を、**遷移先ページの主見出しと一致する表現**にそろえる。取り得る方向は (a) `/about` の h1（`about.title`）とパンくず名を同じ語にそろえる、(b) 種一覧のインデックス（`/species`）を親に据える。(b) は REQ-227 の種ピラー設計に関わるため、**本REQでは (a) を既定とし、(b) を選ぶ場合は REQ-227 側へ委譲する**。JSON-LD と可視パンくずの文字列が別々に手書きされている現状も、同一の定数から生成する形にする。
- **FR-312-06（admin noindex の固定化・訂正の反映）**: 問題Eの訂正を前提に、(a) `admin/layout.tsx:4-7` の `robots` が配下一括の noindex を担っている旨をコメントで明示する、(b) `admin/login/page.tsx:5` の重複宣言を撤去するか「親と同値の冗長宣言である」旨をコメントする、(c) **`/admin` 配下の任意の1ページで `robots` に noindex が解決されることを検査で固定化する**（`generateMetadata` / metadata の解決結果を検証するテスト、または e2e で `<meta name="robots">` を確認する）。`robots.ts:16` の `disallow: ['/admin/']` はクロール制御であって noindex の保証ではないため、二重防御の片側が消えたことを検知できる状態にする。
- **FR-312-07（多言語URLの判断と記録）**: 「多言語SEOを取りに行くか」を判断し、**結論を判断記録として残す**（本REQの「対象外」節または `docs/planning/` の判断記録）。取りに行く場合は `/[locale]` ルーティング・`alternates.languages`・`x-default`・sitemap の言語別エントリを**別REQとして起票**する（本REQでは実装しない）。取りに行かない場合は「現状維持で問題なし」と明記し、翻訳が4言語1277キー揃っている事実を併記して将来の再判断余地を残す。
- **FR-312-08（退行検知）**: FR-312-01 のヘルパを使わずに `openGraph` を直接手書きしたページが増えることを防ぐ検査を1つ用意する。最小案は「indexable な静的ページの og:url が canonical と一致すること」をビルド成果物または metadata 解決結果に対して検証するテスト。**`openGraph` を部分定義したページで og:image が欠落しないことも同じ検査に含める**（問題Bの型）。
