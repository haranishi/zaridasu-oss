## ユーザーストーリー

### US-001: 運用者として API コストを抑制したい
**As a** プロジェクト運用者（開発者）,
**I want to** 投稿数の増加に対し AI 判定 API のコストが線形に増えないようにしたい,
**So that** 持続可能なサービス運営が可能になる.

**受け入れ条件:**
- [ ] AC-1: 月額 Gemini API コストが、施策実施前と比較して **80% 以上削減**されていること
- [ ] AC-2: コスト削減後も AI 判定の精度（recall / precision）が **施策前比 ±3 ポイント以内**に収まっていること
- [ ] AC-3: 月次コストレポートが自動生成され、ダッシュボードまたは定期メールで確認できること

**優先度:** 高
**見積もり:** XL（複数 Phase に分割実装）

### US-002: 投稿者として無駄な投稿で AI を呼び出したくない
**As a** 一般ユーザー（投稿者）,
**I want to** 明らかに不適切な音声/画像（無音、真っ黒、ブレ写真等）の場合は投稿前にエラーで気づかせてほしい,
**So that** 後から「却下されました」通知を受けてやり直す手間が減る.

**受け入れ条件:**
- [ ] AC-1: 無音音声（RMS が閾値以下）は投稿ボタン押下前にトーストで警告
- [ ] AC-2: 解像度が極端に低い、または極度のブレ写真は投稿前にチェックして警告
- [ ] AC-3: 警告は強制ではなく「それでも投稿」を許可する（誤検知時の救済）

**優先度:** 中
**見積もり:** L

### US-003: 管理者として AI コストを可視化したい
**As a** 管理者,
**I want to** 直近 30 日間の AI 判定 API 呼び出し回数・コストを管理画面で確認したい,
**So that** 異常な急増を早期に検知できる.

**優先度:** 中
**見積もり:** M
