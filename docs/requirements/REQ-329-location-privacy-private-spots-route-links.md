# REQ-329: 位置の公開／非公開を投稿者が選べる・非公開のクイック保存・地図から経路検索

作成日: 2026-09-26
優先度: P1 ／ 種別: UI + DB
状態: 実装済み（migration 未適用）
関連: REQ-243（位置情報プライバシー・公開レベル）、REQ-244（INSERT 列保護）、REQ-091（Google Maps で開く）、REQ-231（逆ジオの地名）、REQ-172（位置精度）

## これは何か

希少種（メダカ・サンショウウオ等）のデータも集めたい。ただし生息地が公開されると採集圧にさらされるので、**場所は伏せたい**。本人要望（2026-09-26）は 3 つ。

1. 投稿ごとに**位置を公開するか非公開にするか**を投稿者が選べる。管理者も決められる（既存の管理画面の公開レベル設定をそのまま使う）。
2. 投稿フォームは項目が多く時間がかかるので、**ボタン 1 つで今の場所を非公開で保存し、自分で名前を付けられる**（クイック保存）。
3. 地図のピンから、**そこまでの経路を Google マップや Yahoo!マップで調べられる**。

## 主要な決定事項（要点）

- **「非公開」は位置の非公開**（`location_disclosure='hidden'`）。投稿そのものは公開のまま（種・市町村・日付は集計や一覧に残る）。理由は要望の対象が「希少種がいるところ」＝場所であることと、外来種の分布データとしての公共性を保つため。投稿ごと隠す案は採らなかった（公開ページ・RPC の監査範囲が大きく、研究データの公共性も落ちる）。
- **投稿者は「より伏せる」方向にだけ動かせる。** INSERT で `hidden` を選べる／UPDATE で `hidden` へ変えられる（一方向）。公開へ戻す・精度を上げる（precise）は管理者だけ。これで**管理者が伏せた記録を投稿者が戻すことも起こらない**（ロック用の列が要らない）。
- **hidden の投稿では字名・水系名も公開列から外す。** 逆ジオの `locality` / `water_body`（「〇〇沼」など）が hidden でも公開列に残り、地域ページの「よく報告される水辺」や地図の一覧データから読めていた（REQ-243 の取りこぼし）。hidden の間は管理者専用テーブル `post_hidden_geo` へ退避して公開列を NULL にし、管理者が公開へ戻すと復元する。**研究用の地名は消さない**。フロントの変更も配信の順序合わせも要らない（DB トリガーだけで完結）。
- **クイック保存は posts とは別テーブル `private_spots`。** 種の制約（american/bullfrog）・審査・24 時間 5 件の投稿上限・公開データセット・ゲーミフィケーションに一切触れないため。見えるのは本人と管理者だけ（RLS）。anon には GRANT 自体を付けない。
- **圏外でも保存できる。** 保存ボタンを押した時点の位置・名前は端末（localStorage）に残し、オンラインに戻ったら自動送信する。キューには利用者 ID を持たせ、同じ端末で別の人がログインしても他人の名義で送らない。
- **経路は各社の公開 URL だけで開く**（API キー・利用料なし）。出発地は渡さない（各アプリが現在地を使う）。**URL には座標だけを載せ、非公開スポットの名前は載せない**（第三者のログに場所の手がかりを残さないため。Yahoo! の行き先名は固定語「目的地」）。

### クライアント

- **FR-329-09**: 投稿詳細：投稿者には「この投稿の位置を非公開にする」（確認つき・一方向）。非公開の記録を本人が見ているときは「あなたと運営だけに表示」を明示。
- **FR-329-10**: 経路ボタン（Google マップ / Yahoo!マップ / Apple マップ）を、地図の投稿ピン・調査依頼ピン・立てたピン・非公開スポット・投稿詳細・調査依頼詳細・管理画面に出す。粗化座標では「おおよその位置」と添える。旧 `OpenInGoogleMapsButton` は置き換えて削除。

- **FR-329-12**: 地図に「非公開で保存」ボタン。名前（任意・空なら「非公開スポット 月/日 時:分」）とメモ（任意）で保存。現在地が取れないときは地図の中心でも保存できる。

## 受け入れ条件
- **AC-01**: 投稿フォームで「非公開」を選んで投稿すると、第三者の地図・公開データセットに位置が出ない（display_lat/lng が NULL）。
- **AC-02**: 投稿者は非公開を公開へ戻せない。管理者は戻せ、戻すと字名・水系名が復元される。
- **AC-03**: 非公開の投稿の字名・水系名は anon から NULL（地域ページの集計にも出ない）。
- **AC-04**: 非公開スポットは本人と管理者しか読めない。anon は権限エラー。
- **AC-05**: 圏外で保存したスポットは、オンライン復帰後に自動で送られる。
- **AC-06**: 地図のどのピンからも 3 社の経路が新しいタブで開く。URL に座標以外（スポット名等）が入らない。
- **AC-07**: `type-check` / `lint` / `test` / `i18n:check` / `schema:check` / pg-tap / `size` / `size:routes` が通る。

## やらないこと（今回）
- 希少種を投稿の「種」として正式に追加すること（`species` の CHECK・AI 判定・図鑑・公開データセットの列定義に波及する。対象種リストの決定が先）。
- 投稿そのもの（写真・コメントを含む）を非公開にすること。
- 利用者による「非公開 → 公開」の取り消し（誤操作は運営が管理画面で戻す）。
- 管理画面からの非公開スポットの編集・削除（DB は管理者の削除を許しているが UI は閲覧専用。監査ログの action 追加が要るため）。

## 残課題（本人判断）
- プライバシーポリシー／利用規約に「非公開スポットは本人と運営だけが見られ、研究のために運営が参照することがある」旨を 1 項目足すか（保存画面には表示済み）。
- Yahoo!マップの経路 URL は 2022 年公開の URL 仕様（`/route/car?to=&toLat=&toLon=`）に従ったが、開発環境から公式ページを直接開けなかったため、実機（iPhone / Android）で一度開いて確認すること。
