## 非機能要件

### パフォーマンス
- 詳細ページのコメント取得は `idx_request_comments_request` で **P95 100ms 以内**
- 統合タイムライン view は依頼あたり 50 件以内想定なので問題なし
- コメント投稿の楽観的 UI 更新（送信失敗時にロールバック）

### セキュリティ
- RLS により他人のコメント削除不可
- ソフトデリートで履歴保持（運用上の問い合わせ対応）
- spam-check + レート制限で乱投稿防止
- XSS 対策: 既存ヘルパで本文を escape して表示（既存 posts コメントと同等）

### UX
- コメントは長押し or メニューから削除可能（モバイル UX 配慮）
- 削除されたコメントは「削除されました」プレースホルダで履歴上は表示
- 投稿後の入力欄クリア + フォーカスは次の自然な位置

### アクセシビリティ
- スレッドは `<ol>` または `aria-live="polite"` の領域
- 削除ボタンに `aria-label`
- キーボードのみで投稿 / 削除完結
