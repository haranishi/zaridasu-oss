## ユーザーストーリー

### US-089-01: ユーザーとして依頼に直接質問したい
**As a** 興味を持った近隣ユーザー,
**I want to** 詳細ページから依頼に直接コメントできる,
**So that** 結果投稿を待たずに依頼者に質問・確認できる.

**受け入れ条件:**
- [ ] AC-1: 詳細ページにコメント入力欄とスレッドが表示される
- [ ] AC-2: 投稿したコメントは即座にスレッドに反映される
- [ ] AC-3: 自分のコメントは削除可能、他人のコメントは削除不可
- [ ] AC-4: 未ログインでは閲覧のみ可能、投稿時はサインイン誘導

**優先度:** 高 ／ **見積もり:** S

### US-089-02: 依頼者として全コメントを 1 箇所で読みたい
**As a** 依頼者,
**I want to** 詳細ページで「依頼へのコメント」と「関連結果投稿のコメント」を時系列で見たい,
**So that** 会話の流れを追える.

**受け入れ条件:**
- [ ] AC-1: 詳細ページに統合タイムラインがある
- [ ] AC-2: 各コメントに「依頼へのコメント」「結果投稿 #X へのコメント」のラベルが付く
- [ ] AC-3: 結果投稿クリックで該当 posts へ遷移可能

**優先度:** 中 ／ **見積もり:** M

### US-089-03: 依頼者として新コメント通知を受けたい
**As a** 依頼者,
**I want to** 自分の依頼にコメントが付いた時に通知が届く,
**So that** 反応を見逃さない.

**受け入れ条件:**
- [ ] AC-1: 依頼へのコメント INSERT で依頼者にメール通知（REQ-088 基盤）
- [ ] AC-2: スレッドに参加した他ユーザーにも通知（opt-out 可）
- [ ] AC-3: 自分が投稿したコメントは自分に通知されない

**優先度:** 中 ／ **見積もり:** S
