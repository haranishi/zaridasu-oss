### 5.3 イラスト要件（v2 で追加）

6画面すべてに1枚ずつ、**オリジナルのイラスト**を置く。環境省の図・写真は転載しない（§6.2）ため、同じ内容を自前の絵で伝える。

#### 作り方と置き場所

- [ ] **FR-284-28（生成手段）**: イラストは **Codex（`codex exec` の画像生成）で作成する**。生成物は必ず目視で確認してから採用する。1枚でも意図と違うものは採用せず、プロンプトを直して作り直す。
- [ ] **FR-284-29（文字を焼き込まない）**: **画像の中に文字（日本語・英数字とも）を一切入れない**。AI生成画像の文字は崩れるうえ、**4言語対応（NFR-284-03）と両立しない**。見出し・ラベル・矢印の注釈はすべて HTML 側のテキストで乗せる。図中に文字が必要に見える場合は、**記号・色・配置で表す**か、HTML の吹き出しを重ねる。
- [ ] **FR-284-30（置き場所と形式）**: `public/images/intro/` 配下に `intro-0X-<slug>.webp` として置く。生成は PNG（正方形 1024px 以上）で行い、**webp へ変換**して採用する。**1枚 80KB 以下**を目安とする（`/optimize-media` 規定）。元の PNG はリポジトリに含めない。
- [ ] **FR-284-31（表示方法）**: `next/image` で表示し、**1枚目のみ `priority`、2枚目以降は遅延読み込み**とする。`sizes` を指定し、モーダル幅を超える解像度を配信しない。画像の読み込み失敗時もテキストだけで意味が通ること（画像は理解を助けるが、**画像なしでは意味が通らない構成にしない**）。
- [ ] **FR-284-32（代替テキスト）**: 各画像に**内容を説明する `alt`** を i18n キー（`intro.slides.N.imageAlt`）で 4言語ぶん用意する。装飾ではなく意味を運ぶ画像なので `alt=""` にしない。

#### 絵柄の統一ルール（6枚で世界観を揃える）

- [ ] **FR-284-33（スタイル）**: 全6枚で次を守る。マスコット「ザリくん」（`public/mascot.svg`・丸い体／大きなハサミ2本／やさしい笑み）と**同じ世界の絵に見えること**が合格条件。
  - **フラットで平面的なベクター調のイラスト**。写実的な写真風・3D風・厚塗りにしない。細い線と単純な面で構成する。
  - **やさしく、丸みのある形**。とがった形・鋭い影・強いコントラストの演出をしない（brand-memo §5「ドミナントシェイプ＝丸」）。
  - **背景は白または淡い生地色**（`#ffffff` / `#fef2f2`）。モーダル内に置くので、周囲と馴染むこと。
  - 人物を描く場合は**顔の特徴を描き込みすぎない**（特定の人物・年齢・性別に見えないようにする）。
- [ ] **FR-284-34（色）**: ブランドパレットに従う。**ザリガニはブランド赤（`#dc2626` 系）**、下地は白・淡赤（`#fef2f2`）、締め色に濃赤（`#7f1d1d`）。加えて次を守る。
  - **対比（あり／なし・前／後・粗い／細かい）を赤と緑の組み合わせで表さない。** 色覚多様性のある人に区別できない。対比には**青（`#0072B2`）と橙（`#D55E00`）**、または**明度差**を使う（ザリダスのチラシで採用済みの方針と揃える）。
  - **ウシガエルの緑（`#16A34A`）をブランド面の色として使わない**（brand-memo Don't）。緑は水草・自然物の描写に限る。
  - 意味を色だけに載せない。**形・位置・大きさでも区別が付く**ようにする。
- [ ] **FR-284-35（描いてはいけないもの）**: 環境省・自治体・大学のロゴやそれらしい紋章／実在の地図の形をなぞった図（**秋田県や日本の正確な県境を描かない**。地図は抽象的な水辺の俯瞰にとどめる）／人が生きものを捕まえて持ち去る場面（§7.1 の推奨行動と矛盾する）／ザリガニを踏む・殺す場面／攻撃的な表情のザリガニ。
