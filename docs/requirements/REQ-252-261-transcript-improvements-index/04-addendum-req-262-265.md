## REQ-263 ゲーミフィケーション拡張（探索・監視・撮影スコア 等）
- **状況（2026-07-07）：取捨選択・追加アイデアはユーザー入力待ち**（「外すもの」＋追加案を後日反映）。
- **背景**：既に XP/レベル・バッジ・週次クエスト（`lib/quests.ts`/`WeeklyQuests`）・解放（`useUnlocks`/`UnlockCelebration`）・図鑑/水槽/3Dザリガニ（`collection/`）・調査リクエストがある。これらを「もっとゲームらしく」拡張したい。
- **やること（アイデア束・要取捨選択）**：
  - **未調査水域の“探索”**：地図の未踏の池を薄く覆い、投稿で開拓（探索感）。REQ-259/255 連動。
  - **進出前線「監視員」ミッション**：前線付近の記録に高XP・専用称号。※駆除でなく「監視・記録」を称える（教育配慮）。
  - **写真クオリティ・スコア/コンボ**：AI 信頼度（REQ-252/253）連動で高品質写真に演出＋ボーナス。撮影スキルの上達ゲージ。
  - **eDNA「答え合わせ」**：eDNA 地点（REQ-260）と目撃の一致/不一致を当てるミニ要素。
  - **地域/学校対抗の協力型シーズンイベント**：中央高校授業（REQ-261）連動。個人競争より協力に寄せて Goodhart 回避。
  - **定点観察ストリーク**：`survey_method='structured'` の継続を可視化（データ質と両立）。
- **こんな感じでできます**：`lib/quests.ts`・`useUnlocks`・`BadgeSection`・`UnlockCelebration`・SurveyRequest を拡張。**アンチGoodhart**（承認済み/品質を称え、量・いいねに流れない）と**中核貢献を壁で隠さない**（REQ-249 原則）を厳守。
- **関連**：REQ-235・248〜251／258・259・260。**優先度**：中（体験価値高いが要設計）。

## REQ-264 水域の3D表現（段階導入）
- **状況（2026-07-07）：②の3Dプレビューは一旦なし**。①2D視認性UP（塗り/アウトライン/アイコン強調）のみ進める。
- **背景**：現状の2D地図では水域（池・川）が分かりにくい、との指摘。水域の視認性を上げたい。
- **やること**：①まず2Dで水域の視認性UP（塗り/アウトライン/アイコン強調）。②特定の池の「3Dプレビュー」（水面・へこみを立体表現）。
- **こんな感じでできます**：水域データは OSM `natural=water`。2D強調が先。3Dは既存 `crayfish3d` チャンク（`Crayfish3DStage`/three/R3F）を流用し別ページ/モーダルで async 描画（`size-limit` の First Load を守る）。将来的に deck.gl / MapLibre `fill-extrusion` も選択肢だが依存増に注意。
- **関連**：REQ-250（3D基盤）／258・259／`next.config.ts` の crayfish3d split。**優先度**：中（②は重い→段階導入）。

## REQ-265 地図上のザリガニ演出（“動く”表現）
- **状況（2026-07-07）：3D（3Dザリガニ配置）は一旦なし**。軽量2Dアニメ（Lottie/CSS スプライト）のみで進める。
- **背景**：いる場所を直感的・楽しく見せたい（「ザリガニをフリリで表現」の要望）。
- **やること**：ザリガニ確認地点/高密度水域に、動くザリガニ表現。投稿時に地図がその場でリアクション（さざなみ/ポップ＝即時報酬）。
- **こんな感じでできます**：軽量2Dアニメ（Lottie/CSS スプライト）を既定にし、負荷を見て既存3Dザリガニのミニチュア配置。密度（REQ-258）に応じ数/動きを変化。**教育配慮**：特定外来生物のため「かわいく見せて放流を助長しない」＝キャプションで外来種問題を明示（`collection` と同方針）。
- **関連**：REQ-250・258／MapView マーカー。**優先度**：中（演出・リテンション）。
