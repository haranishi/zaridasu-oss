## 要件概要

### 背景・目的
ザリダス（kenkyuu-app）の「調査依頼（survey_request）」機能は、ユーザーが「この場所で外来種の状況を調べてほしい」と地図上にピンを立て、近隣ユーザーに調査協力を呼びかけるソーシャル機能である。

現状の実装は **完成度およそ 55%** に留まっており、地図上のオレンジ 🔍 マーカー、詳細ページ、投稿フォーム、本人によるクローズ操作までは動作する。一方で、一覧ページ・結果投稿フロー・応答機能・通知・コメント直結化など、**「依頼が立ってから完了するまで」のループ**が成立していない。

本親ドキュメントでは、調査依頼機能を **「立てる → 見つける → 応答する → 結果が届く → クローズする」** という完結したループに仕上げるため、機能を 5 Phase に分割し、優先順位と依存関係を整理する。

**目標完成度ロードマップ:**

| 時点 | 完成度 | 主要マイルストーン |
|---|---|---|
| 現在 | 55% | 投稿・地図表示・詳細・本人クローズのみ |
| Phase 1 完了 | 65% | 一覧ページ `/requests` 公開 |
| Phase 2 完了 | 75% | 結果投稿が依頼に紐付き、status 遷移が自動化 |
| Phase 3 完了 | 85% | 「協力する」アクションと応答者カウントが機能 |
| Phase 4 完了 | 95% | 近隣ユーザー / 投稿者への通知が動作 |
| Phase 5 完了 | 100% | コメント直結化により会話が分散しない |
