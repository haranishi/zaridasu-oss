# REQ-029: フォームUXの改善（リアルタイムバリデーション・未保存保護）

## 背景
投稿フォーム・認証モーダルでリアルタイムバリデーションが不足しており、ユーザーが送信時まで入力ミスに気づけない。また、投稿フォームで長文のコメントや複数写真を設定した状態でページ離脱しても警告が出ず、データ消失のリスクがある。

## 現状の問題
- `src/components/features/posts/PostForm.tsx`:
  - 個数フィールド（`count`）: `min="1"` `max={COUNT_MAX}` はHTML属性のみ。リアルタイムのユーザーフレンドリーなエラーメッセージなし
  - コメント: `maxLength` は設定済みだが、上限接近時の視覚的警告なし
  - `beforeunload` イベントリスナーなし（フォーム入力中の離脱で確認ダイアログが出ない）
- `src/components/modals/AuthModal.tsx`:
  - メール入力: フォーマットのリアルタイム検証なし
  - パスワード入力: 要件を満たしているかのリアルタイムフィードバックなし
  - エラー表示に赤枠等の視覚的状態変化なし
- `src/components/modals/ReportModal.tsx`:
  - 必須フィールドに `aria-required` 属性なし

## 目的
フォームのリアルタイムバリデーションと未保存データ保護を実装し、ユーザーの入力ミス・データ消失を防ぐ。

## 要件

### 機能要件
- [ ] FR-029-01: PostForm の `count` フィールドにリアルタイムバリデーション（1〜COUNT_MAX の範囲チェック、整数チェック）とエラーメッセージを追加する
- [ ] FR-029-02: PostForm のコメント欄に残り文字数の視覚的警告を追加する（残り20文字以下で黄色、0文字で赤色）
- [ ] FR-029-03: PostForm に `beforeunload` イベントリスナーを追加し、フォームに入力がある状態でページ離脱時に確認ダイアログを表示する
- [ ] FR-029-04: AuthModal のメールフィールドにリアルタイムフォーマット検証を追加する（blur 時）
- [ ] FR-029-05: AuthModal のパスワードフィールドに強度インジケーターを追加する（8文字以上、大小英字、数字の充足状態を表示）
- [ ] FR-029-06: バリデーションエラーのあるフィールドに赤枠（`border-red-500`）を適用する
- [ ] FR-029-07: 必須フィールドに `aria-required="true"` を追加する

### 非機能要件
- [ ] NFR-029-01: バリデーションはデバウンス（300ms）し、キー入力ごとに実行しない
- [ ] NFR-029-02: `beforeunload` はフォームがクリーン（未入力）状態では発火しない

## 受入条件
- [ ] AC-01: 個数フィールドに0を入力するとリアルタイムでエラーメッセージが表示される
- [ ] AC-02: コメント欄が残り20文字以下になると文字数カウンターが黄色になる
- [ ] AC-03: フォームに入力がある状態でブラウザバックするとブラウザの確認ダイアログが表示される
- [ ] AC-04: メールフィールドからフォーカスを外した時、不正なフォーマットではエラーが表示される
- [ ] AC-05: 必須フィールドのHTML要素に `aria-required="true"` が存在する

## 影響範囲
- `src/components/features/posts/PostForm.tsx`
- `src/components/modals/AuthModal.tsx`
- `src/components/modals/ReportModal.tsx`

## 優先度
- **緊急度**: Medium
- **重要度**: Medium
- **理由**: ユーザー体験の質に直結し、投稿データの消失防止は重要だが、致命的な機能欠損ではない
