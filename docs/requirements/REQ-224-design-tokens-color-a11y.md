# REQ-224: デザイントークン整備（60-30-10 カラー / 8pt グリッド / タイポ基準）＋色覚・コントラスト a11y

## これは何か

色・余白・タイポの基本値を CSS カスタムプロパティのトークンへ集約し、あわせて色覚多様性とコントラストの問題を是正する要件。全文は同名ディレクトリの部品ファイルへ逐語で分割してある（入口のみ新規要約）。

## 目的・背景の要約

デザインの基本値がトークン化されておらず、Tailwind ユーティリティとハードコード HEX で各コンポーネントに散らばっている。とくに主役 2 種の色分け（アメリカザリガニ＝赤 `#DC2626` ／ ウシガエル＝緑 `#16A34A`、`src/lib/constants.ts:78-79`）は最も頻出する識別でありながら、色覚多様性で最も識別困難な赤×緑であり、地図マーカー・ドーナツグラフ・進捗バーへ色だけの手がかりとして流れている。本要件は (A) トークンを `:root` / `.dark` へ集約、(B) アクセントを主 CTA 1 色に絞る、(C) 色覚多様性対応とコントラスト適合を行う。下敷きは Obsidian のデザイン基礎ノート群。

## 主要な決定事項の要点

- 配色は 60-30-10（ベース＝ニュートラル／メイン／アクセント＝主 CTA 専用 1 色）。状態は**色＋アイコン＋テキストの 3 点セット**とし、赤×緑・緑×黄の素朴な対比をやめて青×オレンジへ寄せる。データ可視化は Wong パレット系を使う。
- 主役 2 種は色だけに依存させない。地図マーカーは形/グリフで区別し、種色自体も色覚安全な配色へ見直す。
- `#F59E0B` が「不明（種）」「通常（緊急度）」「募集中（ステータス）」の 3 義に再利用されている問題は、値が同じでも**用途別トークンへ分離**して将来の意味別変更を可能にする。
- コントラストはテキスト 4.5:1・UI 部品/グラフ 3:1 以上へ底上げし、情報を担う 14px 未満フォントは 14px 以上へ引き上げる。
- 実装は CSS カスタムプロパティのみで行い、**ランタイムコストゼロ**（JS による色計算・追加再レンダーなし）。移行は段階的で、置換漏れでも壊れないフォールバック値を変数に持たせる。
- 検証は①グレースケール変換②WebAIM 等のコントラスト計測③色覚シミュレータ（P/D 型）の 3 点セットで行い、結果を記録する。
- 構造的 a11y（ARIA・キーボード・スキップリンク）は REQ-031 / 013 / 188 / 202 / 195 の担当で、本要件は触らない。LP 固有は REQ-204、REQ-176 は本要件が作るトークンの利用側。
- 緊急度 Medium / 重要度 High。表示は成立しているが、種の区別というコア機能が色覚多様性ユーザーで機能低下する包摂性の実害であり、後続改善すべての土台になる。
