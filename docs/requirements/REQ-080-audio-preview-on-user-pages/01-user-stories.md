## ユーザーストーリー

### US-080-01: 投稿者として自分の鳴き声録音を聴き直したい
**As a** 投稿者,
**I want to** マイページで自分の過去の音声付き投稿を再生したい,
**So that** AI 判定結果（一致 / 不一致）の根拠を音声レベルで確認できる.

**受け入れ条件:**
- [ ] AC-1: マイページの各投稿カードに、`audio_url` がある場合のみ音声プレーヤーが表示される
- [ ] AC-2: 再生ボタンで音声を再生できる（停止・シーク含む標準 UI）
- [ ] AC-3: 再生時に元音声 URL から直接ストリーミング（別画面遷移なし）
- [ ] AC-4: `audio_url` が null の投稿ではプレーヤー自体が表示されない

**優先度:** 高
**見積もり:** S

### US-080-02: 他ユーザーが投稿詳細で音声を聴けるようにしたい
**As a** 閲覧ユーザー,
**I want to** 投稿詳細ページで音声付き投稿の音声を再生したい,
**So that** 当該投稿の一次情報を確認できる.

**受け入れ条件:**
- [ ] AC-1: `/post/[id]` で `audio_url` がある場合のみ音声プレーヤーが表示される
- [ ] AC-2: 再生前にロードを開始しない（`preload="metadata"` でメタデータのみ）
- [ ] AC-3: 公開 (`status='approved'`) な投稿のみ音声が表示される（pending / rejected では非表示、あるいは自分の投稿に限る）
- [ ] AC-4: モバイル Safari でも再生できる

**優先度:** 中
**見積もり:** S

### US-080-03: 読み込み失敗時にも救済されたい
**As a** ユーザー,
**I want to** 音声の読み込みが失敗した場合にエラーが分かる,
**So that** 「プレーヤーは出ているのに何も起きない」状態に陥らない.

**受け入れ条件:**
- [ ] AC-1: `<audio>` の error イベントでエラーメッセージ表示（「音声の読み込みに失敗しました」）
- [ ] AC-2: フォールバックとして audio_url への直接リンク（ダウンロード扱い）を提供

**優先度:** 中
**見積もり:** XS
