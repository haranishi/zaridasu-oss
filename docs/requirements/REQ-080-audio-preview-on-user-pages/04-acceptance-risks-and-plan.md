## 受け入れ基準

| ID | 受け入れ基準 |
|---|---|
| AC-080-01 | マイページで音声付き投稿を 1 件表示し、プレーヤーで再生できる |
| AC-080-02 | 投稿詳細ページで音声付き投稿を開き、プレーヤーで再生できる |
| AC-080-03 | `audio_url` NULL の投稿ではプレーヤーが表示されない |
| AC-080-04 | `audio_url` が 404 / CORS エラーの場合、エラーメッセージとダウンロードリンクが表示される |
| AC-080-05 | モバイル Safari (iOS 16+) で再生できる |
| AC-080-06 | ダークモードでプレーヤーが適切に表示される |
| AC-080-07 | VBR ヘッダ無し MP3 でも duration 表示が `0:08` のように正しく出る |

## リスク・トレードオフ

| リスク | 緩和策 |
|---|---|
| 一覧に複数プレーヤーを置くとメモリ/ネットワーク負荷増 | `preload="metadata"` で本体ダウンロードを遅延 |
| 音声ファイルが storage から消えるとリンク切れ | onError で救済 UI 表示 |
| モバイル Safari で最初のタップまで再生開始が遅い | Safari 仕様のため受容、preload="auto" にすると逆に帯域消費増 |
| public_read_audio RLS 依存のため、将来プライベート音声化すると全面修正 | 本要件外で signed URL 化を別途検討 |
| 投稿詳細で pending / rejected 投稿の音声を誰でも聴けると悪用の余地 | 閲覧可視性は status + 所有者で絞る（FR-080-02 AC-3） |
